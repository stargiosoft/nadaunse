# QA 체크리스트

> 이 파일은 QA 에이전트가 참조하는 검증 항목 목록입니다.
> 새로운 검증 항목이 필요하면 여기에 추가하세요.

## 1. 공통 (모든 페이지)

- [ ] 페이지 정상 로딩 (빈 화면 아님)
- [ ] JavaScript 콘솔 에러 없음
- [ ] 주요 UI 요소 렌더링됨
- [ ] 네비게이션 헤더/하단바 정상 표시
- [ ] 뒤로가기 버튼 동작
- [ ] 로딩 스피너가 무한 로딩 아님

## 2. 홈 화면

- [ ] 사용자 이름 표시 (로그인 시)
- [ ] 검색바 존재
- [ ] 사주/타로 상담 섹션 표시
- [ ] NEW 무료 운세 카드 표시 (최소 1개)
- [ ] BEST 운세 랭킹 표시
- [ ] 카테고리 필터 버튼 동작
- [ ] 푸터 정보 표시

## 3. 콘텐츠 상세

- [ ] 썸네일 이미지 로딩
- [ ] 제목, 설명 텍스트 표시
- [ ] CTA 버튼 (구매/무료보기) 클릭 가능
- [ ] 가격 정보 정확히 표시 (유료)
- [ ] "무료" 뱃지 표시 (무료)

## 4. 사주 입력

- [ ] 생년월일 입력 필드 동작
- [ ] 성별 선택 동작
- [ ] 시간 선택 (모름 옵션 포함)
- [ ] 저장된 사주 목록 표시 (로그인 시)
- [ ] 유효성 검증 (미래 날짜 등)

## 5. 결과 페이지

- [ ] AI 생성 답변 텍스트 표시
- [ ] 목차 존재 (유료)
- [ ] 나다움 기록하기 (태그 선택) 동작
- [ ] 공유 버튼 존재

## 6. 프로필

- [ ] 사용자 정보 표시
- [ ] 사주 관리 링크
- [ ] 구매 내역 링크
- [ ] 나다움 태그 확인
- [ ] 보고서 목록

## 7. 알려진 버그 패턴 (필수 확인)

- [ ] DEV 전용 요소가 프로덕션에 노출되지 않음
- [ ] 하단 CTA 버튼이 다른 요소에 가려지지 않음
- [ ] 이미지 로딩 실패 없음 (CSP 위반)
- [ ] 콘솔에 CORS 에러 없음
- [ ] localStorage/sessionStorage 접근 에러 없음

## 8. 성능

- [ ] 초기 로딩 5초 이내
- [ ] 페이지 전환 2초 이내
- [ ] 이미지 lazy loading 동작
- [ ] 불필요한 API 중복 호출 없음

## 9. 접근성

- [ ] 주요 버튼에 접근 가능한 이름 존재
- [ ] 이미지에 alt 텍스트 존재
- [ ] 폼 입력 필드에 label 연결
