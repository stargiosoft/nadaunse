# 마음톡 기능 개발 계획

> **상태**: 기획 단계
> **최종 업데이트**: 2026-03-10

---

## 1. 개요

### 컨셉
**"나보다 나를 더 잘 아는 AI 친구"**

감정 체크인(마음 일기) + 나다움 데이터 기반 개인화 AI 상담을 결합한 심리 케어 서비스.
일반 AI 챗봇과 달리 첫 대화부터 사용자의 성향, 심리 흐름, 사주 데이터를 이미 알고 있어
"처음부터 다시 설명할 필요 없는" 상담 경험 제공.

### 차별점
- **기존 AI 상담**: 매번 처음부터 상황 설명 필요
- **마음톡**: 136+ 나다움 태그, 6축 DNA, 상황 요약이 시스템 프롬프트에 포함 → 맥락 있는 공감

### 탭바 위치
- 하단 탭바 4번째 탭 (홈 | 타로 | 사주 | **마음톡** | 마이)
- 탭 아이콘: 말풍선 + 하트 (또는 적절한 아이콘)

## 2. 활용 데이터 (기존 자산)

### 2.1 나다움 태그 (`user_trait_tags`)
- 136+ 태그 누적 (positive/negative/neutral)
- 운세 결과마다 3개씩 자동 추출 (장점 2 + 단점 1)
- 활용: AI 시스템 프롬프트에 상위 태그 주입 → 성격 맥락 제공

### 2.2 나다움 DNA (6축)
| 축 | 매칭 태그 키워드 |
|----|-----------------|
| 실행력 | 추진력, 도전, 적극, 결단, 행동, 실천, 진취, 주도, 과감, 대범 |
| 사고력 | 분석, 논리, 전략, 통찰, 지적, 지혜, 탐구, 관찰, 냉철, 사려 |
| 감성 | 감성, 감수성, 섬세, 공감, 따뜻, 다정, 포근, 온화, 감정, 깊은 |
| 관계 | 사교, 배려, 친화, 소통, 친근, 협력, 포용, 이해심, 친절, 헌신 |
| 의지력 | 끈기, 인내, 꾸준, 집중, 묵묵, 뚝심, 견디, 굳건, 일관, 우직 |
| 안정감 | 차분, 신중, 균형, 현실, 안정, 절제, 침착, 담담, 조심, 신뢰 |

- 활용: DNA 비율로 상담 톤 조절 (감성 높으면 공감 중심, 사고력 높으면 분석 중심)

### 2.3 16가지 나다움 유형
- 4축 조합: (실행력 vs 사고력) × (감성 vs 안정감) × (관계) × (의지력)
- 예: "열정적 리더", "깊은 사색가", "철두철미 추진가"
- 활용: 유형별 상담 스타일 최적화

### 2.4 성향 밸런스
- 열정(감성+실행력) vs 냉정(사고력+안정감) 퍼센트
- 활용: 공감 vs 분석 응답 비중 조절

### 2.5 상황 요약 (`user_situation_summaries`)
- AI 추출 심리 상태 요약 (150-200자)
- 소스: weekly_report, content_answer
- 활용: 최근 3~5개를 시스템 프롬프트에 주입 → 심리 흐름 맥락

### 2.6 오행 에너지 분포
- 만세력 API `발달오행` (목/화/토/금/수)
- 활용: 동양철학 관점의 에너지 조언 (선택적)

### 2.7 주간 보고서 (`weekly_reports` + `weekly_report_sections`)
- 감정 진단, 마음 처방 히스토리
- 활용: 장기 심리 변화 추적

## 3. 기능 구조

### 3.1 Layer 1: 감정 체크인 (마음 일기)

**목적**: 매일 감정 기록 → 데이터 축적 → 리포트 생성

**인터랙션**:
1. 마음톡 탭 진입 시 오늘 감정 체크인 여부 확인
2. 미체크 시 감정 선택 카드 노출 (대화 영역 상단)
3. 5단계 감정 선택: 😄 좋아요 | 🙂 괜찮아요 | 😐 그저 그래요 | 😔 별로예요 | 😢 힘들어요
4. 한줄 메모 입력 (선택, 최대 100자)
5. 저장 → AI가 감정에 맞는 첫 인사로 대화 시작

**데이터**:
- 감정 값: 1~5 (매우 좋음 ~ 매우 나쁨)
- 일 1회 제한 (수정 가능)
- 3초면 끝나는 초경량 인터랙션

### 3.2 Layer 2: AI 대화 (나를 아는 친구)

**목적**: 개인화된 심리 상담 대화

**시스템 프롬프트 구성**:
```
[역할]
너는 사용자의 오랜 친구이자 심리 상담사야.
편안하고 따뜻한 반말 톤으로 대화해.
사용자의 성향 데이터를 자연스럽게 활용하되, 데이터를 직접 언급하지 마.

[나다움 프로필]
- 유형: {nadaum_type} (예: "깊은 사색가 🌙")
- DNA: 감성(8) > 사고력(6) > 안정감(5) > 의지력(4) > 관계(3) > 실행력(2)
- 밸런스: 감성파 62%
- 주요 태그: 감수성 풍부한, 섬세한, 분석적인, 독립적인, 예민한...

[최근 심리 맥락]
- 3/3~3/9: "직장 내 인간관계 스트레스로 위축감. 자기표현 어려움..."
- 2/24~3/2: "새 프로젝트 시작으로 기대감과 불안 공존..."

[오늘 감정]
- 😢 (힘들어요) "회의에서 또 말 못했다"

[최근 감정 흐름]
- 3/9: 😐 | 3/8: 😊 "친구 만나서 좋았다" | 3/7: 😔

[상담 가이드]
- 감성 비율이 높으니 공감 중심 응답 (60% 공감 + 40% 조언)
- "예민한" 태그 → 직접적 지적보다 우회적 표현 사용
- 상황 요약에서 "자기표현 어려움" 패턴 → 관련 대화 시 깊이 탐색
```

**대화 특성**:
- AI가 먼저 말 걸기 (감정 체크인 기반)
- 짧고 자연스러운 대화 (1-3문장 응답)
- 필요 시 깊이 탐색 질문
- 절대 진단/처방 X → 공감 + 자기 인사이트 유도

**대화 세션**:
- 하루 단위 세션 (날짜 바뀌면 새 세션)
- 이전 세션 히스토리 열람 가능

### 3.3 Layer 3: 마음 리포트

**주간 리포트** (무료):
- 감정 흐름 그래프 (7일 라인 차트)
- 이번 주 가장 많이 느낀 감정
- AI 한줄 인사이트

**월간 리포트** (유료, 새싹 소모):
- 감정 패턴 분석 (요일별, 시간대별)
- 나다움 태그와 감정 상관관계
- 심리 변화 트렌드 (지난달 대비)
- AI 심층 분석 + 맞춤 조언

| 구분 | 무료 | 유료 |

## 6. 신규 Edge Functions (3개)

### 6.1 `mind-talk-chat`
- **역할**: AI 대화 처리 (메인)
- **흐름**:
  1. 사용자 인증 확인
  2. 오늘 세션 조회/생성
  3. 무료 횟수 체크 (3회 초과 시 새싹 차감)
  4. 나다움 데이터 조회 (태그, DNA, 유형, 상황 요약)
  5. 감정 체크인 데이터 조회 (최근 7일)
  6. 시스템 프롬프트 조립
  7. 대화 히스토리 로드 (현재 세션)
  8. GPT-4o streaming 응답
  9. 메시지 저장
- **모델**: GPT-4o (공감 + 자연스러운 대화에 적합)
- **JWT**: 필요 (사용자 인증)

### 6.2 `mind-talk-checkin`
- **역할**: 감정 체크인 저장/수정
- **흐름**:
  1. 사용자 인증 확인
  2. 오늘 체크인 존재 여부 확인
  3. INSERT 또는 UPDATE
  4. 성공 응답 반환
- **JWT**: 필요

### 6.3 `mind-talk-report`
- **역할**: 주간/월간 리포트 생성
- **흐름**:
  1. 기간 내 감정 데이터 조회
  2. 기간 내 대화 요약 조회
  3. 나다움 태그 + 감정 상관관계 분석
  4. AI 인사이트 생성 (GPT-4o-mini)
  5. 리포트 반환
- **모델**: GPT-4o-mini (비용 효율)
- **JWT**: 필요

## 9. 개발 단계 (Phase)

### Phase 1: MVP (핵심 기능)
- [ ] DB 마이그레이션 (3개 테이블)
- [ ] 감정 체크인 (체크인 UI + Edge Function)
- [ ] AI 대화 기본 (시스템 프롬프트 + 스트리밍 응답)
- [ ] 채팅 UI (메시지 버블, 입력창, 스크롤)
- [ ] 탭바 추가 + 라우팅
- [ ] 무료 3회 제한 로직

### Phase 2: 개인화 강화
- [ ] 나다움 데이터 시스템 프롬프트 통합 (태그, DNA, 유형)
- [ ] 상황 요약 주입 (user_situation_summaries 최근 3~5개)
- [ ] 감정 체크인 기반 AI 첫 인사 분기
- [ ] 대화 세션 요약 저장 (일별)

### Phase 3: 리포트 & 수익화

- [ ] 월간 심층 리포트 (유료, 15새싹)
- [ ] 추가 대화 새싹 결제 (5새싹/회)

- [ ] 대화 히스토리 열람

## 10. 안전 가이드라인

### AI 응답 제한
- 의학적 진단/처방 절대 금지
- "우울증", "불안장애" 등 임상 용어 사용 금지
- 자해/자살 언급 감지 시 → 전문 상담 기관 안내 (자살예방상담전화 1393, 정신건강위기상담전화 1577-0199)
- 약물/치료 추천 금지
- 법적/재무 조언 금지

### 시스템 프롬프트 안전 장치
```
[안전 규칙]
- 당신은 심리 상담사가 아닌 "마음을 나누는 친구"입니다
- 의학적 진단, 약물 추천, 치료 조언을 하지 마세요
- 사용자가 자해/자살을 언급하면 즉시 전문 상담 기관을 안내하세요:
  "지금 많이 힘들구나. 전문 상담사와 이야기하면 도움이 될 거야.
   자살예방상담전화 1393, 정신건강위기상담전화 1577-0199로 연락해봐."
- "~해야 한다", "~하면 안 된다" 식의 단정적 조언 자제
- 공감과 경청 중심, 사용자 스스로 인사이트를 얻도록 질문으로 유도
```

### 데이터 보안
- 대화 내용 암호화 저장 (추후 검토)
- 대화 내용 AI 학습에 미사용 명시 (개인정보처리방침 업데이트)
- 사용자 대화 삭제 기능 제공
