# 미래 예측기 비즈니스 전략서

> **작성일**: 2026-03-18
> **현재 상태**: 8단계 플로우 구현 완료 (QA 진행 중)
> **목표**: 일회성 운세 기능 → 누적형 인생 시뮬레이터로 진화
> **핵심 프레임워크**: 7대 본능 결합 × Hook Model × Lock-in

---

## 1. 현재 진단

### 1-1. 건드리고 있는 본능

| 본능 | 현재 작동 방식 | 강도 |
|------|--------------|------|
| 오만 (Pride) | "나는 이런 사람이다" 자아 확인, 네뷸러 그래프의 시각적 임팩트 | ★★☆ |
| 나태 (Sloth) | AI가 알아서 분석, 5분이면 결과 확인 | ★★☆ |
| 음욕 (Lust) | 연애 카테고리 존재 | ★☆☆ |

### 1-2. 치명적 부재 요소

| 부재 요소 | 문제점 | 비즈니스 영향 |
|----------|--------|-------------|
| **시기 (소셜)** | 혼자 보고 끝, 공유 동기 없음 | 바이럴 제로, CAC 높음 |
| **탐욕 (이득)** | "이걸 보면 내 인생에 뭐가 달라지는데?" 답 없음 | 유료 전환 동기 부재 |
| **Lock-in** | 한 번 보고 끝, 재방문 이유 없음 | LTV 극도로 낮음 |
| **Escalation** | 무료→유료 자연스러운 상승 경로 없음 | 매출 구조 부재 |
| **시간축** | 스냅샷 1장, 변화 추적 불가 | 반복 사용 동기 없음 |

### 1-3. 근본 문제

> **운세 서비스의 구조적 한계**: 한 번 보고 끝.
> 이 문제를 해결하지 않으면 어떤 수익 모델을 붙여도 지속되지 않는다.

현재 온톨로지 그래프가 핵심 자산인데, **한 번 생성하고 localStorage에 저장한 뒤 버리고 있음**.
이걸 **시간과 함께 축적되는 자산**으로 전환하는 것이 전략의 출발점이다.

## 2. 진화 전략: 3개 레이어

### Layer 1. 시간축 도입 — "일회성 점술"에서 "인생 시뮬레이터"로

#### 컨셉

```
[현재 — 스냅샷 모델]
태그 선택 → 온톨로지 1회 생성 → 결과 보기 → 끝

[진화 — 누적 모델]
1월: 직장 예측 → 온톨로지 v1 저장 (12노드)
2월: 연애 예측 → 기존 노드에 추가 → 온톨로지 v2 (20노드)
3월: 재물 예측 → 또 추가 → 온톨로지 v3 (28노드)
6월: → 온톨로지 v6 (45노드, 80+ edges)
         ↓
  시간이 갈수록 "나만의 인생 지도"가 정교해짐
  = 떠날 수 없는 구조 (Lock-in)
```

#### 구체적 설계

| 요소 | 설명 | 저장 |
|------|------|------|
| **나의 온톨로지 (My Ontology)** | 회원 DB에 누적 저장, 프로필에서 항시 열람 | `user_ontology` 테이블 |
| **노드 성장** | 예측할 때마다 노드 추가, 기존 노드 간 새 edge 발견 | `ontology_nodes`, `ontology_edges` |
| **시간 레이어** | "3개월 전의 나" vs "지금의 나" 그래프 비교 | `ontology_snapshots` |
| **정확도 피드백** | "지난달 예측이 맞았나요?" → AI 학습 → 다음 예측 정교화 | `prediction_feedback` |
| **성장 지표** | 노드 수, 연결 밀도, 탐색한 카테고리 수 시각화 | 프론트엔드 계산 |

#### 건드리는 본능

- **오만**: "내 인생 지도는 이렇게 복잡하고 깊다" — 노드가 많을수록 자부심
- **나태**: AI가 과거 데이터를 기억하고 알아서 연결해줌
- **탐욕**: "더 정확한 예측 = 더 나은 의사결정 = 인생 이득"

### Layer 2. 소셜 레이어 — 시기심 엔진

현재 가장 큰 구멍. **혼자 보는 운세는 바이럴이 안 된다**.

#### 2-1. 유형 카드 + 희소성 (오만 + 시기)

```
예측 결과에서 유형을 부여:
  "당신은 '폭풍전야의 전략가' 타입입니다"
  → 공유 카드 이미지 자동 생성
  → "이 유형은 전체 사용자 중 3.2%만 해당합니다"
```

| 요소 | 역할 | 본능 |
|------|------|------|
| 유형 이름 (멋진 네이밍) | 정체성 부여 | 오만 — "나는 특별하다" |
| 희소성 퍼센트 | 차별화 강조 | 오만 + 시기 — "상위 3%라니" |
| 공유 카드 (인스타/카톡) | 본 사람이 "나도 해봐야지" | 시기 — FOMO 유발 |
| 카테고리별 유형 수집 | 4개 카테고리 × 각각 유형 | 수집욕 — 컴플리트 욕구 |

**공유 카드 스펙**:
- 1080×1080 또는 1080×1920 (인스타 스토리)
- 다크 그라데이션 배경 + 네뷸러 그래프 미니 시각화
- 유형 이름 + 핵심 특성 3줄 + 희소성 퍼센트
- 나다운세 로고 + QR/링크

#### 2-2. 궁합 시뮬레이션 (시기 + 음욕)

```
나의 온톨로지 ←→ 상대방 온톨로지
        ↓
  두 그래프를 겹쳐서 시각화
  → 겹치는 노드 = 공명점 (초록)
  → 충돌하는 노드 = 마찰점 (빨강)
  → "이 관계의 미래 시나리오" AI 생성
```

**바이럴 메커니즘**:
1. A가 궁합 분석 요청
2. B에게 초대 링크 전송 (카카오톡)
3. B가 미래 예측기를 직접 완료해야 궁합 결과 열림
4. B도 자신의 결과를 받음 → B가 C에게 궁합 요청 → 연쇄 확산

**궁합 종류**:
| 유형 | 대상 | 주요 본능 |
|------|------|----------|
| 연애 궁합 | 연인/썸 | 음욕 + 시기 |
| 우정 궁합 | 친구 | 시기 + 오만 |
| 비즈니스 궁합 | 동료/파트너 | 탐욕 + 분노 |

#### 2-3. 예측 적중률 공개 (탐욕 + 오만)

```
"지난달 재물 예측 적중률: 78%"
"직장 카테고리 전체 유저 평균 적중률: 62%"
"당신의 적중률은 상위 15%입니다"
```

- 적중률 높으면 → 자랑하고 싶음 (오만) → 공유
- 적중률 낮으면 → 더 정교한 분석 원함 → 유료 전환 동기
- 적중률 자체가 매월 변하므로 → 재방문 동기 (Variable Reward)

### Layer 3. 수익 모델 — PAS 공식 적용

#### 3-1. 무료→유료 전환의 심리 설계

```
┌─ Problem (문제 인식) ──────────────────────────────┐
│                                                   │
│  무료 결과를 보여줌                                 │
│  "당신의 직장 미래에 '정체기 리스크'가 감지됨"        │
│  네뷸러 그래프에서 위험 노드를 빨간색으로 강조        │
│                                                   │
├─ Agitation (증폭) ────────────────────────────────┤
│                                                   │
│  간극 분석(Gap)에서 구체적 수치로 증폭               │
│  "성격 기반 예측 vs 사주 기반 예측의 괴리: 34%"      │
│  "이 괴리를 방치하면 6개월 내 번아웃 가능성 ↑"       │
│  "유사 유형 사용자 중 72%가 실제로 전환점 경험"       │
│                                                   │
├─ Solution (해결) ─────────────────────────────────┤
│                                                   │
│  "맞춤 대응 전략 리포트"                            │
│  → 이 간극을 줄이는 월별 행동 가이드                 │
│  → 구체적 실천 항목 + 체크리스트                     │
│  → "지금 3,900원에 받아보기"                        │
│                                                   │
└───────────────────────────────────────────────────┘
```

**핵심**: 무료 결과가 "불완전하다"가 아니라 "위험 신호를 발견했다"로 프레이밍.
문제를 만드는 게 아니라, 이미 존재하는 불안을 **언어화**해주는 것.

#### 3-2. 수익 구조 (Tier 설계)

| Tier | 가격 | 내용 | 타겟 본능 | 전환 트리거 |
|------|------|------|----------|-----------|
| **무료** | 0원 | 전체 8단계 + 기본 결과 + 유형 카드 | 나태 (쉽게 체험) | — |
| **딥 리포트** | 3,900원 | 맞춤 대응 전략 + 월별 행동 가이드 | 분노 (문제 해결) + 탐욕 (인생 이득) | Gap 분석 후 PAS |
| **궁합 분석** | 2,900원 | 두 사람 온톨로지 겹침 + 관계 시나리오 | 음욕 + 시기 | 궁합 요청 시 |
| **월간 추적** | 4,900원/월 | 매월 온톨로지 업데이트 + 적중률 추적 + 리포트 | Lock-in + Escalation | 2회차 예측 시 |
| **프리미엄 유형** | 9,900원 | GPT-4o 고급 모델 + 30페이지 PDF 리포트 | 오만 (프리미엄 = 특별함) | 유형 카드에서 업셀 |

#### 3-3. 구독의 핵심: "떠나면 잃는 것" 설계

```
구독 중:
  ✅ 온톨로지 매월 자동 성장
  ✅ 적중률 추적 + 히스토리
  ✅ 월간 맞춤 리포트
  ✅ 궁합 분석 무제한
  ✅ 프리미엄 유형 카드

구독 해지 시:
  ⚠️ "3개월간 쌓인 예측 데이터와 적중률 기록이 동결됩니다"
  ⚠️ "온톨로지 성장이 멈추고, 다음 달 예측 정확도가 떨어집니다"
  → 전환비용 발생 (Lock-in)
  → 데이터는 삭제하지 않음 (재구독 시 복원 = 복귀 장벽 낮춤)
```

## 3. Hook Model 설계

```
┌─ Trigger ─────────────────────────────────────────────┐
│                                                       │
│  External Trigger:                                    │
│    • 매월 1일 푸시: "이번 달 운세 업데이트 준비됨"       │
│    • 카카오 알림톡: "지난달 예측 적중률 공개"            │
│    • 친구 궁합 초대 알림                                │
│                                                       │
│  Internal Trigger (습관 형성 후):                       │
│    • 불안한 일이 생기면 → 나다운세 열기                  │
│    • 새로운 관계가 시작되면 → 궁합 분석                  │
│    • 월초/분기초 → "이번 달은 어떨까?"                   │
│                                                       │
├─ Action ──────────────────────────────────────────────┤
│                                                       │
│  태그 선택 → 테스트 → 결과 확인 (5분)                   │
│  기존 온톨로지가 있으면 더 빠름 (3분)                    │
│  나태 본능 충족: 쉽고 빠르고 예쁨                        │
│                                                       │
├─ Variable Reward ─────────────────────────────────────┤
│                                                       │
│  Tribe (소속감):                                       │
│    • 유형 커뮤니티, 같은 유형 사용자 수                  │
│  Hunt (정보 사냥):                                     │
│    • 매번 다른 온톨로지 그래프 (예측 불가능)              │
│    • 지난달 적중률 공개 (맞았을 때 도파민)                │
│  Self (자기 성취):                                     │
│    • 온톨로지 노드 성장 시각화                           │
│    • 새로운 유형 이름 부여 (슬롯머신 효과)                │
│                                                       │
├─ Investment ──────────────────────────────────────────┤
│                                                       │
│  • 온톨로지 노드 축적 (데이터) — 쓸수록 정교해짐         │
│  • 적중률 히스토리 (성과) — 쌓을수록 의미 있어짐          │
│  • 유형 컬렉션 (수집) — 4카테고리 컴플리트 욕구           │
│  • 궁합 관계 맵 (관계) — 인간관계 자산                   │
│  → 투자할수록 떠나기 어려워짐                            │
│                                                       │
└───────────────────────────────────────────────────────┘
```

## 4. 본능 결합 맵 — 미래 예측기 전용

### 현재 → 진화 후 비교

```
[현재]                          [진화 후]
오만 ★★☆                       오만 ★★★ (유형 카드, 희소성, 노드 성장)
시기 ☆☆☆                       시기 ★★★ (공유 카드, 궁합, 랭킹)
분노 ☆☆☆                       분노 ★★☆ (Gap 분석 → 문제 해결 동기)
나태 ★★☆                       나태 ★★★ (AI 기억, 더 빠른 재분석)
탐욕 ☆☆☆                       탐욕 ★★☆ (적중률 → 의사결정 이득)
탐식 ☆☆☆                       탐식 ☆☆☆ (해당 없음)
음욕 ★☆☆                       음욕 ★★★ (궁합 시뮬레이션)
```

### 기능별 본능 교차 매트릭스

| 기능 | 오만 | 시기 | 분노 | 나태 | 탐욕 | 음욕 | 본능 수 |
|------|------|------|------|------|------|------|--------|
| 기본 예측 (무료) | ● | | | ● | | | 2 |
| 유형 카드 + 공유 | ● | ● | | | | | 2 |
| 궁합 시뮬레이션 | | ● | | | | ● | 2 |
| Gap 간극 분석 | | | ● | | ● | | 2 |
| 딥 리포트 (유료) | ● | | ● | ● | ● | | 4 |
| 월간 추적 (구독) | ● | ● | | ● | ● | | 4 |
| 적중률 시스템 | ● | ● | | | ● | | 3 |

> **4개 본능 교차 = 메가 기능**: 딥 리포트와 월간 추적이 가장 강력한 수익 엔진.

## 5. 모방 욕망 (Mimetic Desire) 활용 전략

### 모방 모델 설계

```
[1단계] 유형 카드가 SNS에 공유됨
         ↓
[2단계] 본 사람: "저건 뭐지? 나도 해볼까?" (욕망 전염)
         ↓
[3단계] 직접 체험 → 자신의 유형 카드 생성
         ↓
[4단계] 본인도 공유 → 연쇄 확산
         ↓
[5단계] 희소한 유형일수록 → "나도 저 유형이고 싶다" (경쟁)
         ↓
[6단계] 태그를 더 많이 선택 → 프리미엄 분석 → 유료 전환
```

### 인플루언서 시딩 전략

| 단계 | 행동 | 기대 효과 |
|------|------|----------|
| 시딩 | 타로/MBTI 인플루언서에게 프리미엄 유형 카드 제공 | 초기 모방 모델 배치 |
| 확산 | "이 유형은 0.8%만 해당" 희소성 강조 | 시기심 자극 → 체험 유도 |
| 전환 | 궁합 분석으로 팔로워 참여 유도 | 바이럴 루프 완성 |

## 6. Lock-in + Escalation 구조

### 전환비용 설계

```
사용 1회차:
  → 온톨로지 12노드, 유형 1개
  → 전환비용: 낮음 (떠나도 아깝지 않음)

사용 3회차:
  → 온톨로지 28노드, 유형 3개, 적중률 데이터 시작
  → 전환비용: 중간 ("3달치 데이터가 아깝긴 한데...")

사용 6회차:
  → 온톨로지 45노드, 유형 4개 컴플리트, 적중률 6개월 추적
  → 전환비용: 높음 ("이건 나만의 인생 지도인데 버릴 수 없어")

사용 12회차:
  → 1년치 인생 데이터, 궁합 관계 맵, 계절별 패턴 분석
  → 전환비용: 극높음 (사실상 이탈 불가)
```

### Escalation 경로

```
무료 체험 (0원)
  ↓ "더 정밀한 분석이 궁금하다"
딥 리포트 1회 구매 (3,900원)
  ↓ "매번 사는 것보다 구독이 낫겠다"
월간 추적 구독 (4,900원/월)
  ↓ "연간으로 하면 할인되나?"
연간 구독 (39,900원/년, 32% 할인)
  ↓ "프리미엄 리포트도 받아보고 싶다"
프리미엄 플랜 (7,900원/월)
```

## 7. 수익 시뮬레이션

### 가정

| 지표 | 수치 | 근거 |
|------|------|------|
| 월 신규 유저 (무료) | 5,000명 | 유형 카드 바이럴 기반 |
| 딥 리포트 전환율 | 5% | PAS 흐름 최적화 시 |
| 궁합 구매율 | 8% | 궁합 = 2인 이상 참여, 높은 동기 |
| 월간 구독 전환율 | 2% | 3회차 이상 사용자 대상 |
| 월간 구독 유지율 | 70% | Lock-in 구조 기반 |

### 월 매출 추정 (안정기 기준)

| 항목 | 계산 | 월 매출 |
|------|------|--------|
| 딥 리포트 | 5,000 × 5% × 3,900원 | 975,000원 |
| 궁합 분석 | 5,000 × 8% × 2,900원 | 1,160,000원 |
| 월간 구독 (누적) | 300명 × 4,900원 | 1,470,000원 |
| 프리미엄 유형 | 5,000 × 1% × 9,900원 | 495,000원 |
| **합계** | | **약 410만원/월** |

> 구독자가 누적되므로 6개월 후 구독 매출만 월 500만원+ 가능.
> 바이럴이 성공하면 신규 유저 × 2~5배 → 매출 비례 성장.

## 8. 우선순위 로드맵

### Phase 1: 바이럴 기반 구축 (1~2주)

| 순서 | 작업 | 본능 | 난이도 | 매출 기여 |
|------|------|------|--------|----------|
| 1-1 | 유형 카드 이미지 생성 (Canvas → PNG) | 오만 + 시기 | 중 | 간접 (바이럴) |
| 1-2 | 카카오톡/인스타 공유 버튼 | 시기 | 하 | 간접 (바이럴) |
| 1-3 | 희소성 퍼센트 표시 (유형별 사용자 비율) | 오만 | 하 | 간접 (바이럴) |

### Phase 2: 첫 매출 (2~3주)

| 순서 | 작업 | 본능 | 난이도 | 매출 기여 |
|------|------|------|--------|----------|
| 2-1 | 딥 리포트 유료화 (PAS 흐름 + 결제) | 분노 + 탐욕 | 중 | 직접 |
| 2-2 | 프리미엄 유형 (GPT-4o 모델 업그레이드) | 오만 | 중 | 직접 |
| 2-3 | 온톨로지 DB 누적 저장 (localStorage → Supabase) | Lock-in | 중 | 간접 (유지) |

### Phase 3: 바이럴 폭발 (3~4주)

| 순서 | 작업 | 본능 | 난이도 | 매출 기여 |
|------|------|------|--------|----------|
| 3-1 | 궁합 시뮬레이션 (초대 링크 + 결과) | 음욕 + 시기 | 상 | 직접 + 바이럴 |
| 3-2 | 궁합 초대 카카오 알림톡 연동 | 시기 | 중 | 바이럴 |

### Phase 4: 반복 매출 (4~6주)

| 순서 | 작업 | 본능 | 난이도 | 매출 기여 |
|------|------|------|--------|----------|
| 4-1 | 월간 추적 구독 상품 | Lock-in + Escalation | 상 | 직접 (MRR) |
| 4-2 | 적중률 피드백 시스템 | 탐욕 + 오만 | 상 | 간접 (재방문) |
| 4-3 | 시간 레이어 (과거 그래프 비교) | 오만 | 중 | 간접 (유지) |

### Phase 5: 성장 가속 (6주+)

| 순서 | 작업 | 본능 | 난이도 | 매출 기여 |
|------|------|------|--------|----------|
| 5-1 | 연간 구독 + 할인 | 탐욕 | 하 | 직접 (선결제) |
| 5-2 | 유형 컬렉션 (4카테고리 컴플리트 배지) | 오만 | 중 | 간접 (반복 사용) |
| 5-3 | 인플루언서 시딩 프로그램 | 시기 (모방 욕망) | 중 | 바이럴 |

## 10. 리스크와 대응

| 리스크 | 영향 | 대응 |
|--------|------|------|
| "운세는 한 번이면 충분" 인식 | 재방문율 저조 | 시간축 + 적중률로 "변화 추적" 가치 강조 |
| 유료 전환 거부감 | 매출 부진 | 무료 가치를 충분히 제공한 뒤, PAS로 자연스럽게 전환 |
| 궁합 초대 무시 | 바이럴 실패 | 초대 메시지 A/B 테스트 + 카카오 알림톡 활용 |
| AI 비용 증가 | 마진 악화 | 기본은 GPT-4.1-nano 유지, 프리미엄만 GPT-4o |
| 적중률이 낮으면 신뢰 하락 | 이탈 | "적중률"보다 "자기 이해도"로 프레이밍 전환 |
