## 설계 원칙

| 원칙 | 적용 |
|------|------|
| **운명론 진입 → 행동 전환** | Ch4 타이밍 가이드로 "언제"를 만족시킨 후 Ch5에서 "어떻게"로 전환 |
| **간극 = 핵심 훅** | 무료에서 간극을 보여주고, 유료에서 간극을 메우는 구조. 간극 수치가 보고서 전체를 관통 |

## 결제 전까지 유저 감정 흐름

```
설문 5개  → "나는 이런 사람이구나" (자기인식)
태그 선택 → "내 성향이 구체화되네" (몰입)
결과 페이지 → "미래가 이렇게 흘러갈 수 있구나" (기대/불안)
사주 입력 → "내 사주는 이런 흐름이구나" (운명론 충족)
간극 시각화 → "심리적 나 vs 사주적 나가 이렇게 다르다고?" (문제 심화, 불안 극대화)
대책 보고서 미리보기 → "해결책이 있긴 하네" (기대감)
결제 → "내 미래를 바꿀 수 있다면" (행동 전환)
```

**결제 후 보고서 역할**: 간극을 메우는 구체적 로드맵 = 해결의 카타르시스

### 유형 네이밍 체계 (카테고리별)

각 카테고리에서 심리 축 + 사주 흐름 조합으로 유형명 자동 생성.

| 카테고리 | 유형 예시 | 조건 |
|---------|----------|------|
| 연애 | 불안형 몽상가 | 감성 高 + 사주 흐름 中 + 간극 大 |
| 연애 | 안정형 현실주의자 | 감성 中 + 사주 흐름 高 + 간극 小 |
| 재물 | 소극적 잠재부자 | 진실성 高 + 재성 有 + 간극 中 |
| 학업 | 실행력 있는 합격자 | 실행력 高 + 인성 有 + 간극 小 |
| 직장 | 불만형 잠재이직자 | 사고력 高 + 관성 弱 + 간극 大 |

→ **AI가 프로파일 기반으로 동적 생성** (프롬프트에 유형명 생성 규칙 포함)

## Chapter 2. 심리 vs 사주, 왜 다른가

간극 시각화에서 "28% 차이나네요"만 보여줬다면, 여기서는 **왜 차이가 나는지** 해부.

### 구성

```
┌─────────────────────────────────────────┐
│  💡 간극의 원인 분석                      │
│                                         │
│  ┌─ 심리 분석 ──────────────────────┐   │
│  │ 당신의 태도 테스트에서 [감성] 축이    │   │
│  │ 78점으로 높게 나왔습니다.            │   │
│  │                                      │   │
│  │ 이는 이상적 관계에 대한 기대가        │   │
│  │ 크다는 뜻이며, "완벽한 상대"를        │   │
│  │ 기다리는 경향이 있습니다.             │   │
│  └──────────────────────────────────┘   │
│           ↕ 간극 28%p                    │
│  ┌─ 사주 분석 ──────────────────────┐   │
│  │ 을묘 대운(2024~2033)에서              │   │
│  │ 정재+식신 조합이 활성화되고 있어       │   │
│  │ 안정적 만남의 기운이 서서히            │   │
│  │ 강해지는 흐름입니다.                  │   │
│  │                                      │   │
│  │ → 올해 하반기~내년 상반기 전환기      │   │
│  └──────────────────────────────────┘   │
│                                         │
│  📌 핵심:                                │
│  운의 흐름은 오고 있지만,                 │
│  심리적 벽이 그 기회를 인식하지 못하게     │
│  막고 있을 가능성이 높습니다.             │
└─────────────────────────────────────────┘
```

### 간극 해석 프레임 (AI 프롬프트 가이드)

| 간극 크기 | 해석 톤 | 핵심 메시지 |
|----------|---------|-----------|
| 0~10%p (조화) | 긍정적 확인 | "심리와 운이 같은 방향을 보고 있어요. 흐름을 타세요." |
| 11~25%p (주의) | 경고 + 희망 | "약간의 조율이 필요해요. 의식적 노력으로 충분히 줄일 수 있습니다." |
| 26~50%p (간극) | 문제 제기 + 처방 | "운은 오고 있지만 심리적 벽이 방해하고 있어요. 처방전이 필요합니다." |
| 51~100%p (충돌) | 강한 경고 + 전환 유도 | "완전히 다른 방향을 보고 있어요. 지금이 전환점입니다." |

### 운명론 점수(fatalism_score)에 따른 톤 분기

| fatalism_score | AI 프롬프트 톤 |
|---------------|---------------|
| 高 (0.7+) | "사주 흐름을 타는 법" — 운명론을 수용하되 행동 유도. "대운이 바뀌는 시기에 이렇게 하면 흐름을 탈 수 있다" |
| 中 (0.4~0.7) | 균형 — 사주 해석과 심리 조언을 동등 비중으로 배치 |
| 低 (0.4 미만) | "구체적 실행 계획" — 사주는 참고 수준, 심리학 기반 행동 교정 중심 |

> **fatalism_score**: 태도 테스트 5문항 내 숨은 축으로 측정. 유저에게 라벨로 노출하지 않음.
> 근거: 대화 데이터 분석에서 유저 52.6%가 운명론 패턴 보유, 44%가 운명론+행동지향 동시 보유.

| 시기 유형 | 연애 | 재물 | 학업 | 직장 |
|----------|------|------|------|------|

## Chapter 5. 나만의 행동 처방전

간극을 줄이기 위한 **구체적 행동 3가지**. 보고서의 핵심 가치.

### 구성 원칙

| 처방 번호 | 기반 | 역할 |
|----------|------|------|
| 처방 1 | **심리학 기반** | 행동 교정 (태도 테스트에서 발견된 패턴 타겟) |
| 처방 2 | **사주 기반** | 운명론 충족 + 행동 유도 (대운/세운 에너지 활용법) |
| 처방 3 | **셀프 모니터링** | 서비스 리텐션 연결 (주간 보고서/재측정 유도) |

### 처방전 예시 (연애 카테고리)

```

│  💊 00님을 위한 행동 처방전 3가지         │
│                                          │
│  처방 1. "3회 룰" 적용하기 [심리학]       │
│  ┌──────────────────────────────────┐    │

│  │                                      │    │

│  │ 직감이 너무 빨리 작동합니다.          │    │
│  │                                      │    │

│  │                                      │    │
│  │ 📅 적용 시기: 5월 전환점부터          │    │
│  │ 🎯 목표: 8~9월 절정기까지 유지        │    │
│  └──────────────────────────────────┘    │

│                                          │
```
