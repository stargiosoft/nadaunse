## 1. 바이럴 기능 설계 원칙

### 토스에서 배우는 공식

> **시의성 있는 트렌드 훅 → 유저 유입 → 핵심 서비스로 자연스러운 연결**

토스 '두쫀쿠맵' 사례:
- 1인 개발자가 만든 재고 확인 서비스 → 토스 미니앱으로 **하루 만에 출시**
- 한 달 만에 **MAU 108만** 달성
- 두쫀쿠 재고 확인 → 페이스페이 결제 유도 (할인 쿠폰)
- 출처: https://toss.im/apps-in-toss/blog/dubaicookiemap

### 나다운세 적용 공식

> **공감/호기심 트리거 → 진단/결과 생성 → 예쁜 카드로 공유 → 유료 콘텐츠 전환**

## 2. 우선순위별 바이럴 기능 로드맵

### Tier 1: 즉시 실행 가능 (난이도 낮음, 효과 높음)

#### A. 결과 공유 카드 강화 (스포티파이 Wrapped 스타일)

**벤치마크**: 스포티파이 Wrapped, W컨셉 심리테스트 (2주 18만 플레이)

현재 나다운세에 공유 기능이 있지만, 바이럴을 위해 필요한 것:
- 인스타 스토리에 최적화된 **9:16 세로 카드** 이미지
- "나의 나다움 유형은 ___" 한 줄 + 시각적 아이콘
- 공유 시 자동으로 **nadaunse.com** 링크 포함
- 계절/시즌별 디자인 변경 (벚꽃, 크리스마스 등)

**핵심 지표**: 공유 카드 생성 수, SNS 유입 트래픽

#### B. 화제 콘텐츠 시의성 연동

**벤치마크**: 토스 두쫀쿠맵 (트렌드 속도 = 생명)

실행 예시:
- 대군부인(아이유) 캐릭터 사주 분석 → 드라마 방영 시즌에 맞춰
- BTS 멤버 사주 궁합 → 컴백/공연 시즌에 맞춰
- "내 새끼의 연애2" 출연자 궁합 분석 → 예능 방영일에 맞춰
- 아이돌 생일에 맞춘 "오늘 생일인 사람의 사주 특징"

**핵심**: 트렌드 감지 후 **24시간 이내 콘텐츠 발행**이 관건

### Tier 2: 2~4주 개발 (난이도 중간, 효과 매우 높음)

#### C. 심리테스트형 퀴즈 — "연애 체질 테스트"

**벤치마크**: W컨셉 심리테스트 (2주 18만), 각종 MBTI 테스트

구조:
1. 5~8개 질문 (감정 기반, 빠른 진행)
2. 결과: 사주 오행 기반 연애 유형 (예: "불꽃형 연애체질 🔥")
3. 궁합 매칭 ("나와 잘 맞는 유형은 ___")
4. 공유 카드 자동 생성
5. CTA: "더 자세한 연애운 보기" → 유료 전환

**Threads 인기글에서 검증된 주제**:
- "연애 못하는 사람 특징 N가지" (자가진단형)
- "회피형/불안형 연애 유형" (애착 유형)
- "연애 시장에서 매력 체급" (구조 분석형)

#### D. 연간/반기 운세 리포트 자동 생성

**벤치마크**: 스포티파이 Wrapped, 카카오 이모티콘 연말결산

구조:
- "2026년 상반기 나의 운세 리포트"
- 6장짜리 카드 시퀀스 (연애운/재물운/건강운/인간관계/행운의 달/총운)
- 각 카드 개별 공유 가능
- 연말/반기에 시즌 한정 발행 → 희소성

### Tier 3: 장기 검토 (난이도 높음, 확장성 큼)

#### E. 카카오톡/토스 미니앱

- 카카오톡 안에서 "오늘의 운세" 바로 확인
- 토스 앱인토스 입점 → 3천만 유저 노출
- 로그인 허들 제거 (토스 인증 활용)
- 푸시 알림으로 재방문 유도

#### F. AI 챗봇 연애상담 (Threads/인스타 연동)

- DM으로 사주 정보 입력 → AI 연애 상담
- 결과를 스토리로 공유하면 추가 분석 제공
- 팬덤 연계: "내 최애와의 사주 궁합"

### 검증된 후킹 공식 4가지

| 패턴 | 공식 | 나다운세 적용 |
|------|------|-------------|
| **숫자 권위** | "N명 상담해봄 → 깨달은 것" | "AI가 10만명 분석한 연애운 패턴" |
| **자가진단 리스트** | "~하는 사람 특징 N가지" | "올해 연애운 터지는 사주 특징 5가지" |

| 플랫폼 | 연애 우세 배율 | 시사점 |
|--------|--------------|--------|
| Google Trends | 5배 | 검색 관심도 기준 |
| 유튜브 조회수 | **23배** | 실제 소비 기준 가장 정직한 지표 |

## 7. 바이럴 케이스 스터디 (해외)

### A. 16Personalities / MBTI Chemistry Quiz
- **개요**: 16가지 성격유형 테스트 + 궁합 비교
- **바이럴 원리**: 정체성 표현("나는 이런 사람") + 2인 루프(상대 MBTI 필요 → 테스트 유도)
- **공유 메커니즘**: 결과 카드 스크린샷 → 인스타 스토리/틱톡/트위터 바이오
- **규모**: 누적 10억+ 테스트, 월 1,590만 방문
- **나다운세 시사점**: 사주 기반 유형 카드를 MBTI처럼 "한 장짜리 정체성 카드"로 만들면 동일 효과

### B. "How Well Do You Know Me?" 퀴즈 (BuddyMeter, FriendQuiz)
- **개요**: 내가 10개 질문에 답 → 링크 공유 → 친구가 맞추기 → 점수 리더보드
- **바이럴 원리**: **제품 자체가 공유 없이 작동 불가** (강제 바이럴 루프)
- **공유 메커니즘**: 고유 URL 생성 → 카톡/인스타 스토리로 전파 → 친구가 자기 퀴즈도 생성 → 체인 반응
- **규모**: TikTok #FriendshipQuiz 5억+ 조회
- **나다운세 시사점**: "내 사주를 얼마나 아는지" 퀴즈 → 친구에게 링크 공유 → 친구도 자기 사주 보게 유도

### C. 36 Questions to Fall in Love (NYT)
- **개요**: 심리학 연구 기반, 점점 깊어지는 36개 질문으로 친밀감 형성
- **바이럴 원리**: 저항 불가 헤드라인("누구와든 사랑에 빠지는 법") + 실제 연구 기반 신뢰도 + 체험자 후기
- **규모**: NYT 2015년 최다 공유 기사 중 하나, 10년 지나도 여전히 회자
- **나다운세 시사점**: "사주로 보는 우리 사이 36가지 질문" — 커플/썸 타는 사이에서 공유

### D. Bird Test (틱톡)
- **개요**: 파트너에게 "오늘 새 봤어" 같은 사소한 말을 하고 반응 촬영. Gottman의 "관계 신호" 연구 기반
- **바이럴 원리**: 누구나 즉시 실행 가능 + 합격/불합격 긴장감 + 심리학 근거
- **규모**: 원본 영상 5,600만 조회
- **나다운세 시사점**: "사주로 보는 파트너 반응 테스트" — 간단한 챌린지 포맷

### E. Love Language Test (5가지 사랑의 언어)
- **개요**: 신체 접촉/칭찬/봉사/시간/선물 중 나의 사랑 언어 진단
- **바이럴 원리**: 감정적 니즈에 이름을 붙여줌 → "그래서 내가 서운했구나" 깨달음
- **공유 메커니즘**: 결과 퍼센티지 스크린샷 → 파트너/친구와 비교
- **규모**: TikTok #lovelanguages 3.18억+ 조회
- **나다운세 시사점**: 사주 오행 기반 "나의 사랑 언어" 진단 → 기존 프레임워크 차용 + 사주 차별화

### F. Dating Wrapped (스포티파이 Wrapped 패러디)
- **개요**: 올해 연애 요약 — 첫 만남 횟수, 고스팅 당한 횟수, 최악의 데이트 등
- **바이럴 원리**: 자조적 유머 + Wrapped 포맷 차용 + FOMO
- **규모**: TikTok #DatingWrapped 1,030만+ 조회, NBC/BuzzFeed 보도
- **나다운세 시사점**: "2026 상반기 나의 운세 Wrapped" — 이미 Tier 2에 기획된 기능과 정확히 일치

### G. Red Flag / Green Flag / Beige Flag
- **개요**: 연애 위험 신호/좋은 신호/애매한 신호를 이모지 깃발로 표현
- **바이럴 원리**: 누구나 참여 가능 + 논쟁 유발 + 유머
- **나다운세 시사점**: "사주로 보는 내 연애 레드플래그 3가지" → SNS 콘텐츠화

### H. Pop the Balloon or Find Love

## 8. 바이럴 케이스 스터디 (국내)

### A. Vonvon (봉봉)
- **개요**: 페이스북 퀴즈 플랫폼. "페이스북에서 가장 많이 쓴 단어" 등
- **바이럴 원리**: 개인화된 결과(내 데이터 기반) + 호기심 갭 + 자동 타임라인 공유
- **규모**: "가장 많이 쓴 단어" 퀴즈 **5일 만에 1,750만 유저**. 누적 2억+ 상호작용
- **나다운세 시사점**: 한국에서 퀴즈형 바이럴이 얼마나 폭발적일 수 있는지의 벤치마크

### B. Ktestone (케이테스트) — 퍼스널 컬러 테스트
- **개요**: 12개 질문 → 나를 대표하는 "성격 색상" 부여. 내부적으로 MBTI 매핑
- **바이럴 원리**: **결과 카드가 예쁨** (90년대 페인트 SW 스타일 UI) → 인스타 스토리에 올리고 싶은 디자인
- **공유 메커니즘**: 스크린샷 → 인스타 스토리. "너 색깔 뭐야?" → 테스트 유도
- **규모**: TikTok #colorpersonalitytest **4.9억 조회**. 한국을 넘어 글로벌 바이럴
- **나다운세 시사점**: ⭐ **가장 직접적인 벤치마크**. "사주 오행 컬러"로 동일 포맷 가능. 결과 카드 디자인이 전부

### C. 방구석연구소 (Banggooso)
- **개요**: 성격 테스트/MBTI 퀴즈/연애 성격 테스트 전문 플랫폼
- **바이럴 원리**: 트렌드에 맞춰 끊임없이 새 테스트 출시 + 카카오톡 공유 최적화
- **나다운세 시사점**: 경쟁자이자 벤치마크. 이들이 못 하는 것 = "실제 사주 데이터 기반" 개인화

### D. Smore (스모어, 구 도다마인드)
- **개요**: 노코드 퀴즈 제작 플랫폼. 브랜드/개인이 바이럴 퀴즈 생성
- **바이럴 원리**: 첫 테스트 "나에게 맞는 대학 스타일" → 네이버 실검 1위
- **규모**: MAU 300만+, 누적 1,100만 유저. **완료율 92%**, CTR 30~40%
- **나다운세 시사점**: Smore에 나다운세 퀴즈를 올리는 것도 채널 전략으로 고려 가능

### E. 이름궁합 테스트
- **개요**: 두 사람 이름 획수로 궁합 퍼센티지 계산 (지락실, 봉봉, 심콩 등)
- **바이럴 원리**: **3초면 끝남**(이름 2개 입력) + 숫자 결과 → "우리 94%래!" → 대화 소재
- **공유 메커니즘**: 결과 스크린샷 → 카톡/인스타 DM. 친구들이 자기 이름+짝사랑 테스트 → 체인
- **나다운세 시사점**: ⭐ 이미 궁합 기능이 있음. 핵심은 **결과를 공유하고 싶게 만드는 카드 디자인**과 **초저마찰 입력**

### F. 밸런스 게임
- **개요**: "코 고는 애인 vs 잠꼬대하는 애인" 양자택일 연애 질문
- **바이럴 원리**: 정답 없음 → 논쟁 유발 → 댓글/대화 폭발. 마라맛(극단적) 버전이 더 바이럴
- **공유 메커니즘**: 커플/친구가 플레이하는 영상 → 틱톡/인스타. 리액션이 콘텐츠
- **나다운세 시사점**: "사주로 보는 연애 밸런스 게임" — 오행별 다른 질문 세트

## 10. 바이럴 케이스 스터디: 욕망 트리거별 분류

### 🔴 비교/랭킹 ("나는 몇 점이지?")

- **나다운세 시사점**: **"AI x 사주 매력 분석"** — 지적/성적/감성 매력 각각 점수화

## 12. 나다운세 적용: 바이럴 기능 후보

### 🔥 S-Tier: 강제 공유 루프가 내장된 기능

#### ① "내 사주를 얼마나 아는지" 퀴즈
- **구조**: 내 사주 기반 10개 질문 자동 생성 → 고유 URL → 친구에게 공유 → 맞추기
- **바이럴 포인트**: 제품 자체가 공유 없이 작동 불가 (BuddyMeter 공식)
- **유료 전환**: 퀴즈 결과 후 "진짜 내 사주 풀이 보기" CTA
- **개발 난이도**: 중간 (질문 생성 AI + 고유 URL + 점수 시스템)

#### ② 사주 궁합 카드 (초저마찰)
- **구조**: 생년월일 2개만 입력 → 궁합 퍼센티지 + 예쁜 카드 → 공유
- **바이럴 포인트**: 이름궁합의 사주 버전. 3초 입력 → 즉시 결과 → "우리 87%래!"
- **유료 전환**: "상세 궁합 분석 보기" CTA
- **개발 난이도**: 낮음 (기존 궁합 기능 + 공유 카드 디자인만 추가)

### 🔥 A-Tier: 정체성 표현 + 공유 카드

#### ③ 사주 오행 퍼스널 컬러 (Ktestone 공식)
- **구조**: 사주 기반 → "나의 오행 컬러" + 성격 요약 → 예쁜 컬러 카드
- **바이럴 포인트**: Ktestone이 4.9억 조회를 만든 바로 그 공식. 카드가 예뻐야 공유함
- **유료 전환**: "내 오행 컬러로 보는 올해 운세" CTA
- **개발 난이도**: 낮음 (사주 데이터 → 오행 매핑 → 카드 디자인)

#### ④ 연애 체질 유형 카드
- **구조**: 사주 오행 기반 연애 유형 ("불꽃형 🔥", "바다형 🌊" 등) + 잘 맞는 유형
- **바이럴 포인트**: MBTI 16유형처럼 "너 뭐 유형?" 대화 유발
- **유료 전환**: "나의 연애 유형 상세 분석" CTA
- **개발 난이도**: 중간 (유형 체계 설계 + 카드 디자인 + 궁합 매트릭스)

### 🔥 B-Tier: 시즌/이벤트 연동

#### ⑤ "2026 상반기 연애운 Wrapped"
- **구조**: 6장짜리 카드 시퀀스 — 연애 키워드/행운의 달/주의할 달/인연 유형/총평
- **바이럴 포인트**: Wrapped 포맷 검증 완료 (스포티파이, Dating Wrapped)
- **유료 전환**: "하반기 상세 운세" CTA
- **개발 난이도**: 중간 (6장 카드 시퀀스 + 애니메이션)

#### ⑥ 연애 밸런스 게임 (사주 버전)
- **구조**: 오행별 맞춤 밸런스 질문 → 답변 후 "사주로 본 너의 선택 해석"
- **바이럴 포인트**: 논쟁 유발 + 사주 해석 추가 → 기존 밸런스 게임과 차별화
- **유료 전환**: "연애 성향 풀분석" CTA
- **개발 난이도**: 낮음

## 13. 핵심 인사이트 (잊지 말 것)

1. **"검색량 = 관심도" 공식이 붕괴 중** — AI 검색 전환으로 전통 검색량 전반 하락. 관심도 측정은 SNS 언급량 + 유튜브 조회수 + 커뮤니티 활성도를 크로스 체크해야 함.

2. **연애 콘텐츠가 모든 플랫폼에서 압도적** — 유튜브 기준 '성공'의 23배. Threads/디시인사이드에서도 4~8배. 나다운세의 연애운/궁합이 최우선 바이럴 무기.

3. **Threads 인기글의 본질 = 타로/사주 니즈와 동일** — "나는 왜 이런가" + "앞으로 어떻게 될까" = 자기진단 + 미래예측. 이건 나다운세가 하는 것과 정확히 같음.

4. **바이럴 기능의 핵심은 "예쁜 결과 카드 + 공유 버튼"** — W컨셉 2주 18만, 스포티파이 Wrapped 글로벌 바이럴. 복잡한 기능보다 공유하고 싶은 결과 이미지가 핵심.

5. **속도가 곧 바이럴** — 토스 두쫀쿠맵 하루 만에 출시. 트렌드 감지 후 24시간 이내 콘텐츠 발행 체계 구축 필요.

6. **강제 2인 루프가 최강의 바이럴** — Friendship Quiz(틱톡 5억 조회), Paired(800만 DL). 제품이 공유 없이 작동 불가한 구조가 가장 강력한 바이럴.

7. **Ktestone이 가장 직접적 벤치마크** — 한국 발 글로벌 바이럴, 틱톡 4.9억 조회. 핵심은 MBTI를 "컬러"로 리패키징한 것. 나다운세는 사주를 "컬러/유형"으로 리패키징 가능.

8. **ChatGPT가 못 하는 것에 집중** — 일반 연애 조언은 AI가 대체. 사주 데이터 기반 "나에 대한 객관적 진단"은 대체 불가.

9. **숫자를 주면 공유한다** — Photofeeler, ELO, SMV, AI 매력점수. 퍼센타일/점수 형태의 결과는 자랑이든 자조든 반드시 공유됨.

10. **논란 자체가 마케팅** — 아만다(외모 심사), 골드스푼(자산 인증), Tea(전남친 리뷰). 논란이 클수록 미디어 노출 폭발. 사주 티어링은 적절한 논란 유발 가능.

11. **광고 티 나면 플레이 수 절반** — 푸망 데이터: 브랜딩 최소화한 테스트가 2배 더 플레이됨. 사주 테스트도 "나다운세 홍보"가 아닌 "순수한 재미"로 포장해야 함.

12. **자조 유머가 가장 넓게 퍼진다** — He's a 10 but(1억 조회), Dating Wrapped(1,030만). 연애 실패를 웃기게 포장하는 포맷이 가장 공유 저항이 낮음.
