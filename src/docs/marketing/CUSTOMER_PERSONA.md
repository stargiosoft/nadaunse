## 1차 페르소나: 윤하은 (Haeun Yoon) — 10대 후반

### 기본 정보

| 항목 | 내용 |
|------|------|
| **이름** | 윤하은 (Haeun Yoon) |
| **나이** | 18세 (고3) |
| **상황** | 수능을 앞두고 진로 고민 중, 친구 관계도 복잡해지는 시기 |
| **성격** | INFP - 감수성 풍부하고 내면 세계가 깊지만, 밖으로 잘 표현 못 함 |
| **디지털 환경** | 인스타 스토리·릴스, 유튜브 쇼츠, 틱톡이 일상 |

### Bio: "나는 누구지?"가 가장 큰 화두인 나이

**보여지는 모습**
- 친구들 사이에서 조용하지만 센스 있는 애
- 인스타 스토리에 감성 짤·타로 결과 공유
- MBTI, 타로, 성격 테스트 결과를 프로필에 올려둠

**진짜 모습**
- "나는 뭘 좋아하는 사람이지?" 매일 밤 고민
- 친구들은 다 진로를 정한 것 같은데 나만 모르겠는 불안
- 부모님에게 속마음을 말하기 어렵고, 친구에게도 무거운 얘기는 꺼려짐
- SNS에서 본 타로 영상이 신기하게 내 마음을 맞춰서 빠져들게 됨

### Goals

1. **나를 알고 싶다** — "내가 어떤 사람인지, 뭘 잘하는 사람인지 알고 싶어"
2. **불안 해소** — 미래가 막막할 때 "괜찮을 거야"라는 한마디
3. **친구와 공유하는 재미** — 타로 결과 캡처해서 단톡방에 올리는 소소한 즐거움

### Pains

| 구분 | 내용 |
|------|------|
| **정체성 혼란** | 나를 설명하는 언어가 없어서 MBTI·사주에서 답을 찾으려 함 |
| **진로 불안** | 뭘 해야 할지 모르겠는데 시간은 흘러가는 압박감 |
| **표현의 어려움** | 속마음을 털어놓을 곳이 마땅치 않음 (부모님 X, 친구 부담) |
| **경제적 제약** | 용돈이 한정적 → 유료 콘텐츠 결제에 심리적 장벽 높음 |

### 나다운세 이용 패턴

- **진입 경로**: 인스타/틱톡에서 타로·사주 콘텐츠 → 검색 → 나다운세 발견
- **주 이용 시간**: 밤 10시~새벽 1시 (자기 전 혼자만의 시간)
- **핵심 기능**: 무료 운세 → 나다움 분석(DNA) → 마음톡(AI 채팅)
- **공유 행동**: 결과 캡처 → 인스타 스토리·카톡 단톡방 공유
- **결제 장벽**: 무료 콘텐츠 위주, 새싹(소액) 결제는 "이 정도면 괜찮지" 심리

- **충성 요인**: "AI인데 내 마음을 맞추는 느낌", 주간 보고서의 루틴화

## 1020 세대 공통 인사이트

### 왜 운세/사주/타로인가?

Z세대에게 운세는 **"예언"이 아니라 "자기 해석의 도구"**

| 기존 인식 | Z세대의 인식 |
|-----------|-------------|
| 미래를 점치는 것 | 나를 이해하는 체계적 프레임 |
| 미신·비과학 | MBTI처럼 자기탐색의 한 방법 |
| 혼자 몰래 보는 것 | 친구와 공유하는 소셜 콘텐츠 |
| 불안할 때만 찾는 것 | 일상적으로 즐기는 엔터테인먼트 |

### 타로 vs 사주 선호 변화

> "Z세대는 설명을 요구하는 세대" — 위코노미타임스

- 타로: 즉흥적·시각적·리더 직관 의존 → **재미·감성 소비**
- 사주: 구조적·체계적·출생 정보 기반 → **자기탐색·실용 소비**
- 트렌드: 감정 소비 → **자기 탐색**으로 이동, 사주의 "체계적 해석"에 끌림

### 콘텐츠 소비 행태

- **정보 탐색**: 유튜브(66.2%) > SNS(61.7%)
- **공유 문화**: 결과 캡처 → SNS 스토리·단톡방 공유 → 친구와 재해석
- **결제 심리**: 가격 민감하지만 가치 있으면 소액 결제 OK (자기이해 유료 이용 21%)
- **프로모션 반응**: 73.8%가 프로모션으로 구매 경험 → 한정·타임세일 효과적

## 서비스 설계 시 고려사항

### DO (해야 할 것)

- **자기이해 프레임 강화** — "운세"보다 "나다움 발견" 포지셔닝
- 판단하지 않고 있는 그대로를 인정하는 메시지
- 작은 성취를 축하하고 기록하는 기능 (나다움 태그, 새싹 미션)
- **공유 최적화** — 결과를 캡처·공유하고 싶게 만드는 비주얼
- **소액 결제 허들 낮추기** — 새싹 시스템으로 "용돈 수준" 결제 경험
- 혼자만의 시간에 위안이 되는 감성적 UI/UX
- **10대 맞춤 톤앤매너** — 딱딱한 해석이 아닌 친근하고 공감되는 말투

### DON'T (하지 말아야 할 것)

- 타인과 비교하게 만드는 랭킹/순위 시스템
- 완벽해야 한다는 압박을 주는 목표 설정
- 부정적인 운세 결과를 그대로 전달 (반드시 위로/대안 제시)
- 과도한 알림으로 인한 피로감 유발
- **어른 말투·권위적 해석** — 10대가 이탈하는 가장 큰 원인
- **높은 초기 결제 장벽** — 무료 경험 충분히 제공 후 자연스러운 전환
