## 4. 바이럴 설계 원칙

### 4-1. 감정 설계 (바이럴의 핵심)

바이럴은 정보가 아니라 **감정**이 움직일 때 발생한다.

**공유를 부르는 4대 감정**:
1. **공감**: "나만 이런 게 아니었어!" → 나다움 유형 결과 공유
2. **호기심**: "16가지 중 나는 뭘까?" → 유형 테스트 진입
3. **인정욕구**: "나는 이런 사람이야" → 유형 카드 캡처/공유
4. **유머/재미**: "열정 72% 냉정 28%ㅋㅋ" → 밸런스 결과 공유

### 4-2. 행동경제학 기반 전략 (카피 작성 시 필수 적용)

| 전략 | 설명 | 예시 |
|------|------|------|
| **단일 메시지 집중** | 장점 나열 대신 행동 이유 하나만 | "16유형 중 나는 뭘까?" |
| **손실 회피** | 잃는 두려움 자극 | "나도 몰랐던 내 성격의 약점" |
| **구체적 숫자** | 신뢰도 향상 | "16가지 유형", "3초면 끝" |
| **타겟 지목** | 내 이야기처럼 느끼게 | "MBTI에 질린 너" |
| **간편성** | 진입장벽 최소화 | "딱 3초", "사주만 넣으면 끝" |
| **FOMO** | 소외 불안 | "벌써 10만명이 확인한" |
| **인정욕구** | 특별해지고 싶은 심리 | "남들이 모르는 진짜 나" |
| **확실성 효과** | 확실한 보상 제시 | "누구나 받는 무료 분석" |
| **또래 동조** | Z세대 핵심 — 친구가 하면 나도 | "친구들 다 해봤는데 너만 안 했어?" |

### 4-3. 카피 유형 패턴

| 유형 | 용도 | 예시 |
|------|------|------|
| 질문/테스트 유도형 | 진입 유도 | "16유형 중 나는 뭘까?" |
| 비교/경쟁 자극형 | FOMO | "친구들은 이미 유형 공유 중" |
| 문제점 후벼파기형 | 공감 유도 | "나를 제일 모르는 사람이 나였다" |
| 호기심 유발형 | 클릭 유도 | "사주가 다 알고 있었다" |
| 시의성 강조형 | 신선함 | "2026 최신 AI 사주 성격 분석" |
| **또래 공유 유도형** | 바이럴 확산 | "이거 캡처해서 단톡방에 올려봐" |
| **비교 놀이형** | 친구 초대 | "너랑 나랑 유형 비교해보자" |

## 5. 주요 바이럴 콘텐츠 자산

### 5-1. 나다움 유형 카드 (핵심 공유 자산)

16가지 유형별 구성:
- 이모지 + 유형명 + 부제 + 명언(quote)
- 그라디언트 배경 카드 (스크린샷 유도용)

| 유형 예시 | quote |
|-----------|-------|
| 🔥 열정적 리더 | "세상을 바꾸는 건 논리가 아니라 당신의 열정입니다" |
| 🏔️ 믿음직한 실행자 | "당신의 한마디면 모두가 안심합니다" |
| 🦋 감각적 모험가 | "느낌이 맞으면 바로 움직이는 게 당신의 매력" |
| 🎨 감성적 몽상가 | "상상이 현실이 되는 순간을 아는 사람" |

**전체 16유형**: `NadaumAnalysisPage.tsx` → `computeNadaumType()` 참조

### 5-2. 열정/냉정 밸런스

- 열정축: 실행력 + 감성 + 관계 (행동/감정/사람 중심)
- 냉정축: 사고력 + 의지력 + 안정감 (분석/인내/침착 중심)
- 비율에 따른 인사이트 카피 자동 생성
- 바 컬러: 열정(🔥 빨강→주황 그라디언트) / 냉정(🧊 하늘→파랑 그라디언트)

### 5-3. 오행 에너지 분포

- 만세력 API 기반 목/화/토/금/수 비율
- 최고 에너지 기반 한 줄 인사이트
- 예: "토(土) 에너지가 50%로 가장 강해요 — 안정과 신뢰의 중심!"

### 5-4. 나다움 DNA 레이더 차트

- 6축: 실행력, 사고력, 감성, 관계, 의지력, 안정감
- 최고 축 기반 인사이트: "실행력이 가장 높아요 — 생각보다 행동이 먼저!"

- **릴스**: 유형별 특징 숏폼 ("열정적 리더 특징 3가지"), MBTI×사주 조합

- **스토리**: "내 유형은?" 투표/퀴즈 스티커 → 나다운세 링크
- **사용자 공유 유도**: 결과 캡처 → "스토리에 올리고 친구 태그해봐"

## 9. 전환 퍼널 설계 (1020 최적화)

### 10대 퍼널 (용돈 경제)

```
SNS 숏폼 → 무료 나다움 분석 → 유형 카드 캡처·공유 → 친구 유입
                                    ↓
                          마음톡 무료 체험 → 새싹 소액 결제 → 유료 콘텐츠
```

**핵심**: 무료 경험 충분히 제공 → 공유 바이럴로 성장 → 자연스러운 소액 전환

### 20대 퍼널 (자기투자 심리)

```
SNS/검색 → 무료 콘텐츠 → 심화 해석 결제 → 주간 보고서 루틴화 → 지속 이용
                              ↓
                    나다움 분석 → 유료 상세 분석 → 마음톡 심화
```

**핵심**: 무료에서 "더 알고 싶다" 욕구 자극 → 해석 깊이로 유료 전환

### 프로모션 전략

| 전략 | Z세대 반응률 | 적용 |
|------|-------------|------|
| 타임세일 ("오늘만 할인") | 39.2% 반응 | 새싹 충전 한정 보너스 |
| 한정 수량/소진 시 종료 | 높음 | 시즌 한정 유형 카드 |
| 리미티드 에디션 | 높음 | 특별 해석 콘텐츠 |
| 친구 초대 보상 | 높음 | 공유 → 새싹 보상 |

## 10. 카피 작성 체크리스트

카피 작성 시 아래 항목을 점검:

- [ ] "운세" 단어가 포함되어 있지 않은가? (앱 심사 제약)
- [ ] 행동경제학 전략이 1개 이상 적용되었는가?
- [ ] 3초 안에 핵심이 전달되는가?
- [ ] 구체적인 행동(확인, 시작, 해보기)을 유도하는가?
- [ ] **1020 Z세대**의 언어/톤에 맞는가? (딱딱한 존댓말 X)
- [ ] 글자 수 제한을 지키는가? (틱톡 80자, 트위터 160자)
- [ ] **공유하고 싶은 요소**가 있는가? (캡처·태그·비교)
- [ ] 10대가 봐도 진입 장벽이 없는가? (용어·절차 간편)
