# 소셜 키워드 관심도 분석 리포트

> **조사일**: 2026-03-19
> **목적**: '연애' vs '성공' 키워드의 플랫폼별 실제 관심도 비교 + Threads 인기글 후킹 패턴 분석
> **배경**: AI 검색 전환으로 전통 검색량이 전반적으로 감소하는 추세 → 검색량 외 다른 관심도 지표 확보 필요

## 1. 플랫폼별 관심도 종합 비교

| 플랫폼 | 지표 | 연애 | 성공 | 연애 우세 배율 |
|--------|------|------|------|--------------|
| **Google Trends** (한국, 5년) | 검색 관심도 (0~100) | 평균 25 | 평균 4 | **5배** |
| **인스타그램 해시태그** | 누적 게시물 수 | 169만 | 226만 | 0.75배 (성공이 많음) |
| **인스타그램 인게이지먼트** | 최근 15개 평균 좋아요 | ~8 | ~8 | **비슷** |
| **유튜브** (주간 상위 10개) | 총 조회수 | ~350만 | ~15만 | **23배** |
| **Threads** | 최근 20개 총 좋아요 | ~340 | ~87 | **4배** |
| **디시인사이드** | 관련 갤러리 수 | 152개 | 18개 | **8.4배** |
| **디시인사이드** | 대표 갤러리 누적 게시물 | 806만 (연애상담) | 856 (성공) | **9,400배** |

### 핵심 인사이트

- **인스타에서만 '성공'이 우세**한 이유: 자기계발/MLM/네트워크 마케팅 계정이 해시태그를 마케팅 목적으로 대량 사용
- **유튜브에서 격차가 가장 큼** (23배): 조회수 = 실제 소비이므로, 관심도 차이가 가장 정직하게 드러남
- **디시인사이드**: '연애상담' 갤러리 하나만 806만 게시물 → 한국 인터넷에서 가장 활발한 연애 담론 공간

## 3. AI 시대 관심도 측정 — 검색량의 한계와 대안

### 문제: "검색량 = 관심도" 공식의 붕괴

PandaRank 기준 '맛집' 키워드 월 검색량 78.5만회, 전년 대비 **-11.83% 감소**.
피크(2023.07) 대비 약 1/3 수준. AI에게 직접 물어보는 행동이 검색을 대체하는 중.

### 관심도가 분산된 4가지 경로

| "알고 싶다" | "공감하고 싶다" | "사고 싶다" | "보고 싶다" |
|------------|---------------|------------|------------|
| AI에게 질문 (검색량에 안 잡힘) | SNS 언급/인게이지먼트 | 커머스/결제 데이터 | 유튜브 조회수/숏폼 소비 |

### 현실적으로 추적 가능한 대안 소스

| 소스 | 측정 가능한 것 | 한계 |
|------|-------------|------|
| **Google Trends** | 상대적 검색 관심도 추이 | 절대 검색량 아닌 상대지수 |
| **인스타 해시태그** | 누적 게시물 수 (정기 수집 시 증가율 산출) | 마케팅 게시물 노이즈 |
| **유튜브 검색 결과** | 업로드량 + 조회수 | 1회 스냅샷, 추세 보려면 반복 수집 |
| **Threads/X 키워드 검색** | 언급 빈도 + 인게이지먼트 | 검색 API 제한적 |
| **디시인사이드** | 게시물 수 + 댓글 수 | 특정 커뮤니티 편향 |
| **에브리타임** | 대학생 관심도 | 로그인+대학인증 벽 (크롤링 불가) |

## 4. Threads 인기 연애글 후킹 패턴 분석

### 4-1. 주제 분류 (5가지 카테고리)

#### A. "왜 안 되는지" 진단형 — 가장 높은 비중

| 후킹 포인트 | 예시 |
|------------|------|
| "너 이거 해당되지?" → 자기 대입 유도 | "연애 못하는 남자 특징 5가지" |
| 체크리스트 형태 | "남자보는 눈 없는 여자 공통점 11가지" |
| 회피형/불안형 등 애착 유형 | "회피형은 밖에선 좋은 사람, 연인한텐 차가움" |

**왜 잘 먹히나**: 운세/타로 사용자와 심리 구조 동일 — "내가 왜 이런지" 알고 싶은 자기 진단 욕구

#### B. "이렇게 하면 됨" 처방형

| 후킹 포인트 | 예시 |
|------------|------|
| 경험 기반 권위 ("N명 해봄") | "남자 200명 상담해봄 → 깨달은 5가지" |
| 단정적 처방 | "남자가 푹 빠지게 하려면? 내비두면 된다" |
| 구체적 행동 지침 | "잘못했을 때 침묵 + 잘했을 때 칭찬" |

**왜 잘 먹히나**: "방법을 모르는 거지 못하는 게 아님"이라는 희망 제공

#### C. "이게 현실임" 팩폭형

| 후킹 포인트 | 예시 |
|------------|------|
| 통념 뒤집기 | "사랑해 자주 말하는 놈이 제일 진심 아님" |
| 반전 | "연애 오래 가는 사람 특징 → 근데 이런 사람이 제일 먼저 차임" |
| 도발적 단정 | "확신 안 주는 건 선택할 만큼은 아니라는 뜻" |

**왜 잘 먹히나**: "인정하기 싫지만 맞는 말"에 대한 반응 욕구 (댓글 폭발)

#### D. "연애 시장 메타" 구조 분석형

| 후킹 포인트 | 예시 |
|------------|------|
| 연애를 시스템/시장으로 프레이밍 | "연애 시장에서 매력 체급이 높은 사람이 주도한다" |
| 시의성 있는 변수 | "요즘 연애 시작할 때 중요한 것 = 정치 성향" |
| 나이/시기 단정 | "남자 31~33 / 여자 27~29가 결혼 적기" |

**왜 잘 먹히나**: 분석욕 + 내 위치 파악 욕구 → 운세/사주 콘텐츠와 본질적으로 같은 니즈

#### E. "실화임" 스토리형

| 후킹 포인트 | 예시 |
|------------|------|
| 실제 상담/경험 | "3일 전 단기 연애 이별 재회 사례" |
| 일상 서사 + 반전 | "남편이 백수가 되었다" |
| 분노 공감 | "30대는 설레면 안 되냐?" |

**왜 잘 먹히나**: 추상적 조언보다 "실제로 그랬다"는 증거가 신뢰 생성

---

### 4-2. 후킹 공식 4가지

| 패턴 | 공식 | 대표 예시 | 효과 |
|------|------|----------|------|
| **숫자 권위** | "N명/N년 해봄 → 깨달은 것" | "소개팅 100명 주선해봄" | 신뢰 + 클릭 유도 |
| **자가진단 리스트** | "~하는 사람 특징 N가지" | "연애 못하는 남자 특징 5가지" | 자기 대입 + 저장 |
| **통념 뒤집기** | "A인 줄 알지? 사실 B임" | "사랑해 자주 말하는 놈이 제일 진심 아님" | 반전 + 댓글 논쟁 |
| **한 줄 팩폭** | 짧고 단정적 문장 | "잘해주는 건 많은데 설레게 하는 건 없음" | 공유 + 인용 |

### 최강 조합 (가장 높은 인게이지먼트)

> **숫자 권위 + 리스트형 + 마지막에 질문**
>
> 예: "연애 못하는 남자 특징 5가지... 너네는 몇 번 해당돼?"

이 구조가 **댓글 유도 + 공유 + 저장**을 동시에 만들어내는 포맷.

### 4-3. 나다운세 콘텐츠에 적용할 포인트

| Threads 인기 패턴 | 나다운세 적용 방향 |
|------------------|-------------------|
| 자가진단형 ("~하는 사람 특징") | 타로/사주 기반 자기 진단 콘텐츠 |
| 애착 유형 (회피형/불안형) | 사주 오행과 연애 궁합 연결 |
| "N명 상담해봄" 권위형 | AI 상담 데이터 기반 인사이트 |
| 타임라인별 이별 원인 | 운세 시기별 연애운 흐름 |
| 팩폭 한 줄 | 오늘의 운세 한 줄 요약 포맷 |

**핵심**: Threads 인기 연애글의 본질 = **"나는 왜 이런가" + "앞으로 어떻게 될까"**
→ 이것은 타로/사주 서비스의 핵심 니즈와 **완전히 동일**함.
