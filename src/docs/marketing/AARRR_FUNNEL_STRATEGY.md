# AARRR 퍼널 전략서 — 나다운세

> 마케팅과 제품을 분리하지 않는다.
> 퍼널의 모든 단계에서 "제품이 곧 마케팅"이 되도록 설계한다.
> **최종 업데이트**: 2026-03-12

---

## 퍼널 전체 구조

```
Acquisition (유입)
  "나다운세를 처음 알게 되는 순간"
    ↓
Activation (활성화)
  "들어와서 '이거 괜찮은데?' 하는 순간"
    ↓
Retention (리텐션)
  "다시 돌아오는 이유가 생기는 순간"
    ↓
Revenue (매출)
  "돈을 쓸 만큼 가치를 느끼는 순간"
    ↓
Referral (추천)
  "친구한테 '너도 해봐' 하는 순간"
```

## 1. Acquisition — 유입

> 목표: "나다운세를 모르던 사람이 처음 링크를 클릭하게 만든다"

### 채널 우선순위

| 순위 | 채널 | 역할 | 핵심 지표 |
|------|------|------|----------|
| 1 | **인스타 릴스** | 바이럴/공유 메인 엔진 | 릴스 도달률, 공유 수, 프로필 방문 |
| 2 | **네이버 클립** | 검색 유입 (릴스 영상 재업) | 클립 노출수, nadaunse.com 유입 |
| 3 | **에브리타임 시딩** | 20대 직접 타겟 | 게시글 반응률, 링크 클릭수 |
| 4 | **틱톡** | 10대 + 추가 도달 | 조회수, 프로필 방문 |
| 5 | **스레드 & 트위터** | 텍스트 바이럴/공유 | RT/리포스트 수, 링크 클릭 |

### 채널별 콘텐츠 전략

**인스타 릴스 (메인)**
- 유형 카드 리액션: "사주로 보니까 나 열정 90%래ㅋㅋ 맞는 듯"
- MBTI vs 나다움: "ENFP인데 사주로 보면 전혀 다른 유형이 나옴"
- 오행 에너지 시각화: "내 화(火) 에너지가 이 정도라고?"
- 밸런스 결과 공유: "열정 72% 냉정 28% 사람의 특징"

**에타 시딩**
- 자연스러운 후기 톤: "심심해서 해봤는데 소름 돋음... 16유형 중 나 딱 맞음"
- 학교/학과 맥락 활용: "시험 기간에 이거 왜 하고 있지... 근데 결과 개신기함"

**스레드 & 트위터**
- 유형별 밈 텍스트: "깊은 사색가 유형인 사람 특징: 카톡 읽고 3시간 뒤에 답장"
- 결과 공유 유도: "16유형 중 뭐 나왔는지 달아봐"

### 랜딩 설계

SNS에서 클릭한 사람이 **3초 안에 "해볼까?" 결정**하게 만들어야 한다.

| 요소 | 현재 | 개선 방향 |
|------|------|----------|
| **랜딩 첫 화면** | HomeScreenNew (콘텐츠 목록) | 유입 경로별 맞춤 랜딩 검토 — 나다움 분석 바로 진입 |
| **진입 장벽** | 비회원도 무료 콘텐츠 1회 가능 | 유지 (로그인 벽 없이 체험 → Activation으로 연결) |
| **OG 이미지** | 기본 | 유형 카드 기반 동적 OG 이미지 (공유 시 유형 노출) |

## 2. Activation — 활성화

> 목표: "처음 들어온 사람이 '가치'를 체감하고 회원가입까지 완료한다"
> 핵심 질문: "유저가 '이거 괜찮은데?'라고 느끼는 Aha Moment가 어디인가?"

### 나다운세의 Aha Moment

```
사주 정보 입력 → AI가 생성한 나다움 유형 카드를 보는 순간
"사주로 보니까 나 이런 사람이었어?"
```

이 순간까지의 시간(Time to Value)을 최소화하는 게 Activation의 전부다.

### 현재 Activation 플로우

```
[비회원]
  홈 → 무료 콘텐츠 클릭 → 사주 입력 → AI 결과 확인 (Aha!) → 나다움 기록하기 → 회원가입 유도
  홈 → 사주/타로 상담 체험 → 결과 확인 (Aha!) → 추천 콘텐츠 → 회원가입 유도

[회원가입 플로우]
  OAuth(카카오/구글) → 약관 동의 → 홈 → 나다움 태그 5개 수집 → 30새싹 보상
```

### 단계별 이탈 포인트 & 개선

| 단계 | 이탈 원인 | 개선 방향 |
|------|----------|----------|
| **홈 → 콘텐츠 클릭** | 뭘 해야 하는지 모름 | 첫 방문자용 "3초 성격 분석" CTA 강조 |
| **콘텐츠 → 사주 입력** | 생년월일 입력이 귀찮음 | 입력 필드 최소화, "딱 생년월일만 넣으면 끝" 카피 |
| **사주 입력 → 결과 대기** | 로딩이 길면 이탈 | 로딩 중 기대감 조성 (진행 상태 + "당신의 사주를 분석하고 있어요") |
| **결과 확인 → 회원가입** | 가입 동기 부족 | 결과 저장/공유/나다움 태그 수집을 가입 인센티브로 |
| **회원가입 → 태그 수집** | 태그 모으는 재미 부족 | 태그 5개 달성 시 30새싹 보상 안내 강화 → 상세 분석 해금 연결 |

### Activation 핵심 전략

1. **Time to Value 최소화** — 클릭 → 결과까지 **60초 이내** 목표
2. **로그인 벽 제거** — 결과 확인까지는 비회원으로 가능 (현재 구현 완료)
3. **결과의 WOW 퀄리티** — 유형 카드 비주얼 + 개인화된 인사이트가 "캡처해서 공유하고 싶은" 수준
4. **가입 = 보상** — 결과 영구 저장 + 나다움 태그 수집 시작 → 태그 5개 = 30새싹 + 상세 분석 해금

### 비회원 → 회원 전환 트리거

| 트리거 | 현재 상태 | 설명 |
|--------|----------|------|
| 무료 콘텐츠 일일 제한 | 구현 완료 | `anonymous_free_views` — 비회원 1일 제한 |
| 상담 체험 1회 제한 | 구현 완료 | `consultLimitService` — SHA-256 fingerprint 기반 |
| 나다움 상세 분석 해금 | 구현 완료 | 나다움 태그 5개 수집 시 해금 (수집할 때마다 30새싹 보상) |
| 결과 저장 | 가입 시 저장 | 비회원 결과는 휘발 → "저장하려면 가입" |

## 3. Retention — 리텐션

> 목표: "한 번 온 사람이 다시 돌아오는 이유를 만든다"
> 핵심: 리텐션 없이 Acquisition에 투자하면 밑 빠진 독에 물 붓기다.

### 나다운세의 리텐션 엔진

| 엔진 | 주기 | 메커니즘 | 현재 상태 |
|------|------|---------|----------|
| **주간 보고서** | 매주 | pg_cron → AI 보고서 생성 → 알림톡 발송(일요일) → 앱 재방문 | 구현 완료 |
| **마음톡 AI 채팅** | 수시 | 일반/사주/타로 모드 채팅 → 라운드 시스템 | 구현 완료 |
| **나다움 분석** | 비정기 | 사주 기반 성격 DNA → 16유형 → 상세 분석 | 구현 완료 |
| **재방문 쿠폰** | 복귀 시 | 이탈 유저 복귀 시 쿠폰 자동 발급 | 구현 완료 |
| **새 콘텐츠 알림** | 비정기 | 신규 유/무료 콘텐츠 등록 시 | 알림톡 수동 |

### 리텐션 루프 설계

```
[주간 루프 — 보고서 기반]
  일요일 알림톡 수신
    → 주간 보고서 확인 (핵심 인사이트)
    → 보고서 타로 3장 뽑기 (인터랙션)
    → 마음 챙김 콘텐츠
    → 응원 한마디 작성

[일상 루프 — 마음톡 기반]
  고민이 있을 때 마음톡 진입
    → AI 대화 (일반: 무료 무제한)
    → 사주/타로 모드 전환 (3회 무료 → 5새싹)

[성장 루프 — 나다움 기반]
  나다움 분석 결과 확인
    → 태그 선택/기록 (CheckRecordMe)
    → 시간이 지나면 "내 유형이 변했을까?" 재방문 동기
    → 새 콘텐츠로 추가 분석
```

### 리텐션 개선 방향

| 영역 | 현재 | 개선 방향 |
|------|------|----------|
| **주간 보고서 완독률** | 보고서 → 타로 → 마음챙김 → 메모 순서 | 각 단계 완료율 추적 → 이탈 구간 파악 |
| **마음톡 재방문** | AI 선제 인사 | 대화 심리 흐름 축적 기능 추가 검토 → 개인화 강화 |
| **Push 알림** | 알림톡(카카오) | 브라우저 Push 알림 검토 (비용 0원, 즉시 도달) |
| **콘텐츠 소진** | 신규 콘텐츠 수동 등록 | 시즌/시기별 콘텐츠 캘린더 (절기, 월초 운세 등) |
| **습관 형성** | 없음 | 연속 방문 리워드 (3일 연속 → 새싹, 7일 → 쿠폰) |

## 4. Revenue — 매출

> 목표: "유저가 돈을 쓸 만큼의 가치를 느끼는 구조를 만든다"
> 핵심: 무료에서 유료로의 자연스러운 업셀링 경로

### 현재 수익 모델

| 수익원 | 단가 | 메커니즘 | 관련 기능 |
|--------|------|---------|----------|
| **새싹 충전** | 패키지별 | 유일한 과금 포인트 — 새싹을 충전해서 모든 유료 기능에 소모 | sprout-charge Edge Function |
| **유료 콘텐츠 (심화 해석)** | 30새싹/건 | 무료 체험 → "더 깊은 해석" 업셀 → 새싹 소모 | MasterContentDetailPage |
| **마음톡 사주/타로 모드** | 5새싹/회 | 일반 모드 무료 → 사주/타로 모드 3회 무료 후 과금 | mind-talk-chat |
| **쿠폰 시스템** | 할인 | 재방문 쿠폰 → 첫 충전 유도 | coupon.ts, CouponBottomSheetNew |

### 무료 → 유료 업셀링 퍼널

```
[경로 1: 무료 콘텐츠 → 유료 심화 (새싹 소모)]
  무료 콘텐츠 결과 확인
    → 결과 하단에 "더 깊은 해석 보기" (recommended_paid_content_id + upsell_hook_text)
    → 유료 콘텐츠 상세 → 30새싹 소모 → 결제
    → AI 심화 해석 결과 → "이 정도 퀄리티면 또 사고 싶다"
    → 새싹 부족 시 → 충전 유도

[경로 2: 마음톡 → 새싹 충전]
  마음톡 일반 모드 무료 대화 (습관 형성)
    → 사주/타로 모드 3회 무료 체험
    → "이 모드 더 쓰고 싶은데" → 새싹 5개 소모
    → 새싹 잔액 부족 → 충전 유도

[경로 3: 나다움 태그 → 무료 새싹 → 유료 콘텐츠 체험]
  콘텐츠 이용 → 나다움 태그 기록 → 태그 5개 달성 → 30새싹 보상
    → 보상 새싹으로 유료 콘텐츠 첫 체험 (무료 느낌)
    → 퀄리티 체감 → 추가 이용 시 새싹 충전 유도
```

### Revenue 개선 방향

| 영역 | 현재 | 개선 방향 |
|------|------|----------|
| **첫 충전 전환** | 태그 5개 보상 30새싹으로 첫 체험 | 첫 체험 후 새싹 소진 → "또 해보고 싶은데" → 자연스러운 충전 유도 |
| **업셀 타이밍** | 무료 결과 하단 추천 | 감정 최고조(결과 확인 직후) CTA 강화 |
| **새싹 가격 심리** | 패키지별 가격 | 앵커링 — 대용량 패키지일수록 새싹당 단가 할인 강조 |
| **재이용 유도** | 없음 | 이용 후 "다른 주제 해석도 궁금하지 않으세요?" 추천 |
| **새싹 경제 순환** | 태그 5개=30새싹, 공유=30새싹 | 무료 새싹 획득 → 유료 체험 → 퀄리티 체감 → 충전 전환 |
| **번들/패키지** | 없음 | 새싹 대량 패키지 할인 — "100새싹 사면 20새싹 보너스" |

### PMF 검증 공식

```
3 × CAC < LTV → PMF 달성

CAC = 총 마케팅 비용 ÷ 신규 유저 수
LTV = ARPU × 평균 이용 기간 (월)
```

현재 SNS 오가닉 중심이라 **CAC ≈ 0**에 가까움 → LTV를 키우는 것이 핵심.
LTV 향상 = **리텐션 기간 연장** × **결제 빈도 증가** × **객단가 유지**

## 5. Referral — 추천

> 목표: "유저가 자발적으로 친구에게 '너도 해봐'라고 말하게 만든다"
> 핵심: 공유하고 싶은 결과물 + 공유하면 보상

### 현재 Referral 자산

| 자산 | 공유 동기 | 현재 상태 |
|------|----------|----------|
| **나다움 유형 카드** | "나는 이런 사람이야" (정체성 표현) | 구현 완료 — 16유형 그라디언트 카드 |
| **열정/냉정 밸런스** | "열정 72% 냉정 28%ㅋㅋ" (유머) | 구현 완료 |
| **오행 에너지 분포** | "내 화(火) 에너지가 50%래" (신기함) | 구현 완료 |
| **콘텐츠 공유 보상** | 공유하면 나와 친구 모두 30새싹 | 구현 완료 — 무료/유료 콘텐츠 상세에서 공유 |

### Referral 루프 설계

```
[자발적 공유 루프]
  나다움 분석 결과 확인
    → 유형 카드가 예쁘고 "나를 잘 설명함"
    → 캡처 → 인스타 스토리/카톡 공유
    → 친구가 "나도 해볼래" → nadaunse.com 유입
    → 친구도 결과 공유 → 바이럴 루프

[인센티브 공유 루프 — 30새싹 양방향 보상]
  무료/유료 콘텐츠 상세에서 공유하기 클릭
    → 친구에게 링크 발송
    → 친구가 링크로 가입 → 친구 30새싹 지급
    → 나에게도 30새싹 지급
    → 양쪽 모두 유료 콘텐츠 1회 체험 가능 (30새싹)
    → "나도 해봤는데 진짜 맞아" → 추가 공유 → 바이럴 루프
```

### Referral 개선 방향

| 영역 | 현재 | 개선 방향 |
|------|------|----------|
| **공유 이미지 퀄리티** | 유형 카드 (텍스트 기반) | 동적 OG 이미지 — 공유 링크에 유형 카드 자동 표시 |
| **공유 URL** | nadaunse.com (홈) | `/nadaum/result?type=열정적리더` — 링크 자체가 콘텐츠 |
| **공유 접점 확대** | 무료/유료 콘텐츠 상세 | 나다움 분석 결과, 주간 보고서 등 추가 공유 포인트 검토 |
| **비교 기능** | 없음 | "너랑 나랑 유형 비교" — 친구 초대의 자연스러운 동기 |
| **공유 보상 인지도** | 30새싹 양방향 보상 구현 완료 | 공유 버튼 근처에 "친구와 나 모두 30새싹" 안내 강화 |
| **결과 텍스트 프리셋** | 없음 | 공유 시 자동 카피: "사주로 본 내 성격 유형: 열정적 리더 — 너도 해봐" |

### 바이럴 계수 (K-Factor) 목표

```
K = 사용자당 평균 초대 횟수 × 추천 전환율

현재 추정: K = 0.5 × 0.1 = 0.05 (자연 성장 어려움)
목표:      K = 2.0 × 0.15 = 0.30 (가속 성장)

K > 1.0이면 자가 증식 — 마케팅 비용 없이 유저가 유저를 데려옴
```

**K-Factor 올리는 방법:**
- 초대 횟수 늘리기 → 공유하고 싶은 결과물 퀄리티 + 공유 접점 확대
- 전환율 올리기 → 공유 링크의 랜딩 퀄리티 + 진입장벽 제거

## 퍼널 별 핵심 지표

### Acquisition 지표

| 지표 | 정의 | 측정 방법 |
|------|------|----------|
| **MAU** | 월간 순수 이용자 수 | GA4 Active Users |
| **DAU** | 일간 순수 활동 이용자 수 | GA4 Active Users (daily) |
| **NU** | 신규 방문자 수 | GA4 New Users |
| **채널별 유입수** | SNS별 nadaunse.com 클릭 수 | UTM 파라미터 + GA4 |
| **CPC / CPM** | 유료 광고 시 클릭/노출당 비용 | 광고 플랫폼 |

### Activation 지표

| 지표 | 정의 | 측정 방법 |
|------|------|----------|
| **Bounce Rate** | 첫 페이지에서 이탈한 비율 | GA4 |
| **PV** | 둘러본 페이지 수 | GA4 Pages per Session |
| **DT (Duration Time)** | 평균 체류 시간 | GA4 Avg. Session Duration |
| **가입전환율** | (회원가입수 / 방문수) × 100 | Supabase auth + GA4 |
| **Time to Aha** | 첫 방문 → 나다움 결과 확인까지 시간 | GA4 이벤트 타임스탬프 차이 |
| **무료 콘텐츠 완료율** | 무료 콘텐츠 시작 → 결과 확인까지 완료 비율 | GA4 이벤트 퍼널 |

### Retention 지표

| 지표 | 정의 | 측정 방법 |
|------|------|----------|
| **Stickiness** | DAU / MAU — 일상적으로 쓰는 정도 | GA4 |
| **CRR** | (기간 종료 시 기존 유저 / 기간 시작 시 기존 유저) × 100 | Supabase users + visit_dates |
| **N일차 리텐션** | Day 0 유입자 중 N일차 재방문 비율 | GA4 Cohort Analysis |
| **주간 보고서 열람률** | 보고서 발송 수 대비 열람 수 | weekly_reports 테이블 + 알림톡 클릭률 |
| **마음톡 재사용률** | 첫 대화 후 7일 내 재대화 비율 | mind_talk_conversations 테이블 |

### Revenue 지표

| 지표 | 정의 | 측정 방법 |
|------|------|----------|
| **AOV** | 평균 주문 금액 (총 매출 / 총 주문 수) | orders 테이블 |
| **ARPU** | 유저 1인당 평균 매출 | 총 매출 / MAU |
| **ARPPU** | 결제 유저 1인당 평균 매출 | 총 매출 / 결제 유저 수 |
| **LTV** | 유저 1명의 생애 잠재 수익 | ARPPU × 평균 이용 기간 |
| **CAC** | 유저 1명 유치 비용 | 총 마케팅 비용 / NU |
| **구매전환율** | (구매건수 / 방문수) × 100 | orders + GA4 |
| **쿠폰 사용률** | 발급 쿠폰 중 실제 사용 비율 | user_coupons (is_used) |
| **새싹 충전 전환율** | 새싹 부족 노출 → 실제 충전 비율 | sprout_transactions |

> **PMF 기준: 3 × CAC < LTV**

### Referral 지표

| 지표 | 정의 | 측정 방법 |
|------|------|----------|
| **K-Factor** | (사용자당 평균 초대 횟수) × (추천 전환율) | 공유 이벤트 + 초대 링크 가입 추적 |
| **NPS** | 추천고객 비율 - 비추천고객 비율 | 설문 (인앱 or 알림톡) |
| **공유 클릭률** | 활성 유저 중 공유 버튼 클릭 비율 | GA4 share 이벤트 |
| **초대 링크 전환율** | 공유 링크 클릭 → 가입 완료 비율 | UTM + Supabase auth |

## 퍼널 간 연결 — 제품이 퍼널을 돌리는 구조

```
[Acquisition → Activation]
  SNS에서 나다움 유형 카드 본 사람
    → "나도 해볼래" 클릭 → 비회원 무료 체험 → 결과 확인 (Aha!)

[Activation → Retention]
  회원가입 완료 → 나다움 태그 수집 시작 → 태그 5개 = 30새싹 + 상세 분석 해금
    → 주간 보고서 자동 발송 시작 (일요일) → 매주 재방문 이유 생성
    → 마음톡 일반 모드 무료 → 수시 재방문

[Retention → Revenue]
  나다움 태그 보상 30새싹으로 유료 콘텐츠 첫 체험 → 퀄리티 체감 → 새싹 충전
  마음톡 사주/타로 모드 무료 3회 소진 → 새싹 충전
  무료 콘텐츠 결과 → "더 깊은 해석" 업셀 → 30새싹 소모

[Revenue → Referral]
  유료 결과의 높은 퀄리티 → "이거 진짜 잘 맞아" → 콘텐츠 공유
  공유하면 나와 친구 모두 30새싹 → 친구도 유료 체험 가능 → 바이럴 루프

[Referral → Acquisition]
  공유된 유형 카드/링크 → 새 유저 클릭 → Acquisition으로 복귀
  → 퍼널 자동 순환
```

### 우선순위 로드맵

지금 가장 임팩트가 큰 개선 순서:

| 순위 | 영역 | 액션 | 기대 효과 |
|------|------|------|----------|
| 1 | **Referral** | 공유 보상(30새싹) 인지도 강화 + 동적 OG 이미지 | K-Factor 상승 → 무료 유입 증가 |
| 2 | **Activation** | 첫 방문자 CTA 강화 ("3초 성격 분석") | 가입전환율 상승 |
| 3 | **Retention** | 주간 보고서 완독률 퍼널 추적 | 이탈 구간 파악 → 보고서 구조 개선 |
| 4 | **Revenue** | 쿠폰 만료 알림 + 업셀 CTA 강화 | 첫 결제 전환율 상승 |
| 5 | **Acquisition** | 릴스 콘텐츠 본격 제작 | MAU/NU 확대 |
