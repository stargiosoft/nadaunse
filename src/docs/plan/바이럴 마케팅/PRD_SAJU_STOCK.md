# 바이럴 기능 요구사항 정의서 (PRD)

## 프로젝트 개요

- **기능명**: 사주 시세 차트 — "당신의 연애운, 현재 역대 저점입니다"
- **바이럴 공식**: [주식 차트/투자 분석 A] + [사주 기반 연애운 시세 환산 B] = "이런 건 처음이다"
- **바이럴 기능 간단 요약**: 사용자의 사주를 입력하면 연애운을 **주식 시세**로 환산해 증권사 리서치 리포트 형태로 출력한다. 현재가·목표가·저평가율·투자의견이 포함된 **종목 리포트 카드 1장**이 즉시 생성되며, 연간 운세를 월별 주가 차트로 시각화한다. 핵심 역설은 **"시가총액은 높은데 시장가가 바닥"** — 커리어·성격·감성 등 내면 밸류에이션은 4,000만원대인데 연애 시장에서의 현재 거래가는 800원대. 이 **저평가율(▼78%)이 숫자로 보여주는 위로**다. "시장이 당신을 몰라봅니다. 펀더멘털은 탄탄합니다"가 핵심 메시지. 결과물은 증권 HTS 스타일의 다크 네이비 카드 — 현재가 + 목표가 + 투자의견 + 애널리스트 코멘트가 담겨 즉시 캡처·공유 가능. "내 연애 1,200원이래ㅋㅋ 근데 강력매수래 너는 얼마야?"가 대화를 만들고, **커플 M&A 시너지 분석**이 강제 2인 루프를 만든다.

---

## 바이럴 루프

### 바이럴을 일으키는 구조

1. **입력**: 생년월일시 + 현재 연애 상태(싱글/썸/연애중) 입력 (10초, 가입 불필요) → "사주증권 리서치센터 분석 중..." 로딩 연출
2. **종목 리포트 카드**: 현재가 + 목표가 + 저평가율 + 투자의견 + 차트가 담긴 카드 1장 즉시 생성 → **바이럴 지점 1**
3. **시가총액 상세 분석**: "밸류에이션 보고서 열기" → 커리어 PER, 성격 ROE, 매력 PBR 등 항목별 분석 (3~4턴 인터랙티브)
4. **연간 시세 차트**: 월별 연애운을 주가 차트로 시각화 + 급등/급락 시점 + 애널리스트 코멘트 → **바이럴 지점 2**
5. **커플 M&A 분석**: "합병 시너지 분석하기" → 상대방 생년월일 입력 필수 → **강제 2인 루프**
6. **전환**: "수석 애널리스트와 1:1 상담" → 캐릭터 챗봇 유료 상담

### 유발 감정

| 감정 | 메커니즘 |
|------|---------|
| **뜨끔 + 자조 (Hook)** | "현재가 1,200원"이라는 숫자가 내 연애 현실을 적나라하게 보여줌 → "ㅋㅋ 맞는데" 캡처 |
| **위로 + 자존감 (Relief)** | "시가총액 4,100만원, 저평가율 ▼78%" — 내 가치는 높은데 시장이 못 알아본 거라는 면죄부 |
| **희망 (Hope)** | "목표가 9,800원, 7월 도화살 진입 시 급등 예상" → 구체적 상승 시점 |
| **비교 (Envy)** | 현재가 + 시가총액 숫자 비교 → "너는 얼마야?" "너 시총 얼마래?" |
| **탐욕 (Greed)** | "강력 매수" "역대 저점" "지금이 바닥" → 주식 투자 감각으로 기대감 증폭 |

### 논란 설계

- **"현재가 800원"이 논란의 핵심 엔진**: 낮은 숫자에 "이거 나 무시하는 거 아니야?" vs "ㅋㅋ 맞는데 어쩔" 갈림
- **저평가율 자체가 밈**: "저평가 78%" "관리종목 지정" "상폐 직전" → 자조적 공유 폭발
- **"펀더멘털은 탄탄합니다"가 안전장치**: 현재가가 낮아도 시가총액(진짜 가치)은 높다는 구조 → 찌르되 반드시 올려줌
- **스윗 스팟**: 현재가는 바닥이지만 목표가는 높고, 투자의견은 강력 매수. 자조하면서도 기분 나쁘지 않은 톤. 바닥일수록 = 상승 여력이 크다는 주식 논리가 자연스럽게 위로가 됨

## 사용자 스토리

**As** (누가): 사회적 스펙과 커리어는 탄탄하지만 외모 컴플렉스로 연애 시장에서 저평가받아 온 3040 여성 유저는

**Want to** (무엇을 원한다): 내 연애운을 주식 시세처럼 객관적 숫자로 보고, 지금이 바닥인지 언제 오르는지 확인해서, 종목 리포트 카드를 친구들과 공유하며 "너는 현재가 얼마야?" 대화를 하기를 원한다.

**So that** (어떤 목적/가치를 위해): "현재가는 바닥이지만 시가총액은 높다"는 숫자로 내 가치를 재확인하고, 목표가 달성 시점(급등 예정월)에 대한 기대감을 갖고, 궁금해진 상세 분석을 캐릭터 챗봇으로 이어가기 위해.

## MVP 필요 기능

### Step 1. 초저마찰 랜딩 및 정보 입력

- 메인 화면: "당신의 연애운, 현재 시세를 조회합니다" 문구 + 증권 HTS 스타일 다크 UI + "시세 조회" 버튼
- 입력폼: 생년월일(양력/음력), 성별, 태어난 시간(선택), 현재 연애 상태(싱글/썸/연애중). **10초 컷** 설계
- 입력 직후 **"사주증권 리서치센터 분석 중..."** 로딩 연출:
  - "종목 데이터 수집 중..."
  - "원국 밸류에이션 산정 중..."
  - "도화살 모멘텀 분석 중..."
  - "수석 애널리스트 검토 중... 📊"
  - → 증권사 느낌의 긴장감 빌드업 (2~3초)

### Step 2. 종목 리포트 카드 생성 (바이럴 핵심 — 1장 캡처 공유)

사주 분석 결과를 기반으로 증권사 리서치 리포트 형태의 카드 1장이 즉시 생성된다. **이 카드가 바이럴의 최소 단위.**

#### 2-1. 투자의견 배정 — 사주 요소와 연결

사주 원국에서 현재 연애운 상태를 추출하여 5단계 투자의견 중 1개를 자동 배정:

| 투자의견 | 사주 트리거 | 의미 | 카드 표시 |
|---------|-----------|------|----------|
| **강력 매수** | 도화살 2개 이상 + 현재 억압(편인 과다) | 매력 폭발 직전, 지금이 바닥 | 🔴 빨간 뱃지 |
| **매수** | 도화살 1개 + 정관/정인 동주 | 안정적 상승 예상 | 🟠 주황 뱃지 |
| **보유(존버)** | 식신 보유 + 현재 대운 평이 | 급등은 아니지만 손절 금지 | 🟡 노랑 뱃지 |
| **비중 축소** | 편관격 + 도화살 충 | 현재 고점, 차익 실현 시기 | 🟢 초록 뱃지 |
| **관리종목** | 공망 진입 + 편인 과다 + 도화살 합거 | 일시 거래 정지 상태 | ⚫ 회색 뱃지 |

| **차트** | 월별 등락을 시각적으로 | "7월에 급등하네 존버해야겠다" |
| **애널리스트 코멘트** | 사주 기반 핵심 조언 | 캡처 트리거 — 찔리거나 웃김 |

#### 2-3. 현재가 산정 로직

**현재가 = 기본가(5,000원) - 억압 감소분 + 모멘텀 가산분**

현재 사주에서 연애운을 억압하는 요소가 많을수록 현재가가 낮아진다. **현재가가 낮을수록 = 저평가 폭이 크다 = 상승 여력이 크다**는 역설이 핵심. 800원 받아도 기분 나쁘지 않음 — "바닥이니까 강력매수"니까.

```
억압 감소분 (사주에서 산출):
  편인 과다 (자격지심)        -1,500원
  도화살 합거 (매력 봉인)     -1,200원
  정관 약 (인연 부재)         -1,000원
  공망 진입                   -800원
  상관 과다 (자기 의심)       -600원

모멘텀 가산분 (현재 대운/세운):
  도화살 운 진입 예정(3개월 내)  +1,500원
  정관 운 진입 예정(6개월 내)    +800원
  편인 합거 예정               +600원
  식신 운 진행 중              +300원
```

| 현재가 구간 | 등급 | 카드 스타일 |
|-----------|------|-----------|
| **8,000원+** | 우량주 | 골드 테두리, "프리미엄 종목" 뱃지 |
| **5,000~7,999원** | 중형주 | 실버 테두리 |
| **2,000~4,999원** | 소형주 | 기본 테두리, "저평가 발굴" 뱃지 |
| **800~1,999원** | 동전주 | 네온 레드 테두리, "역대 저점" 뱃지 |
| **800원 미만** | 관리종목 | 회색 테두리, "관리종목 지정" 경고 |

> 역대 저점(800~1,999원)이 가장 화려한 네온 레드 → 공유 욕구 최대. "관리종목"은 희귀 등급으로 화제성 극대.

#### 2-4. 시가총액(적정가치) 산정 로직

현재가와 별개로 **진짜 가치**를 산정하는 것이 핵심 위로 장치. "시장이 못 알아볼 뿐, 당신의 펀더멘털은 탄탄합니다."

```
시가총액 = 커리어 PER + 성격 ROE + 감성 EPS + 매력 PBR

항목별 산출 (사주 요소 기반):
  커리어 PER (편관·정관·편인 조합)
    → 관성이 강하면 높음 = 사회적 역량
  성격 ROE (정인·식신·비견 조합)
    → 인성+식상이 강하면 높음 = 내면 매력
  감성 EPS (식신·상관·정인 조합)
    → 식상이 풍부하면 높음 = 감정 표현력
  매력 PBR (도화살·홍염살·편재 조합)
    → 도화 요소가 많으면 높음 = 외적 매력

  시가총액 범위: 1,500만원 ~ 9,999만원
```

**핵심 설계**: 시가총액은 대부분 높게 나오도록 설계. 현재가는 낮을 수 있어도 시가총액은 3,000만원 이상 — **"저평가율이 높다 = 가치가 높은데 시장이 몰라본다"**가 되어야 위로가 성립.

#### 2-5. 목표가 + 급등 시점 산정 로직

사주 대운·세운에서 **억압 요소가 풀리는 시점**을 급등 시점으로 환산:

```
주요 판단 기준:
  편인이 합거되는 시점     → "자격지심 해소 = 상승 모멘텀"
  도화살 운 진입 시점      → "매력 발현 = 급등"
  정관이 투출되는 시점     → "인연 출현 = 목표가 도달"

목표가 = 시가총액 기반 적정 주가 환산
         (현재가 대비 300~900% 상승률 범위)

표시: "7월 도화살 진입 시 목표가 9,800원 (↑717%)" (월 단위까지)
```

#### 2-6. 투자의견별 애널리스트 코멘트

카드에 박히는 핵심 문장. **이 코멘트가 캡처·공유의 트리거.**

| 투자의견 | 애널리스트 코멘트 | 공유 포인트 |
|---------|----------------|-----------|
| 강력 매수 | "현재 극심한 저평가 구간. 펀더멘털 대비 시장가가 바닥입니다. 지금이 매수 타이밍." | "바닥이래ㅋㅋ 근데 강력매수" |
| 매수 | "안정적 상승 추세 진입. 단기 변동성 감안하되 중장기 보유 추천." | "꾸준히 오른대" |
| 보유(존버) | "현재 구간에서 손절은 최악의 선택입니다. 존버가 답입니다." | "존버하래ㅋㅋ 손절 금지" |
| 비중 축소 | "현재 고점 근접. 이 시기에 무리한 추가 매수는 자제하시고 차익 실현을 권합니다." | "고점이래 나 팔아야 하나" |
| 관리종목 | "일시적 거래 정지 구간입니다. 이 시기는 종목 분석에 집중하시길. 반등은 옵니다." | "관리종목ㅋㅋㅋ 상폐 직전" |

### Step 3. 시가총액 상세 분석 (인터랙티브)

종목 리포트 카드 확인 후 **"밸류에이션 상세 보기"** 버튼으로 진입. 사주증권 애널리스트가 항목별로 분석해주는 인터랙티브 구간.

#### 3-1. 분석 구조 (3~4턴)

| 턴 | 진행 | 유저 참여 |
|----|------|----------|
| **1턴: 시장 진단** | 애널리스트가 현재가가 낮은 이유를 사주로 설명 | 유저 반응 선택지 2~3개 |
| **2턴: 밸류에이션** | 항목별 적정가치 산출 과정 공개 (커리어·성격·감성·매력) | — |
| **3턴: 저평가 원인** | "시장이 당신을 왜 저평가하는지" 질문 → 유저 답변이 분석에 반영 | 유저 선택지 2~3개 |
| **4턴: 투자 전략** | 유저 답변 기반 맞춤 급등 시나리오 + 리스크 요인 제시 | — |

#### 3-2. 핵심 설계 원칙

| 원칙 | 이유 |
|------|------|
| **숫자가 계속 나와야 함** | PER, ROE, PBR 등 수치가 비교·캡처의 핵심 연료 |
| **현재가는 낮아도 시가총액은 높게** | "바닥이지만 가치 있다"는 역설이 위로의 핵심 |
| **유저의 선택이 분석에 반영** | "스펙은 좋은데 안 팔린다" 선택 → 애널리스트가 그 키워드로 저평가 원인 분석 |
| **주식 용어를 일관되게 사용** | "손절" "존버" "물타기" "상폐" — 밈 언어와 자연스럽게 결합 |

#### 3-3. 분석 예시 — "강력 매수" 종목

**1턴: 시장 진단**
```
사주증권 수석 애널리스트:

"김○○ 종목 분석 시작합니다.

 현재가 1,200원.
 52주 최저가 근접입니다.

 그런데 이 종목의 원국을 보면
 日支에 正官, 月支에 桃花가
 동시에 있습니다.

 이건 펀더멘털이 탄탄한
 우량주가 시장에서 묻힌 겁니다.

 혹시 본인도 그렇게 느끼시나요?"

  ① "스펙은 괜찮은데 연애만 안 되는 느낌"
  ② "솔직히 내가 매력 없다고 생각해요"
  ③ "관심 있는 사람이 날 안 봐요"
```

②번 선택 시:
```

"아, 자기 평가가 시장가를
 끌어내리고 있군요.

 사주로 보면 偏印이 月干에서
 일간을 24시간 압박하고 있습니다.

 '나 같은 게' '내가 뭐라고'
 이런 생각, 자주 하시죠?

 이게 PBR을 0.6배까지
 떨어뜨린 주범입니다.

 근데요, 이건 실적이 나쁜 게
 아니라 시장이 못 알아보는 겁니다."
```

**3턴: 저평가 원인 + 유저 질문**
```
사주증권 수석 애널리스트:

"밸류에이션을 마치겠습니다.

 커리어 PER: 12.8배 — 우량
 성격 ROE: 24.7% — 고수익

 전체 시가총액: 4,100만원
 현재 시장가: 1,200원

 저평가율: ▼78%

 한 가지 여쭤보겠습니다.
 이 저평가의 원인이
 뭐라고 생각하세요?"

  ① "내가 먼저 다가가는 걸 못 해서"
  ② "외모에 자신이 없어서"
  ③ "좋은 사람을 못 만나서"
```

②번 선택 시:
```
사주증권 수석 애널리스트:

"외모요?

 솔직히 말씀드리겠습니다.
 PBR 0.6배의 원인은
 외모가 아닙니다.

 피고인... 아니, 고객님의 사주에서
 偏印이 桃花를 누르고 있어요.

 이건 매력이 없는 게 아니라
 매력을 본인이 꺼놓은 구조입니다.

 시장에 상장을 안 한 종목을
 누가 사겠습니까.

 7월에 丙午 운이 들어오면

 지금은 매수 타이밍이지

#### 6-2. 전환 플로우

```
종목 리포트 / 연간 차트에서 CTA 클릭
