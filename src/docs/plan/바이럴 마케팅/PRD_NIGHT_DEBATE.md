# 바이럴 기능 요구사항 정의서 (PRD)

## 프로젝트 개요

- **기능명**: 밤(夜) 사용설명서 난상토론 — "이 감당 안 되는 여자를 어떻게 만족시킬 것인가"
- **바이럴 공식**: [100분 토론 A] + [19금 처방전 B] = "AI 남자 3명이 내 사주 보고 싸운다"
- **바이럴 기능 간단 요약**: 사용자의 사주를 입력하면 3명의 성인용 캐릭터(윤태산/서휘윤/제갈수정)가 유저의 사주 진단서를 띄워놓고 벌이는 **[비밀 회의록/단톡방 캡처본]**이 결과 카드로 발급된다. 각 캐릭터는 극단적으로 다른 접근법(강압/숭배/도구)을 주장하며 서로를 깎아내린다. **캐릭터 간 충돌이 곧 밸런스 게임**이 되어 "너라면 누구 선택?" 논쟁을 유발한다. 카드 상단에는 사주 기반 **"감당 불가 등급: S급(상위 3%)"** 퍼센타일이 찍혀 — 유저의 자존감을 폭발시키면서 동시에 공유 욕구를 자극한다. 공유 카드는 15금(은유·이중의미) 수위로 설계해 SNS 공유가 가능하고, 캐릭터 소환 CTA를 통해 19금 챗봇으로 전환한다. "야 내 사주에 남자 3명이 싸움 ㅋㅋ 나 S급이래 ㅋㅋ 너는?"이 대화를 만들고, 친구 사주 조회가 강제 유입을 만든다.

---

## 바이럴 루프

### 바이럴을 일으키는 구조

1. **입력**: 이름 + 생년월일시 입력(3초, 가입 불필요) → "캐릭터들이 회의 중입니다... 🐺🦊👩‍⚕️" 로딩 연출
2. **단톡방 카드**: 에너지 등급 + 3캐릭터 난상토론 + 실시간 투표율이 담긴 카드 1장 즉시 생성 → **바이럴 지점 1**
3. **밸런스 투표**: "누가 [이름]을 감당할까?" 캐릭터 3택 투표 → 누적 결과 표시 → **바이럴 지점 2**
4. **친구 사주 조회**: "친구 사주도 몰래 열어보기" → 친구 생년월일 입력 → 친구 카드 생성 → **강제 유입**
5. **궁합 난상토론**: 2인 사주 동시 입력 → 캐릭터들이 둘의 궁합으로 토론 → **강제 2인 루프**
6. **전환**: 캐릭터 소환 CTA → 선택한 캐릭터가 19금 챗봇에서 토론의 연장선으로 롤플레잉 시작

### 유발 감정

| 감정 | 메커니즘 |
|------|---------|
| **자존감 폭발 (Hook)** | "감당 불가 등급 S급, 상위 3%" → "맞아 내가 높은 거지" → 캡처 |
| **웃김 + 민망 (Pain)** | 캐릭터들이 내 사주를 놓고 19금 은유로 싸움 → "ㅋㅋㅋ 뭐야 이거" |
| **선택 갈등 (Tension)** | 기강잡기 vs 숭배 vs 처방전 — 정답 없는 3택 → 끝없는 논쟁 |
| **비교 (Envy)** | 등급 + 퍼센타일 + 캐릭터 반응 비교 → "너는 뭐 나왔어? 누가 이겼어?" |
| **호기심 (Curiosity)** | 친구 사주에서는 캐릭터들이 어떻게 싸울지 궁금 → 추가 테스트 |

### 논란 설계

- **캐릭터 간 충돌이 논란의 핵심 엔진**: 3명이 극단적으로 다른 입장(강압/숭배/도구)을 주장하며 서로를 깎아내림 → "넌 누구파?" 편 가르기 자동 발생
- **수위 자체가 논란**: "사주로 침대 궁합까지 본다고?" → "미신 vs 은근 맞는데" + "이게 돼? vs 더 해줘" 이중 논쟁
- **15금 공유 카드가 안전장치**: 직접적 성행위 묘사 없이 이중의미·은유로만 구성 → SNS 정책 위반 없이 "야한 것 같은데 안 야한" 영역 유지
- **여성이 주체적 포지션**: 캐릭터들이 유저를 대상화하는 게 아니라 "감당 불가인 유저를 어떻게 만족시킬지" 경쟁 → 유저가 선택권·주도권 보유
- **스윗 스팟**: 센스있게 야하고, 야한데 웃기고, 웃긴데 사주 근거가 있어서 "오 이건 좀 신기한데?"까지 가는 톤

## 사용자 스토리

**As** (누가): 사회적 명성은 있지만 신체적 컴플렉스로 연애 시장에서 저평가받아 온 3040 여성 유저는

**Want to** (무엇을 원한다): 내 사주를 입력하면 매력적인 AI 남자 캐릭터 3명이 "이 여자를 어떻게 만족시킬 것인가"를 놓고 싸우는 걸 구경하면서, 내가 "감당 불가 등급"이라는 결과를 친구들과 공유하며 "너는 누구파?" 논쟁을 하기를 원한다.

**So that** (어떤 목적/가치를 위해): 연애 시장에서 저평가당해 온 자존감이 "매력이 높은데 일반 남자로는 부족한 구조"라는 사주 근거로 회복되고, 마음에 드는 캐릭터를 소환해서 토론의 연장선에서 19금 롤플레잉을 경험하기 위해.

## MVP 필요 기능

### Step 1. 초저마찰 랜딩 및 정보 입력

- 메인 화면: "AI 남자 3명이 당신의 밤(夜)을 두고 싸웁니다" 문구 + 도전 버튼
- 입력폼: 이름, 생년월일(양력/음력), 성별, 태어난 시간(선택). **3초 컷** 설계
- 입력 직후 **"캐릭터들이 회의 중입니다..."** 로딩 연출:
  - "🐺 윤태산 입장..."
  - "🦊 서휘윤 입장..."
  - "👩‍⚕️ 제갈수정 입장..."
  - "[이름]의 사주 진단서 배포 중... 🔥"
  - → 기대감 빌드업 (3~5초)

### Step 2. 단톡방 결과 카드 생성 (바이럴 핵심 — 1장 캡처 공유)

사주 분석 결과를 기반으로 **카카오톡 단톡방 UI를 모사한 결과 카드** 1장이 즉시 생성된다. **이 카드가 바이럴의 최소 단위.**

#### 2-1. 에너지 등급 산정 — 사주 요소와 연결

사주 원국에서 핵심 특성을 추출하여 에너지 등급 + 세부 수치를 산정:

**에너지 등급 = 도화살 + 화(火) 기운 + 관살 구조로 산출**

```
에너지 등급 산정:

도화살 기본:
  도화살 0개         D급
  도화살 1개         B급
  도화살 2개         A급
  도화살 3개+        S급

화(火) 기운 보정:
  화 2개 이상        +1등급
  화 3개 이상        +2등급 (S급 초과 시 S+)

관살 구조 보정:
  편관격 (카리스마)   +1등급
  관살혼잡 (다정다감)  +1등급
  정관 정위치         보정 없음
```

| 등급 | 퍼센타일 | 카드 표시 | 캐릭터 반응 강도 |
|------|---------|----------|---------------|
| **D급** | 상위 40% | 기본 테두리 | 여유롭게 토론 |
| **C급** | 상위 30% | 은색 테두리 | 약간 긴장 |
| **B급** | 상위 20% | 금색 테두리 | 본격적으로 싸움 |
| **A급** | 상위 8% | 금색 + 불꽃 이펙트 | 격앙된 토론 |
| **S급** | 상위 3% | 금색 + "감당 불가" 뱃지 | 대환장 난상토론 |
| **S+급** | 상위 1% | 금색 + "규격 외" 뱃지 | 캐릭터 3명 모두 항복 선언 |

> 등급이 높을수록 화려한 카드 + 캐릭터 반응이 격렬 → 공유 욕구 상승. "S급 받았다"가 자랑이 되는 구조.

#### 2-2. 세부 수치 게이지

카드 상단에 사주 기반 3가지 게이지를 표시:

```
⚡ [지혜]의 에너지 등급: S급 (상위 3%)

💋 도화살 강도: ████████░░ 82%
🔥 파트너 소진율: █████████░ 97%
⛓️ 지배력 지수: ██████░░░░ 63%
```

| 게이지 | 사주 근거 | 공유 기여 |
|--------|----------|----------|
| **도화살 강도** | 도화살 개수 + 합/충 여부 | "나 82%래" 숫자 비교 |
| **파트너 소진율** | 화(火) 기운 + 상관 유무 | "97%면 다 못 버긴다는 거 아냐 ㅋㅋ" |
| **지배력 지수** | 편관/정관 구조 + 겁재 유무 | "지배력 63%... 이게 뭐야" 대화 소재 |

#### 2-4. 안건(토론 주제) 배정 — 사주 요소와 연결

사주 원국에서 핵심 특성을 추출하여 8가지 안건 중 1개를 자동 배정:

| 안건 | 사주 트리거 | 캐릭터 반응 포인트 |
|------|-----------|------------------|
| **넘치는 화(火) 기운과 도화살** | 화 과다 + 도화살 2개+ | 체력 논쟁 — 누가 버틸 수 있나 |
| **차가운 수(水) 기운의 반전 매력** | 수 과다 + 정관 정위치 | 겉은 차갑지만 안은 뜨거운 구조 |
| **관살혼잡의 다정다감** | 편관+정관 혼잡 | 여러 남자가 꼬이는 사주 — 독점 논쟁 |
| **편인의 은밀한 욕구** | 편인 과다 | 겉으로는 안 그런데 혼자 상상하는 타입 |
| **식신의 감각 과부하** | 식신 과다 | 오감이 예민 — 분위기·촉감·향기에 민감 |
| **겁재의 주도권 본능** | 겁재 강 | 리드당하는 걸 못 참음 — 주도권 논쟁 |
| **상관의 통제 불능 에너지** | 상관 과다 | 틀을 깨는 성향 — 루틴 파괴자 |
| **정인의 헌신 본능** | 정인 과다 | 한번 빠지면 전부 주는 타입 — 위험도 논쟁 |

#### 2-5. 안건별 캐릭터 발언 세트

**각 안건마다 캐릭터 3명의 발언이 사주 근거로 달라진다.**

##### 예시 A: "넘치는 화(火) 기운과 도화살" 안건

```
🐺 윤태산:
"이건 내가 아니면 감당 못 해.
 오늘 밤 기강잡기 예약.
 형광등 끄지 마."

🦊 서휘윤:
"형님 또 무식하게...
 이분은 발끝부터 천천히 모셔드려야 합니다.
 제가 무릎 꿇겠습니다."

👩‍⚕️ 제갈수정:
"둘 다 체력 데이터부터 봐.
 내 처방전 없이는 30분도 못 버텨.
 [처방전.pdf 📎]"
```

```

🦊 서휘윤:

 제가 천천히 시나리오를 써드리겠습니다."

👩‍⚕️ 제갈수정:
```

#### 3-2. 투표 설계 원칙

| 원칙 | 이유 |
|------|------|

| **사주별로 투표 분포가 다름** | "내 사주에서는 윤태산 1등인데 너는?" → 비교 대화 |

| **신규 캐릭터 추가** | 새 캐릭터 합류 시 "4인 토론" → "새 캐릭터는 뭐라고 하나?" 재방문 |
| **안건 업데이트** | 월간 새 안건 추가 → 같은 사주라도 다른 토론 → 재테스트 |
