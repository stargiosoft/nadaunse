## 7. 미래예측기에 대한 인사이트

### 7-1. 태도 테스트 문항 개선 방향

#### 연애 카테고리
- 현재: 애착유형 (안정/불안/회피) — 방향은 맞음
- **개선**: 재회/복합(81K)이 매우 강세 → "과거 관계 집착도" 축 추가 고려
- 배우자상(94K) 질문 패턴 → "이상화 경향" 측정 가능
- 상대마음확인(17K) → "통제 욕구" 측정

#### 재물 카테고리
- 현재: 소비성향 (절약/균형/소비)
- **수정 필요**: 복권/횡재(16K)는 소수, 금전운일반(143K)이 핵심
- 실제 축은 **"재물 불안도 + 계획성"** (운빨의존 vs 계획적 축적)
- "왜 가난해", "돈벼락 맞고 싶다" → 재물 불안/무력감이 진짜 유저 감정

#### 커리어 카테고리
- 현재: 동기유형 (안정/인정/도전) — 부분 맞음
- **보강**: 시험/합격(102K)이 적성/진로(52K)보다 2배 강세
- "합격 타이밍" 질문 패턴 → 커리어에서도 운명론 경향 강함
- "회사 힘들다"(이직/퇴사 34K) → **현재 고통 수준** 측정 추가

#### 건강 카테고리
- 데이터 상 독립 질문 적음 (48K), 다른 카테고리 부수적 언급이 많음
- 유저 관심 실체는 "스트레스/멘탈" 중심
- 5개 카테고리 유지 시 문항이 약할 수 있음 → 다른 카테고리와 통합 검토

#### 인간관계 카테고리
- 궁합(175K)이 압도적이나, 이는 "연애 궁합"에 가까움
- 순수 인간관계(가족, 직장 동료 갈등)는 상대적 소수
- 연애와 분리가 어려움 → 독립 카테고리 유지 여부 재검토

### 7-2. 운명론 지표 활용 전략

**데이터가 증명한 것**: 운명론과 행동지향은 이분법이 아님. 44%가 동시 보유.

**전환 퍼널 모델**:
```
"언제쯤 될까?" (운명론 진입)
    ↓ 스펙트럼 결과로 불안 촉발
"어떻게 바꿀 수 있지?" (행동지향 전환)
    ↓ 유료 보고서 CTA
조언 보고서 구매
```

**구현 방향**:
1. `fatalism_score`를 태도 테스트에서 숨은 축으로 측정 (라벨 노출 안 함)
2. 결과 화면에서는 "언제" 프레임을 먼저 만족시킴 (스펙트럼 위치 = 시기적 흐름)
3. 유료 보고서에서 "어떻게" 로 전환 (사주 언어로 행동 변화 유도)
4. 운명론 높은 유저 → AI 프롬프트 톤: "사주 흐름을 타는 법" (운명론 수용 → 행동 유도)
5. 운명론 낮은 유저 → AI 프롬프트 톤: "구체적 실행 계획" (직접적 조언)
