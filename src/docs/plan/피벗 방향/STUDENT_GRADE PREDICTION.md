# 피벗 전략: 의대 적합도 진단 → 상위권 학생 커뮤니티 → B2B 학원 매칭

> **작성일**: 2026-03-18
> **상태**: 전략 수립 단계
> **기반**: 7대 죄악 비즈니스 프레임워크 + 나다운세 34,942회 콘텐츠 데이터 분석
> **핵심 자산 재활용**: 미래 예측기 (FUTURE_PREDICTION_PLAN.md) 코드 ~70% 재사용

## 1. 왜 피벗하는가

### 나다운세 데이터가 증명한 것

| 발견 | 수치 |
|------|------|
| 전체 트래픽의 58.8%가 "시기+음욕"(관계 불안) | 연애+궁합+이별 = 20,531회 |
| 33.1%가 "오만+탐욕"(자기 확인) | 개인운세+직업+재물 = 11,562회 |
| 가장 강력한 결제 동기 | "나를 더 깊이 알고 싶다"(오만) |
| 탐욕을 직접 말하면 안 팔림 | 재물 카테고리 681회 vs 리즈시절 2,619회 |

### 운세 시장의 한계

- "AI가 분석해줍니다" = ChatGPT가 바로 대체 가능
- 1회성 소비 구조 → 반복 결제 어려움
- 네트워크 효과/데이터 축적/실물 연결 없음

### 피벗 방향: ChatGPT가 대체 불가능한 구조

| 해자(Moat) | 운세 사업 | 새 사업 |
|-----------|----------|--------|
| 네트워크 효과 | 없음 | **등급별 커뮤니티** — 유저 많을수록 가치 상승 |
| 데이터 축적 | 없음 | **성적+기질 데이터** — 쓸수록 정확, 떠나면 리셋 |
| 실물 연결 | 없음 | **학원/과외 매칭** — 현실 세계 연동 |

## 2. 사업 구조: 3단계 욕망 엔진

### 전체 구조도

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  STEP 1. 바이럴 진입 — "의대갈 그릇일까?"               │
│  ┌────────────────────────────────────────────┐         │
│  │ 오만: "나는 의대 갈 수 있는 사람일까?"      │         │
│  │ 시기: "걔는 됐는데 나는?"                   │         │
│  │ 분노: "성적만으로 판단하지 마"               │         │
│  │                                            │         │
│  │ → 태도 설문 + 기질 태그 + 모평 성적 입력     │         │
│  │ → AI가 "의대 적합도" 등급 + 상위% 부여       │         │
│  │ → 결과 공유 → 바이럴                        │         │
│  └────────────────────────────────────────────┘         │
│          ↓                                              │
│  STEP 2. 커뮤니티 Lock-in — 등급별 대나무숲             │
│  ┌────────────────────────────────────────────┐         │
│  │ 오만: "S등급 방에 들어갈 수 있다" (소속감)   │         │
│  │ 시기: "A등급인데 S등급 방은 뭐가 다를까?"    │         │
│  │ 나태: "수준 맞는 애들 정보만 걸러서 보기"    │         │
│  │                                            │         │
│  │ → 등급별 폐쇄 채팅방 (익명 대나무숲)         │         │
│  │ → 등급 올리면 상위 방 해금 (에스컬레이션)    │         │
│  └────────────────────────────────────────────┘         │
│          ↓                                              │
│  STEP 3. B2B 수익화 — 학원/과외 매칭                    │
│  ┌────────────────────────────────────────────┐         │
│  │ 학원: "상위권 학생 데이터가 필요해"           │         │
│  │ 학생: "좋은 학원/과외 추천받고 싶어"          │         │
│  │                                            │         │
│  │ → 등급별 타겟 광고 (학원 → 학생)             │         │
│  │ → 과외/학원 매칭 수수료                      │         │
│  │ → 지역 학습 데이터 리포트 판매               │         │
│  └────────────────────────────────────────────┘         │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 욕망 작동 메커니즘 (7대 죄악 프레임워크 적용)

| 욕망 | 역할 | 구체적 장치 |
|------|------|-----------|
| **오만 (Pride)** | 핵심 엔진 | 등급 부여, 상위%, "기질은 S급", 배타적 방 소속 |
| **시기 (Envy)** | 바이럴 엔진 | 결과 공유 FOMO, 상위 방 궁금증, 친구 비교 |
| **나태 (Sloth)** | 체류 엔진 | AI 자동 분석, 등급별 정보 필터링, 대나무숲 가볍게 읽기 |
| **분노 (Wrath)** | 전환 촉매 | "성적만으로 판단하지 마" → 기질 검사 결제 동기 |
| **탐욕 (Greed)** | 숨은 동기 | "의대 합격 = 인생 역전" (직접 말하지 않고 오만으로 포장) |

### Hook Model 설계

```
① External Trigger: "의대갈 그릇일까?" 바이럴 콘텐츠
     ↓
② Internal Trigger: "나도 해봐야지" (시기) → 습관화 후 "성적 바뀌었으니 다시 해봐야지"
     ↓
③ Variable Reward: 매번 다른 등급/유형/상위%, 커뮤니티 새 글
     ↓
④ Investment: 내 성적+기질 데이터 축적, 커뮤니티 활동 이력 → 떠나면 리셋
     ↓
     ①로 복귀 (성적 변동 시 재진단, 친구 초대)
```

### PAS 공식 적용

| 단계 | 내용 | 활용 욕망 |
|------|------|----------|
| **Problem** | "의대 가고 싶은데, 내가 될 그릇인지 모르겠어" | 시기, 분노 |
| **Agitation** | "성적만 보면 애매한데, 기질까지 보면 답이 달라질 수도" | 오만(체면), 시기(격차) |
| **Solution** | "AI가 성적+기질+남은 시간을 종합 분석해드립니다" | 나태(쉬운 해결) |

## 3. 진단 플로우 상세

### 전체 플로우

```
[랜딩] "의대갈 그릇일까?"
  다크 그라데이션, 후킹 카피, CTA
  ↓
[태도 설문] 7문항 (게이밍 방지 설계)
  트레이드오프 / 스펙트럼 / 상황반응 / 강제순위 / 역채점
  ↓
[기질 태그 선택] 기존 태그 시스템 재활용
  긍정:부정 1:1 노출, 최소 5개 선택
  ↓
[성적 입력] 국/수/영 등급 + 선택과목 + 학년
  → 수능 D-day 자동 계산
  ↓
[AI 로딩] 종합 평가
  ↓
[결과] 등급 + 상위% + 유형 + 온톨로지 그래프
  → 공유 버튼 (바이럴)
  → "커뮤니티 입장" CTA
```

### 성적 입력 설계

| 항목 | 입력 방식 | 필수 여부 |
|------|----------|----------|
| 국어 등급 | 1~9 선택 | 필수 |
| 수학 등급 | 1~9 선택 | 필수 |
| 영어 등급 | 1~9 선택 | 필수 |
| 선택과목 (탐구 2개) | 과목명 + 등급 | 선택 |
| 학년 | 중3 / 고1 / 고2 / 고3 / N수 | 필수 |
| 최근 모의고사 시기 | 2026년 3월, 6월, 9월, 수능 등 | 필수 |

**수능 D-day 활용**:

```
같은 국수영 3등급이라도:

고2 (D-600)  → "잠재력 폭발 직전, 지금이 골든타임"
고3 3월 (D-250) → "전략적 집중이 필요한 시점"
고3 9월 (D-70)  → "기질은 충분하지만 시간 변수 주의"
N수 (D-250)     → "경험치가 무기, 기질과 전략의 싸움"
```

### 등급 체계

| 등급 | 의미 | 부여 기준 |
|------|------|----------|
| **S** | 의대 DNA | 성적 1~2등급 + 기질 최상위 + 충분한 시간 |
| **A** | 높은 적합도 | 성적 or 기질 중 하나 최상위 |
| **B** | 잠재력 보유 | 기질은 있으나 성적 갭 or 시간 부족 |
| **C** | 전환 필요 | 성적/기질 모두 보완 필요 |
| **D** | 다른 길 탐색 | 의대보다 적합한 진로 존재 |

**핵심 설계**: 성적이 낮아도 기질로 S/A 가능, 성적이 높아도 기질로 B/C 가능
→ "성적 3등급인데 기질 S급" = 오만 폭발 → 공유 → 바이럴
→ "성적 1등급인데 기질 B급" = 분노 → 상세 리포트 결제

## 4. 어뷰징 방지 설문 설계

### 원칙: "좋은 답"이 존재하지 않는 구조

### 5가지 기법

#### 기법 1: 트레이드오프 양자택일

둘 다 좋아 보이거나, 둘 다 별로여서 "정답"을 모르게 만드는 구조.

```
"시험 3일 전, 아직 안 본 범위가 30% 남았다"
a) 남은 30%를 빠르게 훑는다 → 리스크 감수형
b) 이미 본 70%를 완벽하게 다진다 → 완벽주의형
c) 비율을 나눠서 둘 다 한다 → 전략형
```

#### 기법 2: 스펙트럼 슬라이더

선택지가 아닌 스펙트럼으로 받으면 "정답 찾기" 자체가 불가능.

```
← 완벽하게 준비하고 시작  |━━━━●━━━━|  일단 시작하고 수정 →
← 혼자 집중이 잘 됨      |━━━━━━●━━|  같이 해야 집중됨 →
← 계획대로 해야 편함      |━●━━━━━━━|  즉흥적이어야 편함 →
```

#### 기법 3: 상황 기반 반응

자기 평가가 아닌, 구체적 상황에서의 반응을 측정.

```
"모의고사 성적이 갑자기 2등급 떨어졌다. 가장 먼저 드는 생각은?"
a) 뭐가 문제였는지 바로 분석해야지 → 분석형
b) 컨디션 문제였을 수도 있으니 다음에 → 낙관형
c) 솔직히 좀 무너진다 → 감성형
d) 오히려 자극 받는다 → 투쟁형
```

#### 기법 4: 강제 순위 배분 (Forced Ranking)

"다 중요하다"를 못 하게 만들어서 진짜 우선순위를 드러냄.

```
"수능까지 6개월. 100포인트를 배분하세요"
□ 취약 과목 집중 공격     [___]점
□ 전 과목 고른 유지       [___]점
□ 멘탈/체력 관리          [___]점
□ 실전 모의고사 반복      [___]점
                    합계: 100점
```

#### 기법 5: 역채점 함정 문항

"성실해 보이는 답"이 실은 부정적 지표인 문항.

```
"공부할 때 나는..."
a) 계획표를 세밀하게 짜고 반드시 지킨다
   → 겉보기 좋음, 실제: 과도한 통제 욕구 = 번아웃 리스크
b) 대략적인 방향만 정하고 유연하게 한다
   → 겉보기 불성실, 실제: 적응력 지표
```

### 설문 구성 (7문항)

| # | 유형 | 측정 요소 | 게이밍 방지 원리 |
|---|------|----------|----------------|
| 1 | 트레이드오프 | 학습 전략 | 둘 다 유효한 답 |
| 2 | 스펙트럼 | 계획성↔유연성 | 정답 없는 축 |
| 3 | 상황 반응 | 회복 탄력성 | 행동 기반 (자기 평가 아님) |
| 4 | 트레이드오프 | 대인 갈등 처리 | 둘 다 유효한 답 |
| 5 | 강제 순위 | 우선순위 판단 | 배분 자체가 데이터 |
| 6 | 상황 반응 | 압박 상황 대처 | 전부 현실적 반응 |
| 7 | 역채점 함정 | 자기 관리 | "좋은 답"이 함정 |

## 5. 커뮤니티 설계

### 등급별 대나무숲

| 방 | 접근 조건 | 분위기 |
|----|----------|--------|
| **S방** | S등급 인증 | 최상위권 정보 공유, 멘토 역할 |
| **A방** | A등급 이상 | 상위권 학습법, 동기 부여 |
| **B방** | B등급 이상 | 성장 과정 공유, 질문 활발 |
| **전체 라운지** | 누구나 | 자유 대화, 가벼운 고민 |

### Lock-in 장치

| 장치 | 작동 방식 | 욕망 |
|------|----------|------|
| 등급 재진단 | 모의고사 시즌마다 재진단 유도 → 등급 변동 | 시기 |
| 상위 방 엿보기 | A등급 유저에게 "S방 인기글 TOP3" 미리보기 노출 | 시기+오만 |
| 활동 뱃지 | 답변 많이 한 유저에게 "멘토" 뱃지 | 오만 |
| 성적 인증 마크 | 성적표 사진 인증 시 🏅 마크 → 발언 신뢰도 상승 | 오만 |
| 학교별/지역별 랭킹 | "우리 학교 S등급 몇 명?" | 시기 |

### 에스컬레이션 구조

```
① 바이럴 진입 (등급 받음)
     ↓
② 자기 등급 방 활동 (데이터 축적)
     ↓
③ 상위 방 궁금증 (시기)
     ↓
④ 재진단으로 등급 올리기 시도 (재방문)
     ↓
⑤ 등급 올라감 → 상위 방 해금 (오만 보상)
     ↓
     ②로 복귀 (중독 루프)
```

## 6. 수익 모델

### B2C (학생 대상) — 저가/무료 중심

| 무료 | 유료 (저가) |
|------|------------|
| 의대 적합도 기본 결과 | 상세 분석 리포트 (2,900원) |
| 자기 등급 방 접근 | 상위 등급 방 엿보기 (990원/주) |
| 기본 커뮤니티 | 멘토 1:1 질문 (건당 500원) |

### B2B (학원/과외 대상) — 핵심 매출

| 수익원 | 모델 | 예상 단가 |
|--------|------|----------|
| **등급별 타겟 광고** | CPM/CPC | 클릭당 500~2,000원 |
| **학원 프로필 페이지** | 월 구독 | 월 10~50만원 |
| **우수학생 매칭** | 건당 수수료 | 건당 3~10만원 |
| **지역 학습 데이터 리포트** | 분기 구독 | 분기 50~200만원 |

### 학원이 돈을 내는 이유

```
① 타겟 정밀도: "S/A등급 학생에게만 노출" → 전환율 극상
② 우수 학생 확보: "우리 학원 합격생"으로 쓸 레퍼런스 학생 모집
③ 데이터: "이 지역 상위권 학생들의 학습 성향" 인사이트
④ 경쟁 우위: 학원 간 학생 유치 경쟁에서 선점
```

## 7. 성적 데이터 수집 전략 (단계별)

### 현실: 한국에 학생 성적 API는 없다

| 경로 | 현황 |
|------|------|
| 나이스 Open API | 학교 기본정보/급식/시간표만 공개, **개인 성적 없음** |
| 나이스 학생/학부모 서비스 | 공인인증서 필수, **외부 연동 API 없음** |
| EBS/족보닷컴/수학대왕 | 자체 서비스 내에서만, **외부 API 없음** |

### 단계별 해결

```
Phase 1 (MVP): 자기 신고 — 국/수/영 등급 직접 입력
  → 허들 제로 (3초면 끝)
  → 기질 검사와 교차 검증으로 뻥 감지
  → "의대갈 그릇일까?" 결과에서 성적보다 기질에 무게
  → 등급은 기질 기반으로 먼저 부여

Phase 2 (검증 후): 성적표 사진 OCR 추가
  → "성적표 인증하면 정확도 +30% 업그레이드"
  → GPT-4o Vision으로 나이스 성적표 자동 파싱
  → 인증 유저에게 🏅 뱃지 → 오만 자극
  → 인증 유저만 상위 등급 방 접근 가능

Phase 3 (스케일): 에듀테크 앱 제휴
  → 유저풀 10만+ 확보 후 족보닷컴/수학대왕과 협상
  → OAuth로 성적 자동 동기화
```

### 뻥(자기 신고 위조) 대응

| 방법 | 설명 |
|------|------|
| 기질-성적 교차 검증 | 성적 1등급인데 기질 검사에서 학습 습관 불일치 → 플래그 |
| 커뮤니티 자정 | S방에서 대화 수준이 안 맞으면 자연스럽게 들킴 |
| 인증 뱃지 차별화 | 성적표 인증자에게 특별 마크 → 미인증자 발언 신뢰도 자연 하락 |
| 재진단 일관성 | 매 모의고사 시즌 재진단 → 매번 1등급 신고하기 어려움 |

## 8. 기존 자산 재활용 맵

### 미래 예측기 → 의대 적합도 진단

| 기존 자산 | 새 비즈니스에서의 역할 | 수정 범위 |
|----------|---------------------|----------|
| 태도 테스트 (HEXACO 5문항) | 기질 검사 (7문항, 게이밍 방지 설계) | 문항 교체 |
| 태그 선택 시스템 (243개) | 학습 스타일 태그 | 태그 일부 추가/교체 |
| 온톨로지 5계층 그래프 | "의대 적합도" 시각화 | 프롬프트 변경 |
| 스펙트럼 (극적 결과 유도) | 등급/상위% 부여 | 채점 로직 추가 |
| 궁합 시뮬레이션 | "친구와 비교하기" 바이럴 | 거의 그대로 |
| 간극 분석 | "현재 성적 vs 의대 합격선" 간극 | 프롬프트 변경 |
| Edge Functions 구조 | 동일 아키텍처 | 프롬프트만 교체 |
| 카카오 공유 | 동일 | 공유 카피 변경 |

### 신규 개발 필요

| 기능 | 설명 | 규모 |
|------|------|------|
| 성적 입력 페이지 | 국/수/영 등급 + 학년 + 모의고사 시기 | 소 |
| 등급 부여 로직 | 성적+기질+D-day 종합 채점 | 중 |
| 커뮤니티 (등급별 방) | 대나무숲 형태 익명 게시판 | 대 |
| 학원 B2B 대시보드 | 광고 관리, 매칭 관리 | 대 (후순위) |

## 9. 경쟁 환경

### 현재 시장: 상위권 학생 전용 커뮤니티는 없다

| 플랫폼 | 대상 | 성적 필터 | 우리와의 차이 |
|--------|------|----------|-------------|
| 오르비 | 수험생 | 없음 | 누구나 가입, 정보 품질 들쭉날쭉 |
| OMG | 중고등학생 | 없음 | 익명 투표 SNS, 학습과 무관 |
| 에브리타임 | **대학생** | 학교 인증 | 중고등학생 대상 아님 |
| 급식판 | 고등학생 | 없음 | 익명 커뮤니티, 필터 없음 |

**빈 자리**: 성적/기질로 필터링된 폐쇄 커뮤니티 = 아무도 안 건드린 영역

### 진입 장벽이 된 이유 (= 우리의 기회)

1. 성적 인증이 어렵다 → **자기 신고 + 기질 교차 검증으로 우회**
2. 학생 대상이라 수익화 어렵다 → **B2B(학원)로 돈 벌기**
3. "차별" 비판 리스크 → **"유형"으로 포장, 성적 순위가 아닌 "적합도"**

## 10. 리스크와 대응

| 리스크 | 심각도 | 대응 |
|--------|--------|------|
| "차별/엘리트주의" 논란 | 높음 | 등급을 "유형"으로 포장 (탐구형/도전형/잠재형), "적합도"로 프레이밍 |
| 성적표 위조 | 중간 | Phase 1은 기질 중심, Phase 2에서 OCR 인증 도입 |
| 학생 결제력 부족 | 중간 | B2C는 무료/저가, 핵심 매출은 B2B |
| 학부모 반발 | 중간 | "학습 성향 분석 + 맞춤 학원 추천"으로 학부모도 타겟 |
| 미성년자 개인정보 | 높음 | 14세 이상 법정대리인 동의, 최소 수집 원칙 |
| 커뮤니티 관리 | 높음 | 익명이되 AI 모더레이션 + 신고 시스템 |

## 11. 실행 로드맵

### Phase 1: MVP — 바이럴 진단 (4주)

```
Week 1-2: 설문 + 성적 입력 + AI 평가 로직
  - 기존 미래 예측기 플로우 포크
  - 7문항 설문 구현
  - 국/수/영 입력 + D-day 계산
  - Edge Function: 종합 평가 프롬프트

Week 3: 결과 페이지 + 바이럴
  - 등급/상위%/유형 결과 카드
  - 카카오 공유 (기존 시스템 재활용)
  - "친구와 비교하기" (궁합 시스템 재활용)

Week 4: 테스트 + 배포
  - iOS Safari 테스트
  - 바이럴 루프 E2E 테스트
  - 랜딩 → staging → production
```

### Phase 2: 커뮤니티 (4주)

```
Week 5-6: 등급별 대나무숲
  - 익명 게시판 CRUD
  - 등급별 방 접근 제어
  - 실시간 or 폴링 기반

Week 7-8: Lock-in 장치
  - 재진단 유도 (모의고사 시즌)
  - 활동 뱃지
  - 성적표 OCR 인증
```

### Phase 3: B2B 수익화 (4주)

```
Week 9-10: 학원 대시보드
  - 학원 회원 가입/프로필
  - 타겟 광고 집행 UI

Week 11-12: 매칭 + 데이터
  - 학생-학원 매칭 시스템
  - 지역별 학습 데이터 리포트
```

## 12. 확장 가능성

### 의대 외 주제 확장

"의대갈 그릇일까?"가 검증되면 동일 구조로:

| 주제 | 바이럴 후킹 | 타겟 |
|------|-----------|------|
| **로스쿨 갈 그릇일까?** | 법학 적합도 | 법대 지망생 |
| **SKY 갈 그릇일까?** | 상위권 적합도 | 고등학생 전체 |
| **공무원 될 그릇일까?** | 공시 적합도 | 공시생 |
| **창업할 그릇일까?** | 창업가 적합도 | 대학생/직장인 |

### 데이터 기반 확장

```
유저 10만+ 성적+기질 데이터 축적
  → 실제 합격 데이터와 매칭 (추후)
  → "이 기질+성적 조합의 의대 합격률 67%"
  → 데이터가 쌓일수록 정확도 상승 = 경쟁자 진입 불가
```
