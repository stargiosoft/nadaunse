## 3. 고객 핵심 불만 (페인포인트)

### 불만 1: "돈만 받고 사기" — 신뢰 공백

> "처음 문의했을 때 바로 상담받았으면 성공률 45%였지만, 지금은 30%로 떨어졌다. 더 비싼 코스를 선택하지 않으면 이별을 받아들이는 게 낫다"
> — 매경 기사, B사 상담 사례

- 공포 마케팅 + FOMO로 결제 종용
- 재회 실패하면 "내담자 탓" → 책임 회피 구조
- 통신판매업 신고도 안 한 불법 업체 90% 이상 (클리앙 분석)

### 불만 2: "아바타가 됐다" — 자기 상실

> "2달 넘는 시간동안 돈도 돈이지만 스스로 바뀐 것도 없이 아바타가 된 거 같은 생각이 들었습니다"
> — 역대최고 후기, 타 업체 피해자

- 지침 문자 대필, 카톡 대신 써주기 → 본인 성장 없음
- 상담 기간 동안 상담사에 심리적 의존 → 종료 시 공허감

### 불만 3: "위험한 지침" — 안전 문제

> "전 남자친구에게 극단적 선택하겠다고 카카오톡 메시지 보내"
> — 매경 기사, A상담소 지침

- 비전문가의 위험한 행동 지시
- 서울대 곽금주 교수: "전문가가 아닌 사람에게 상담받는 건 심리적 지배를 당할 수 있고 매우 위험"

### 불만 4: "진짜 전문가가 없다" — 전문성 부재

> "이 업계에 전문적인 자격증을 가진 사람이 어디 있겠나. 재회가 안 되면 내담자 탓을 하면 된다"
> — 매경 기사, 현직 연애 컨설턴트

- "연애 전공" 자체가 학계에 존재하지 않음 (곽금주 교수)
- 아트라상의 "재회심리학"도 자체 명명한 용어

## 4. 고객이 원하지만 현재 시장이 못 채우는 것

### 갭 1: "저가 + 객관적 진단" — 가격 공백

| 현재 | 갭 | 기회 |
|------|-----|------|
| 최소 100만원 | 1만~5만원대 자가진단 도구 없음 | **저렴한 1차 스크리닝** |
| "재회 가능성 90%" 허위 홍보 | 솔직한 가능성 진단이 오히려 신뢰 형성 | **확률을 정직하게 말해주는 서비스** |

마크최 사례가 증거: "30%라고 솔직하게 말했을 때 오히려 신뢰가 생겼다"

### 갭 2: "자기 변화 중심" — 관점 전환

| 현재 | 갭 | 기회 |
|------|-----|------|
| "상대를 어떻게 조종할까" | 내가 어떻게 변할까 | **자기이해/성장 프로그램** |
| 재회만 유일한 목표 | 이별 수용도 건강한 결론 | **어떤 결과든 성장하는 프레임** |
| 상담사 의존 (아바타화) | 스스로 판단력 키우기 | **셀프 코칭 도구** |

### 갭 3: "이별 직후 냉각기" — 충동 결제 방지

| 현재 | 갭 | 기회 |
|------|-----|------|
| 이별 직후 수백만원 충동 결제 | 감정 안정 후 합리적 판단 유도 | **무료~소액 AI 1차 상담** |
| 즉시 "재회 프로그램 등록" 종용 | 48시간 냉각기 + 자가진단 | **감정 토로 → 냉정한 분석** |

### 갭 4: "이별 극복" — 재회가 아닌 방향

| 현재 | 갭 | 기회 |
|------|-----|------|
| 모든 서비스가 "재회 성공" 약속 | 이별을 건강하게 받아들이는 서비스 없음 | **이별 회복 타임라인** |
| 재회 실패 → 더 큰 상실감 | 실패해도 성장하는 프레임 | **연애 패턴 자기진단** |
| Threads에서 "회피형" "연애 못하는 이유" 인기 | 자기이해 + 다음 연애 준비 | **나다움 유형 기반 연애 리포트** |

## 5. 진입 가능한 서비스 설계

### Option A: 재회 가능성 진단 (사주/AI 기반)

```
[이별 상황 입력] → [사주 궁합 + 이별 유형 분석] → [재회 가능성 %] + [원인 분석] + [지금 할 수 있는 것]
```

- **차별점**: 솔직한 확률 + "왜 헤어졌는지" 원인에 집중
- **가격**: 3,000~9,900원 (현재 시장 100만원+ 대비 1/100)
- **강점**: 충동 결제 방지 역할 → 이 서비스 먼저 보고 나서 고가 상담 결정해도 됨

### Option B: 이별 회복 타임라인

```
[사주 정보 입력] → [감정 흐름 예측: 1주/1달/3달/6달] → [시기별 할 일 가이드]
```

- **차별점**: "언제쯤 마음이 풀리는지" 시기 예측 (사주 대운/세운 기반)
- **프레임**: 재회든 이별 수용이든, **감정 회복 과정** 자체에 가치

### Option C: AI 이별 상담 챗봇 (마음토크 확장)

```
[24시간 감정 토로] → [AI 공감 + 패턴 분석] → [냉각 후 자가진단 리포트]
```

- **차별점**: 새벽 3시에도 가능 / 판단 없이 들어줌 / 저렴
- **위험 관리**: "확증편향 정당화" 문제 → **일정 시점에 객관적 분석 제공**

### Option D: 연애 체질 자가진단 (바이럴 + 전환)

```
[5~8개 질문] → [사주 오행 기반 연애 유형] → [이별 패턴 + 다음 연애 조언]
```

- **차별점**: 재회가 아닌 **자기이해** 관점
- **수익**: 무료 (바이럴 도구) → "더 자세한 연애운" 유료 전환

## 7. 핵심 인사이트

1. **재회 시장 = 신뢰 공백 시장**. 650만원짜리 컨설팅과 무료 유튜브 사이에 "저가 + 객관적 + 자기 변화 중심"의 중간 레이어가 완전히 비어 있음.

2. **"솔직함"이 차별점**. 마크최가 "30%"라고 말했을 때 오히려 신뢰를 얻은 사례가 핵심 증거. 과대 약속 대신 정직한 분석이 경쟁 우위.

3. **재회보다 "자기이해"가 더 큰 시장**. Threads 인기글 분석에서 "왜 안 되는지" 진단형이 가장 높은 인게이지먼트. 이건 나다운세의 본질(사주 기반 자기이해)과 정확히 일치.

4. **AI 상담의 "확증편향 강화" 리스크**를 인지하고, 일정 시점에 객관적 분석을 제공하는 구조 설계 필요.

5. **이별 직후 48시간이 골든타임**. 이 시간에 수백만원 충동 결제를 막아주는 "냉각기 서비스"가 곧 신뢰 형성 → 장기 고객 확보.
