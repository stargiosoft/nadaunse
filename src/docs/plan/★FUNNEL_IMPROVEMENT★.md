## 2. 문제 진단

### 2.1 첫 랜딩 페이지의 구조적 문제

**현상**
- 유료 상세 페이지로 바로 랜딩 → "돈 내야 하네" 인식 → 이탈

**브랜드 전략과의 괴리**
- "자기 긍정"이라는 핵심 가치를 전달하기 전에 결제 요청
- 아기 백조 캐릭터, "너는 네 시간대에 맞춰 가고 있어" 메시지가 첫 화면에 없음

**페르소나 니즈 미충족**
- 이지안(타겟 페르소나)이 원하는 건 "판단 없는 위로"
- 현재 첫 화면은 상품 판매 → 차갑고 거래적인 경험

### 2.2 무료 체험 퍼널 부재

**현상**
- 무료 운세 시도율 10.5% → 서비스 가치 체험 기회 부족

**경쟁사 대비 약점**
- 점신/포스텔러는 무료 콘텐츠로 먼저 신뢰 구축
- 나다운세는 바로 유료 결제 요청

**기술 자산의 낭비**
- FACS 시스템의 95% 정확도를 증명할 기회가 없음
- 518,400가지 사주 완전 커버라는 차별점 미노출

### 2.3 브랜드 정서 연결 부재

**현상**
- 아기 백조 캐릭터가 퍼널에서 부각되지 않음
- "다 때가 있을 뿐, 네 잘못이 아니야" 핵심 메시지 미노출

**Toast Out 상태 고객에게 필요한 것**
- 즉각적인 정서적 위로
- 비교하지 않아도 된다는 안심

**현재 경험**
- 광고 → 결제 화면 (정서적 연결 없음)

### 2.4 나다움 태그 확정율 급락

**가능한 원인**
1. 태그 생성 후 확정까지의 UX 허들
2. 태그의 가치를 체감하지 못함
3. 무료 체험 없이 태그 확정 요청 → 의미 부여 실패

## 3. 개선 전략

### Phase 1: 랜딩 경험 재설계 (즉시 실행)

#### 3.1.1 웰컴 퍼널 도입

**개선된 고객 여정**
```
사주GPT 광고 클릭
    ↓
[NEW] 웰컴 페이지: 아기 백조 + "너는 네 시간대에 잘 맞춰 가고 있어"
    ↓
[NEW] 무료 사주 맛보기 (생년월일만 입력)
    ↓
[NEW] 간단 결과 + "더 깊이 알아보기" CTA
    ↓
회원가입 (자연스러운 전환)
    ↓
무료 쿠폰으로 상세 운세 체험
```

#### 3.1.2 구현 작업

- [ ] 웰컴 랜딩 페이지 컴포넌트 개발
- [ ] 아기 백조 애니메이션 적용
- [ ] 무료 사주 맛보기 플로우 개발
- [ ] A/B 테스트 설정 (기존 vs 신규 퍼널)

### Phase 2: 브랜드 경험 강화 (1-2주)

#### 3.2.1 핵심 메시지 노출 강화

| 터치포인트 | 적용 메시지 |
|-----------|-----------|
| 로딩 화면 | 아기 백조 + 긍정 메시지 |
| 운세 결과 하단 | "다 때가 있을 뿐, 네 잘못이 아니야" |
| 부정적 결과 시 | AI 위로 메시지 자동 삽입 |

#### 3.2.2 나다움 태그 가치 강화

- 태그 생성 시 아기 백조가 "너만의 특별함을 찾았어!" 메시지
- 태그 확정 인센티브 (추가 무료 콘텐츠 잠금 해제)
- 태그 기반 개인화 운세 미리보기 제공

### Phase 3: 리텐션 루프 구축 (2-4주)

#### 3.3.1 재방문 유도 시스템

| 기능 | 설명 |
|------|------|
| 주간 보고서 | 아기 백조가 한 주 응원 (이메일/푸시) |
| 데일리 운세 알림 | "오늘의 너를 위한 한마디" |
| 성장 시스템 | 무료 운세 조회 → 백조 성장 시각화 |

#### 3.3.2 정서적 연결 강화

- 운세 히스토리 기록 + 감정 트래킹
- "나다운 순간" 모아보기 기능
- 긍정 메시지 아카이브
