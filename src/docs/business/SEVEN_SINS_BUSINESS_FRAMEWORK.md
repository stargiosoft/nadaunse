# 7대 죄악 비즈니스 프레임워크

> **목적**: 인간의 7대 본능(7 Deadly Sins)이 구매 동기로 작용하는 메커니즘을 분석하고,
> 본능을 결합하여 지속 가능한 비즈니스 모델을 설계하는 프레임워크.
>
> **핵심 전제**: 사업의 본질은 '인간의 욕구를 해결하고 대가를 받는 것'.
> 글로벌 100대 기업의 이면에는 도덕성보다 원초적 본능이 강력한 구매 동기로 작용한다.

---

## Part 1. 7대 본능과 글로벌 기업 맵핑

### 1. 오만 (Pride) — "당신은 특별합니다"

| 항목 | 내용 |
|------|------|
| **구매 동기** | 타인과 차별화, 우월감, 소속감 |
| **비즈니스 적용** | 한정판, 배타적 멤버십, 고가 정책(High-ticket) |
| **특징** | 가장 높은 이익률(마진)을 창출하는 영역 |

**글로벌 사례**:
- **Apple**: 전자기기가 아닌 '세련된 혁신 집단' 소속감을 판다 (아이메시지 파란색 말풍선)
- **LVMH**: 기능이 아닌 '희소성'과 '높은 가격' 그 자체를 판다

---

### 2. 시기 (Envy) — "나도 저렇게 살고 싶다"

| 항목 | 내용 |
|------|------|
| **구매 동기** | FOMO(뒤처짐 공포), 동경, 비교 심리 |
| **비즈니스 적용** | SNS 플랫폼, 인플루언서 마케팅, 한정판 리셀 |
| **특징** | 트렌드를 강제하고 끊임없는 비교를 만들어냄 |

**글로벌 사례**:
- **Meta (인스타그램)**: 타인의 하이라이트된 일상을 전시 → 시기심 → 광고/커머스 매출
- **ByteDance (틱톡)**: "유행에 뒤처지면 안 된다"는 심리로 압도적 체류 시간 확보

---

### 3. 분노 (Wrath) — "이 불합리함을 참을 수 없다"

| 항목 | 내용 |
|------|------|
| **구매 동기** | 부조리한 시스템에 대항, 권리/자산 보호 |
| **비즈니스 적용** | 중간상인 제거 플랫폼, 독과점 파괴, 법률/보안 서비스 |
| **특징** | 불편함과 억울함이 즉각적 행동을 유발 |

**글로벌 사례**:
- **Uber / Airbnb**: 불친절한 택시, 비싼 호텔에 대한 분노를 앱으로 파괴
- **CrowdStrike / Palo Alto Networks**: 해킹 피해의 억울함을 사전 차단하는 보안 서비스

---

### 4. 나태 (Sloth) — "내 시간과 수고를 아껴줘"

| 항목 | 내용 |
|------|------|
| **구매 동기** | 효율성/생산성 극대화, 수고 최소화 |
| **비즈니스 적용** | B2B SaaS, 온디맨드 배달, 자율주행, AI/로봇 자동화 |
| **특징** | 현재 글로벌 시가총액 최상위를 지배하는 가장 강력한 본능 |

**글로벌 사례**:
- **Amazon**: 원클릭 쇼핑으로 외출의 수고를 완전히 제거
- **Microsoft / Google / NVIDIA**: AI/클라우드로 업무를 대신해주고 시간을 압도적으로 단축

---

### 5. 탐욕 (Greed) — "더 많은 부를 원한다"

| 항목 | 내용 |
|------|------|
| **구매 동기** | 적은 자본/노력으로 큰 수익 추구 |
| **비즈니스 적용** | 핀테크, 투자/트레이딩, 성공학/재테크 지식 비즈니스 |
| **특징** | 자본주의의 근간, 끝없는 부 축적 욕망이 땔감 |

**글로벌 사례**:
- **JPMorgan Chase / BlackRock**: 고객 자산 증식 + 수수료 수익
- **Visa / Mastercard**: '돈이 흐르는 시스템' 자체를 사업화

---

### 6. 탐식 (Gluttony) — "더 자극적이고 맛있는 것을"

| 항목 | 내용 |
|------|------|
| **구매 동기** | 본능적 식욕 충족, 미각적 쾌락 |
| **비즈니스 적용** | 글로벌 F&B 프랜차이즈, 배달, 프리미엄 디저트 |
| **특징** | 가장 원초적이고 반복적인 소비 발생 영역 |

**글로벌 사례**:
- **Nestlé / Coca-Cola**: 달콤하고 짭짤한 가공식품으로 전 세계 미각을 길들임
- **DoorDash / Delivery Hero**: 탐식 + 나태를 결합 → 손가락만으로 음식 배달

---

### 7. 음욕 (Lust) — "더 매력적으로 보이고 싶다"

| 항목 | 내용 |
|------|------|
| **구매 동기** | 타인의 시선 의식, 자신을 아름답게 포장 |
| **비즈니스 적용** | 뷰티/성형, 다이어트/피트니스, 데이팅 앱 |
| **특징** | 생물학적 본능에 직관적으로 소구 |

**글로벌 사례**:
- **L'Oréal / Estée Lauder**: 화학제품이 아닌 '젊음, 아름다움, 환상'을 판매
- **Match Group (틴더)**: 만남이라는 본능적 영역을 게임화(Gamification) → 구독 수익

## Part 2. 본능 결합 메커니즘 — 메가 비즈니스의 탄생 공식

### 킬러 조합 매트릭스

글로벌 톱 기업들은 단 하나의 본능만 자극하지 않는다.
**2개 이상을 교묘하게 결합할 때 폭발적 시너지가 발생**한다.

| 조합 | 메커니즘 | 대표 기업 |
|------|---------|----------|
| **나태 + 탐식** | 노력 없이 쾌락 | 배달앱, 넷플릭스 |
| **시기 + 오만** | 비교 → 과시 소비 | 명품, SNS |
| **분노 + 나태** | 기존 불편함을 쉽게 해결 | 우버, 토스 |
| **탐욕 + 나태** | 자동으로 돈 벌기 | 로보어드바이저, AI SaaS |
| **음욕 + 시기** | 매력 경쟁 | 데이팅앱, 뷰티 |
| **오만 + 탐욕** | 엘리트 네트워크 | 골드만삭스, 아멕스 블랙카드 |

### 3개 이상 결합 = 메가 플랫폼

- **인스타그램**: 음욕 + 시기 + 오만 + 나태
- **아마존**: 나태 + 탐식 + 탐욕(저렴함) + 분노(기존 리테일 불편)
- **테슬라**: 오만(혁신 이미지) + 시기(모방 욕망) + 나태(자율주행)

## Part 3. 지속 가능한 비즈니스 설계 법칙

### 법칙 1: Hook Model (Nir Eyal) — 중독 루프

```
Trigger(자극) → Action(행동) → Variable Reward(가변 보상) → Investment(투자)
     ↑                                                          |
     └──────────────────────────────────────────────────────────┘
```

| 단계 | 설명 | 본능 연결 |
|------|------|----------|
| **External Trigger** | 본능을 건드리는 외부 자극 (알림, 광고) | 진입점 |
| **Internal Trigger** | 반복되면 감정 자체가 트리거 (불안→인스타 열기) | 습관화 |
| **Variable Reward** | 예측 불가능한 보상 = 도파민 (슬롯머신 원리) | 중독 |
| **Investment** | 사용자가 투자할수록 떠나기 어려움 (데이터, 팔로워) | 잠금 |

**핵심**: Trigger 단계에서 본능 2개 이상을 동시에 건드리면 Action 전환율이 폭발한다.

> 틱톡 = 시기(남들 다 보는데) + 나태(누워서 스와이프) + 음욕(매력적인 사람들)

---

### 법칙 2: PAS 공식 (Problem → Agitation → Solution)

문제를 "만드는" 게 아니라 **"인식시키는"** 것. 이미 존재하는 불편함을 언어화해주는 순간 시장이 생긴다.

| 단계 | 역할 | 활용 본능 |
|------|------|----------|
| **Problem** (문제 인식) | 고객이 몰랐던 문제를 발견하게 함 | 시기, 분노 |
| **Agitation** (증폭) | 방치 시 얼마나 나빠지는지 보여줌 | 오만(체면 손상), 시기(격차 벌어짐) |
| **Solution** (해결) | 우리 제품만이 유일한 해답 | 나태(쉬운 해결), 탐욕(이득) |

---

### 법칙 3: 모방 욕망 이론 (René Girard — Mimetic Desire)

피터 틸이 PayPal/Palantir를 만들 때 기반으로 삼은 철학.

> **인간은 자신이 원하는 것을 스스로 결정하지 못한다. 타인이 원하는 것을 원한다.**

```
모델(롤모델) → 욕망 전염 → 경쟁 → 갈등 → 희생양 메커니즘
```

- 시기 + 오만의 이론적 근거
- 인플루언서가 쓰면 → 나도 원함 (욕망 전염)
- 한정판이면 → 경쟁 격화 → 가격 폭등
- **설계 원칙**: 의도적으로 "모방 모델"을 배치하면 욕망이 자동 생성됨

> 테슬라: 일론 머스크라는 모방 모델 → "저 사람처럼 미래지향적이고 싶다" → 차를 삼

---

### 법칙 4: Lock-in + Escalation — 이탈 방지 구조

본능을 건드려서 유입시킨 후, **빠져나갈 수 없게** 만드는 구조:

```
① 본능 자극 (유입)
     ↓
② 데이터/관계/자산 축적 (Investment)
     ↓
③ 전환비용 증가 (Lock-in)
     ↓
④ 본능 강도 증가 (Escalation) — 더 강한 자극 필요
     ↓
⑤ ①로 복귀 (중독 루프 완성)
```

**실전 사례**:
- **넷플릭스**: 시청 기록 → 추천 정확도 향상 → 떠나면 추천 리셋
- **애플**: 에어드롭, 아이메시지, 에어팟 → 생태계 탈출 비용 극대화
- **인스타그램**: 팔로워 = 사회적 자산 → 플랫폼 이전 불가

## Part 4. 종합 — 망하지 않는 비즈니스의 3단계 공식

```
┌─────────────────────────────────────────────────┐
│                                                 │
│  ① 본능 2개 이상 교차 자극 (유입)                 │
│     → 킬러 조합 매트릭스에서 선택                 │
│                                                 │
│  ② 문제를 인식시키고 증폭 (전환)                  │
│     → PAS 공식 + 모방 욕망 이론                   │
│                                                 │
│  ③ 투자-잠금 루프로 이탈 방지 (유지)              │
│     → Hook Model + Lock-in/Escalation           │
│                                                 │
└─────────────────────────────────────────────────┘
```

이 세 가지가 겹치는 비즈니스는 **경기 불황에도 망하지 않는다**.
담배, 도박, SNS, 명품이 불황에 강한 이유가 정확히 이것이다.

### 자가 진단 체크리스트

| 질문 | 기준 |
|------|------|
| 우리 제품은 어떤 본능을 자극하는가? | 최소 2개 이상 |
| 문제를 인식시키는 언어가 있는가? | PAS 중 A(증폭) 존재 여부 |
| 모방 모델(롤모델)이 설계되어 있는가? | 모방 욕망 활용 여부 |
| 사용할수록 떠나기 어려운 구조인가? | Lock-in 메커니즘 존재 여부 |
| 더 강한 자극이 자연스럽게 에스컬레이션되는가? | 업셀/크로스셀 구조 |
