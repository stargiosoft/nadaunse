# 나다운세 운세 콘텐츠 전략 방향서

> **이 문서는 모든 운세 콘텐츠 기획·제작·수정의 기준이 됩니다.**
> 새 콘텐츠를 만들거나 기존 콘텐츠를 수정할 때 반드시 이 문서를 참고하세요.

---

## 1. 핵심 원칙

### 무료는 "거울", 유료는 "내비게이션"

| 구분 | 역할 | 비유 |
|------|------|------|
| **무료** | 나를 정확히 비춰주는 거울 | "와, 이게 나네?" |
| **유료** | 앞으로의 길을 안내하는 내비게이션 | "그래서 어떻게 하면 되는데?" |

무료 콘텐츠는 사용자가 **자기 자신을 발견**하고 소름 돋는 경험을 하게 만든다.
유료 콘텐츠는 그 발견 위에 **구체적인 시기, 장소, 대응법**을 제공한다.

---

## 2. 무료 vs 유료 질문 프레임워크

### 무료: Who + What + Why(대략)

| 질문 순서 | 프레임 | 핵심 | 예시 |
|-----------|--------|------|------|
| Q1 | **Who** | 나는 어떤 사람인가? | "내 사주에 숨겨진 연애 본능은?" |
| Q2 | **What** | 핵심 결론은 무엇인가? | "나에게 끌리는 이성의 유형은?" |
| Q3 | **What + Why(대략)** | 왜 그런 것인가? (간단한 이유) | "그 유형에 끌리는 사주적 원인은?" |

### 유료: Why(구체적) + When + Where + How

| 질문 순서 | 프레임 | 핵심 | 예시 |
|-----------|--------|------|------|
| Q1~Q2 | **Why(구체적)** | 십성 기반 심층 분석 | "편관과 정인의 충돌이 만드는 연애 패턴" |
| Q3 | **When** | 구체적 시기 | "연애운이 폭발하는 시기는?" |
| Q4 | **Where + How** | 장소, 상황, 대응법 | "인연을 만날 장소와 행동 전략" |

---

## 3. 무료 질문 작성 규칙

### 3.1 반드시 지켜야 할 것

- **Q1은 '나'에 대한 질문** — 타고난 기질, 본능, 에너지, 성향을 묻는다
- **Q2는 핵심 결론** — "그래서 뭔데?"에 해당하는 명확한 답을 유도한다
- **Q3는 간단한 이유** — "왜 그런데?"에 대한 사주적 원인을 묻는다
- 질문 자체가 **구체적이고 자극적**이어야 한다 (호기심 유발)
- AI가 **단정적으로 답할 수 있는** 질문이어야 한다

### 3.2 절대 하면 안 되는 것

| 금지 패턴 | 이유 | 대안 |
|-----------|------|------|
| "~하는 방법은?" (How) | AI가 구체적 조언을 못 해서 뜬구름 답변 | "~의 원인은?" / "~의 영향은?" |
| "~시기는 언제?" (When) | 무료에서 시기를 말하면 유료 가치 하락 | "~의 사주적 조건은?" |
| "~장소는 어디?" (Where) | 무료에서 장소를 말하면 유료 가치 하락 | "~의 사주적 이유는?" |
| "~개운법은?" / "~비결은?" | How에 해당, 유료 영역 침범 | "~의 근본 원인은?" |
| "~처세술은?" / "~전략은?" | How에 해당, 유료 영역 침범 | "~의 패턴은?" |
| "~마음가짐은?" / "~태도는?" | How에 해당, 모호한 답변 유발 | "~의 기질적 특성은?" |

### 3.3 좋은 질문 vs 나쁜 질문

**나쁜 질문 (기존)**
```
Q3: "재물운을 상승시키기 위해 내가 지니면 좋은 행운의 색상과 물건은?"
→ AI가 "파란색 지갑을 써보세요" 같은 뻔한 답을 하게 됨
```

**좋은 질문 (개선)**
```
Q3: "나의 재물이 새어나가기 쉬운 사주적 취약점과 그 원인은?"
→ AI가 사주 분석 기반으로 "당신의 비겁이 약해서..." 같은 구체적 인사이트를 줌
```

## 4. 무료 프롬프트 설계 원칙

### 4.1 톤 & 역할

- **역할**: 맛보기 상담사 (궁금증 자극 + 명확한 결론 제공)
- **모델**: gpt-4.1-nano
- **톤**: 친근하되 전문적, 단정적 어조 ("~입니다", "~이에요")

### 4.2 응답 형식

- 1문단, 5~6문장
- 첫 문장에서 **핵심 결론을 단정적으로 제시**
- 나머지 문장에서 간단한 이유와 부연 설명
- 마지막 문장에서 **궁금증을 남기는 여운** (유료 전환 유도)

### 4.3 응답 내 금지 사항

| 금지 | 이유 |
|------|------|
| 구체적 시기 ("3월에", "올해 하반기에") | 유료 영역 |
| 구체적 나이 ("25세에", "30대 초반에") | 개인정보 민감 |
| 구체적 대응법 ("이렇게 하세요") | 유료 영역 |
| "유료를 결제하시면..." 직접 유도 | 반감 유발 |
| 모호한 표현 ("~일 수 있습니다", "~할 수도") | 신뢰도 하락 |

### 4.4 무료 응답의 황금 공식

```
[단정적 결론] + [사주 근거 1~2개] + [구체적 성향/패턴 묘사] + [여운]
```

**예시:**
> 당신의 재물이 모이지 않는 가장 큰 원인은 비겁(比劫)의 과다입니다.
> 사주에 비겁이 강하면 들어온 돈을 나누거나 빌려주는 성향이 강해져
> 주머니에 돈이 머무르지 못합니다. 특히 주변 사람의 부탁을 거절하지 못하는
> 성격이 재물 유출의 핵심 통로가 되고 있네요. 흥미로운 건, 이 기운이
> 특정 시기에 더욱 강해진다는 점입니다.

→ 마지막 문장이 "특정 시기"를 언급하지만 구체적으로 말하지 않아 궁금증 유발

## 5. 유료 프롬프트 설계 원칙

### 5.1 톤 & 역할

- **역할**: 전문 사주 명리학자 (완결된 보고서 제공)
- **모델**: gpt-5.1 (사주) / gpt-4.1 (타로)
- **톤**: 전문적, 권위적, 초개인화

### 5.2 응답 형식

- **4문단, 각 3~4문장**
- 십성 참조표 기반 심층 분석
- 초개인화: 사용자 특성 태그, 이용 이력, 상황 요약 반영
- 이전 답변과 중복 방지 (previousAnswerContext)

### 5.3 유료만의 차별 가치

| 요소 | 무료에 없는 것 | 유료에서 제공 |
|------|---------------|--------------|
| **십성 분석** | 없음 | 정관, 편인, 식신 등 구체적 십성 해석 |
| **구체적 시기** | "특정 시기에..." | "2026년 5월~7월 사이에..." |
| **대응법** | "원인은 이것" | "이렇게 하면 해결됩니다" |
| **초개인화** | 일반 사주 데이터만 | 특성 태그 + 이용 이력 + 상황 요약 |
| **이전 답변 연계** | 없음 | 과거 상담 맥락 반영, 중복 방지 |

## 6. 콘텐츠 기획 시 체크리스트

### 새 콘텐츠 기획

- [ ] 타이틀이 호기심을 자극하는가? (클릭하고 싶은 제목)
- [ ] 무료 Q1은 "나는 어떤 사람?"을 묻는가? (Who)
- [ ] 무료 Q2는 "핵심 결론"을 묻는가? (What)
- [ ] 무료 Q3는 "왜 그런가?"를 묻는가? (Why 대략)
- [ ] 세 질문 모두에 How/When/Where가 없는가?
- [ ] AI가 단정적으로 답할 수 있는 질문인가?
- [ ] 무료 답변만으로도 "소름 돋는" 경험을 줄 수 있는가?
- [ ] 유료로 자연스럽게 이어지는 궁금증이 남는가?
- [ ] `recommended_paid_content_id` 매핑이 설정되었는가? (기타/재미 제외)
- [ ] `upsell_hook_text`가 행동경제학 후킹 전략 기반으로 작성되었는가?
- [ ] 후킹 멘트가 매핑된 유료 콘텐츠의 질문과 연관되는가?

### 기존 콘텐츠 점검

- [ ] Q3에 "~방법은?", "~시기는?", "~장소는?" 패턴이 없는가?
- [ ] 무료 답변이 모호하거나 뜬구름 잡는 느낌이 아닌가?
- [ ] 유료 답변이 무료와 확실히 차별화되는가?
- [ ] `upsell_hook_text`가 NULL인 비-기타 콘텐츠가 없는가?
- [ ] 후킹 멘트에 "유료", "결제", "상담" 단어가 없는가?

## 7. 업셀링 전략

### 7.1 자연스러운 전환 유도 (직접 유도 금지)

무료 콘텐츠가 잘 작동하면 사용자는 스스로 유료를 찾게 된다.

```
무료에서 느끼는 감정:
"와, 이거 진짜 나인데?" → "근데 그래서 언제?" → "어떻게 하면 되는 거지?"
                                    ↓                        ↓
                              유료 When 영역          유료 How 영역
```

### 7.2 무료→유료 자연 전환 포인트

| 무료가 주는 것 | 사용자가 궁금해하는 것 | 유료가 주는 것 |
|---------------|---------------------|--------------|
| "당신은 이런 사람" | "그래서 언제 좋아져?" | 구체적 시기 |
| "이런 패턴이 있다" | "어떻게 바꿔?" | 대응법/개운법 |
| "이게 원인이다" | "더 자세히 알려줘" | 십성 기반 심층 |
| "이런 기질이 있다" | "어디서 발휘해?" | 장소/상황 가이드 |

### 7.3 무료→유료 콘텐츠 매핑 (`recommended_paid_content_id`)

각 무료 콘텐츠는 DB에서 **1:1로 추천 유료 콘텐츠에 매핑**된다.

**매핑 우선순위:**
1. `recommended_paid_content_id` 명시적 매핑 (최우선)
2. 같은 `category_sub` 유료 콘텐츠 자동 폴백
3. 같은 `category_main` 유료 콘텐츠 자동 폴백

**매핑 기준:**
- 같은 카테고리 + **테마적 연관성**이 핵심 (예: "바람기 감별" 무료 → "나쁜 인연 컬렉터" 유료)
- 무료에서 "왜?"를 던졌으면, 유료에서 "언제/어떻게?"를 답하는 관계
- 기타/재미 카테고리는 **매핑하지 않음** (NULL) — 업셀링 불필요

**매핑 체크리스트:**
- [ ] 무료 콘텐츠의 주제와 유료 콘텐츠의 주제가 자연스럽게 연결되는가?
- [ ] 무료 결과를 본 사용자가 "더 알고 싶다"고 느낄 유료인가?
- [ ] 기타/재미 콘텐츠가 아닌데 매핑이 NULL인 것은 없는가?

### 7.4 업셀링 후킹 멘트 (`upsell_hook_text`)

무료 결과 화면 하단에 표시되는 **유료 전환 유도 문구**. 콘텐츠별로 맞춤 작성한다.

#### 후킹 멘트 작성 원칙

| 전략 | 설명 | 예시 |
|------|------|------|
| **손실 회피** | 놓치면 손해라는 느낌 | "모르면 계속 반복되는 연애 패턴이 있어요" |
| **구체적 숫자** | 숫자로 신뢰감 + 호기심 | "사주에서 딱 3가지가 돈을 새게 만들고 있어요" |
| **타겟 지목** | "바로 당신" 느낌 | "이 사주를 가진 사람만 겪는 직장 문제가 있어요" |
| **FOMO** | 지금 안 보면 늦는다 | "올해 안에 꼭 확인해야 할 건강 신호가 있어요" |
| **인정 욕구** | 숨겨진 재능/매력 발견 | "당신이 모르는 숨겨진 매력 포인트가 있어요" |
| **갈등 해소** | 현재 고민의 해결 실마리 | "그 사람과의 갈등, 사주에 원인이 있어요" |

#### 좋은 후킹 멘트 vs 나쁜 후킹 멘트

**나쁜 멘트:**
```
"구체적인 흐름이 궁금하다면..."          → 너무 일반적, 호기심 유발 실패
"유료 상담을 받아보세요"               → 직접 유도, 반감 유발
"더 자세한 내용은 유료에서 확인하세요"   → 광고 느낌, 신뢰 하락
```

**좋은 멘트:**
```
"사주에서 딱 3가지가 돈을 새게 만들고 있어요"     → 구체적 숫자 + 손실 회피
"이 사주에 숨겨진 연봉 점프 타이밍이 있어요"       → FOMO + 구체성
"모르면 반복되는 이별 패턴, 끊어낼 방법이 있어요"   → 손실 회피 + 갈등 해소
```

#### 작성 규칙

- **15~30자** 내외 (너무 길면 읽지 않음)
- 매핑된 유료 콘텐츠의 **질문 내용 기반**으로 작성 (유료에서 실제로 답하는 것을 티저)
- "~있어요", "~보여요" 등 **부드러운 어미** 사용
- "유료", "결제", "상담" 단어 **절대 사용 금지**
- 후킹 전략 1~2개를 **조합**하면 효과적

#### 구현

- DB: `master_contents.upsell_hook_text` (text, nullable)
- 프론트엔드: `FreeSajuDetail.tsx`에서 동적 렌더링
- 폴백: `upsell_hook_text`가 NULL이면 기본 문구 "구체적인 흐름이 궁금하다면..." 표시
- 데이터 흐름: `freeContentService.fetchRecommendedPaidContent()` → `{ content, hookText }` 반환

## 8. 콘텐츠 카테고리 체계

### 8.1 카테고리 분류

| category_main | category_sub 예시 | 설명 |
|---------------|-------------------|------|
| **연애** | 연애운, 결혼운, 궁합, 이별, 바람기 등 | 이성 관계 전반 |
| **재물** | 재물운, 투자, 사업운 등 | 돈과 경제 활동 |
| **직장/학업** | 직장운, 이직, 승진, 적성, 시험운 등 | 커리어와 학업 |
| **건강** | 건강운, 사고수, 스트레스 등 | 신체/정신 건강 |
| **대인관계** | 대인운, 신뢰, 갈등, 소통 등 | 사회적 관계 |
| **자녀** | 자녀운, 자녀 적성, 부모 관계 등 | 자녀 관련 |
| **기타** | 재미, 바이럴, MBTI 등 | 엔터테인먼트 목적 |

### 8.2 카테고리별 특성

- **연애~자녀**: 업셀링 대상. 무료→유료 매핑 필수
- **기타**: **업셀링 제외**. 바이럴/재미 목적으로 유입용 콘텐츠
  - `recommended_paid_content_id` = NULL
  - `upsell_hook_text` = NULL
  - 유료 전환 유도 UI 자체를 숨김

## 11. 콘텐츠 기획 프롬프트 가이드

마스터 콘텐츠 기획 시 AI에게 질문을 생성하도록 할 때, 아래 지침을 프롬프트에 포함해야 한다:

```
[무료 질문 생성 규칙]
- Q1: "나는 어떤 사람인가?" (Who) — 타고난 기질, 본능, 에너지를 묻는다
- Q2: "핵심 결론은?" (What) — 사주가 말하는 명확한 답을 묻는다
- Q3: "왜 그런가?" (Why 대략) — 사주적 원인이나 배경을 묻는다
- How(방법), When(시기), Where(장소) 질문은 절대 만들지 않는다
- "~개운법", "~처세술", "~비결", "~전략" 등의 표현을 사용하지 않는다
- AI가 단정적으로 답할 수 있는 질문만 만든다
```
