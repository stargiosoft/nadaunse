## 1. 왜 B2B2C인가?

### 현실 직시: B2C만으로는 생존이 어렵다

| 지표 | 현재 | 문제점 |
|------|------|--------|
| MAU | 11,000명 | 유료 전환 모수 자체가 부족 |
| 재방문율 | 10% | 90%가 한 번 보고 이탈 |
| 체류시간 | 35초 | 깊은 경험 없이 떠남 |
| 시장 구조 | 콘텐츠형 MAU 5배 > 매출 1/3 | 무료 소비에 갇힌 구조 |

**콘텐츠형 운세 시장의 근본 문제**: 개인 사용자는 "운세는 재미로 보는 것"이라는 인식이 강해, 지갑을 여는 데 심리적 저항이 크다. 광고비를 태워 유저를 모아도 유료 전환율이 극히 낮은 밑 빠진 독 구조.

### B2B2C가 답인 이유

```
기존 B2C 구조:
  [개인 사용자] → 무료 소비 → 이탈 (90%)
                              ↘ 유료 전환 (극소수)

B2B2C 구조:
  [개인 사용자] → 무료 체험 → 바이럴 확산 (PLG)
                                    ↓
  [기업 고객] → 대량 구매/구독 → 안정적 매출
                   ↓
  [개인 사용자] → 기업을 통해 유입 → 나다운세 팬 전환
```

**핵심 공식**: 개인이 퍼뜨리고, 기업이 돈을 낸다.

### 축 1: 명리 SLM API 라이선싱 (Tech B2B)

> **"우리가 직접 모든 사용자를 모을 필요 없다. 이미 사용자가 있는 곳에 기술을 심는다."**

#### 비즈니스 모델

| 구분 | 내용 |
|------|------|
| **상품** | 명리 SLM REST API (사주 풀이, 궁합, 오늘의 운세 등) |
| **고객** | 포털(네이버/카카오 운세탭), 미디어 앱, 기존 운세 서비스, 라이프스타일 앱 |
| **과금** | API 호출 건당 과금 (월 기본료 + 초과분 종량제) |
| **차별점** | 95% 정확도 SLM, 초개인화 가능, 518,400가지 완전 커버 |

#### 수익 시뮬레이션

| 티어 | 월 호출 수 | 월 가격 | 예상 고객 수 | 월 매출 |
|------|-----------|---------|-------------|---------|
| Starter | 1만 건 | 50만원 | 20개사 | 1,000만원 |
| Growth | 10만 건 | 300만원 | 5개사 | 1,500만원 |
| Enterprise | 100만 건+ | 별도 협의 | 2개사 | 2,000만원 |
| **합계** | | | **27개사** | **4,500만원/월** |

#### 구체적 파트너 시나리오

**시나리오 A: 포털 운세탭 공급**
- 네이버/카카오/다음의 운세 코너에 나다운세 SLM 엔진 공급
- 현재 포털 운세는 저품질 DB 기반 → 정확도 95% SLM으로 교체 수요 존재
- 포털 입장: 운세 코너 체류시간 증가 / 나다운세 입장: 대규모 노출 + API 수익
- "powered by 나다운세" 브랜딩으로 B2C 유입까지 연결

**시나리오 B: 기존 운세 앱에 엔진 공급**
- 점신, 포스텔러 등 경쟁사가 아닌 소규모 운세 앱에 API 제공
- 그들은 사용자를 갖고 있지만 AI 기술이 부족 → 상호 보완
- 화이트라벨 형태: 앱 겉모습은 그대로, 엔진만 나다운세

**시나리오 C: 라이프스타일 앱 연동**
- 데이팅 앱(궁합 기능), 일기 앱(오늘의 운세), 캘린더 앱(길일 추천)
- 경량 API 제공으로 자연스러운 운세 경험 삽입
- 사용자가 "더 자세히 보기" 클릭 → 나다운세 앱으로 딥링크

#### 실행 로드맵

| 시기 | 액션 |
|------|------|
| **2026 Q2** | API 문서화 + 개발자 포털 구축 |
| **2026 Q3** | 베타 파트너 3-5곳 확보 (소규모 앱 우선) |
| **2026 Q4** | 포털/대형 파트너 협상 시작 |

### 축 2: 기업 복지 & 멘탈케어 솔루션 (Wellness B2B)

> **"운세를 '직원 멘탈케어 도구'로 재정의한다."**

#### 왜 기업이 돈을 낼까?

2030 여성이 겪는 'Toast Out(토스트 아웃)' 상태는 개인의 문제가 아니라 **기업의 문제**이기도 하다.

| 기업의 Pain Point | 나다운세가 줄 수 있는 가치 |
|-------------------|--------------------------|
| MZ세대 직원 번아웃 급증 | 자기 긍정 기반 일상 멘탈케어 |
| 복지 프로그램 참여율 저조 | "운세"라는 흥미 요소로 자연스러운 접근 |
| 팀 커뮤니케이션 문제 | 사주 기반 팀 궁합/소통 스타일 분석 |
| 리텐션(이직률) 관리 | 직원 만족도 향상 → 이직률 감소 |

#### 상품 설계: '나다운 워크' (B2B SaaS)

**나다운 워크(nadaun WORK)**: 기업용 직원 멘탈케어 & 팀빌딩 솔루션

| 기능 | 설명 | 기업 가치 |
|------|------|-----------|
| **오늘의 나다운 메시지** | 매일 아침 직원 개인에게 자기 긍정 메시지 발송 | 출근 전 긍정 에너지, 하루 시작 루틴 |
| **팀 궁합 리포트** | 팀원들의 사주 기반 소통 스타일 분석 | 팀빌딩, 갈등 예방, 리더십 코칭 |
| **월간 나다움 리포트** | 직원 멘탈 트렌드 익명 통계 | HR 부서 인사이트, 번아웃 조기 감지 |
| **팀 워크숍 콘텐츠** | 사주 기반 자기 이해 워크숍 키트 | 오프라인 팀빌딩 행사 활용 |
| **나다움 태그 프로필** | 직원 개인 강점/성향 카드 | 자기소개, 1:1 미팅 아이스브레이커 |

#### 과금 모델

|------|------|---------|-----------|
| **Starter** | 50인 이하 | 월 30만원 | 오늘의 메시지 + 나다움 태그 |
| **Team** | 200인 이하 | 월 100만원 | + 팀 궁합 리포트 + 워크숍 키트 |
| **Enterprise** | 200인 이상 | 별도 협의 | + 월간 HR 리포트 + 전담 매니저 |

#### 수익 시뮬레이션

| 시나리오 | 고객 수 | 평균 단가 | 월 매출 |
|----------|---------|-----------|---------|
| 보수적 (1년차) | 10개사 | 50만원 | 500만원 |
| 기본 (2년차) | 50개사 | 80만원 | 4,000만원 |

#### PLG 연결 구조 (핵심!)

```
기업이 '나다운 워크' 도입
        ↓
직원 A가 회사에서 '나다운 메시지' 받음
        ↓
"이거 재밌다, 개인적으로도 더 보고 싶다"
        ↓
나다운세 앱 개인 가입 (B2C 전환!)
        ↓
친구에게 공유 → 바이럴 확산
        ↓
친구의 회사에서도 "이거 뭐야?" → B2B 리드 생성
```

**이것이 피그마/노션이 성장한 정확한 구조다.**
- 피그마: 디자이너 개인이 무료 사용 → 팀에 공유 → 기업 유료 전환
- 나다운세: 직원이 회사에서 경험 → 개인 앱 사용 → 친구에게 공유 → 친구 회사로 확산

#### 타겟 기업

| 유형 | 왜 맞는가 | 예시 |
|------|----------|------|
| **IT 스타트업** | MZ 비율 높음, 복지 차별화 니즈 | 토스, 당근, 컬리 |
| **광고/마케팅 에이전시** | 여성 비율 높음, 번아웃 심함 | 이노션, 제일기획 |
| **뷰티/패션 기업** | 2030 여성 타겟과 정확히 일치 | 올리브영, 무신사 |
| **공유 오피스** | 입주사 복지 프로그램으로 제공 | 패스트파이브, 위워크 |

### 축 3: 브랜드 콜라보 & IP 라이선싱 (Partnership B2B2C)

> **"아기 백조 IP와 '자기 긍정' 가치를 다른 브랜드의 마케팅 도구로 만든다."**

#### 비즈니스 모델

| 유형 | 설명 | 수익 구조 |
|------|------|-----------|
| **콜라보 캠페인** | 브랜드 × 나다운세 공동 마케팅 | 캠페인 비용 수주 |
| **콘텐츠 커머스** | 운세 결과 → 제품 추천 연동 | 제휴 수수료 (CPA/CPS) |
| **IP 라이선싱** | 아기 백조 캐릭터 상품화 | 로열티 수익 |
| **오프라인 팝업** | 브랜드 팝업스토어 내 운세 체험존 | 행사 수주 |

#### 구체적 파트너 시나리오

**시나리오 A: 뷰티 브랜드 콜라보**
```
올리브영 × 나다운세 "나다운 뷰티" 캠페인

1. 사용자가 나다운세에서 사주 분석
2. 사주 기반 "나다운 뷰티 타입" 도출
   - 예: "따뜻한 봄 에너지 타입" → 코랄톤 추천
3. 올리브영 제품 큐레이션 연결
4. 구매 시 아기 백조 굿즈 증정

수익: 올리브영에서 캠페인 비용 + 제품 판매 CPS 수수료
나다운세 B2C 효과: 올리브영 유저 대량 유입
```

**시나리오 B: 카페 브랜드 콜라보**
```
스타벅스/투썸 × 나다운세 "오늘의 나다운 음료"

1. QR 코드 스캔 → 나다운세 간편 사주 입력
2. 사주 기반 "오늘의 나다운 음료" 추천
3. 해당 음료 주문 시 아기 백조 스티커 증정
4. SNS 공유 이벤트 → 바이럴

수익: 카페 브랜드에서 프로모션 비용 수주
나다운세 B2C 효과: 오프라인에서 온라인으로 자연 유입
```

**시나리오 C: 이커머스 운세 위젯**
```
29CM / W컨셉 × 나다운세 "운세 기반 큐레이션"

1. 쇼핑 앱 내 "오늘의 나다운 아이템" 위젯 삽입
2. 사주 기반 패션/라이프스타일 제품 추천
3. 구매 전환 시 CPS 수수료

수익: 월 위젯 사용료 + 구매 수수료
나다운세 B2C 효과: 이커머스 유저 나다운세 앱 유입
```

**시나리오 D: 아기 백조 IP 확장**
```
캐릭터 라이선싱 → 문구/굿즈/이모티콘

1단계: 카카오 이모티콘 출시 (자기 긍정 메시지 이모티콘)
2단계: 문구 브랜드와 다이어리/스티커 콜라보
3단계: 팝업스토어 (아기 백조 × 운세 체험)

수익: 로열티 수익
나다운세 B2C 효과: IP 인지도 → 앱 다운로드 전환
```

## 4. PLG (제품주도 성장) 전략

### B2C가 B2B의 영업사원이 되는 구조

나다운세의 B2B2C는 단순히 B2B를 추가하는 것이 아니라, **B2C 제품 자체가 B2B 영업을 대신하는 구조**를 만드는 것이다.

#### PLG 플라이휠

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│   1. 개인 유저가 무료 콘텐츠 체험                              │
│          ↓                                                   │
│   2. "이거 진짜 잘 맞는다" → SNS 공유 (자연 바이럴)             │
│          ↓                                                   │
│   3. 나다움 태그 결과 공유 → "너도 해봐!" 바이럴                 │
│          ↓                                                   │
│   4. 회사에서 동료들과 사주 궁합 이야기                          │
│          ↓                                                   │
│   5. HR/복지 담당자가 "이거 팀빌딩에 쓰면 좋겠다"               │
│          ↓                                                   │
│   6. '나다운 워크' B2B 도입 → 전 직원 사용                     │
│          ↓                                                   │
│   7. 직원들이 개인 앱도 설치 → B2C 유료 전환                    │
│          ↓                                                   │
│   (1로 돌아가서 반복)                                          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

#### 바이럴 트리거 설계

| 트리거 | 공유 동기 | 구현 방안 |
|--------|----------|-----------|
| **나다움 태그 카드** | "나는 이런 사람이야" 정체성 표현 | 인스타 스토리 최적화 카드 이미지 |
| **팀 궁합 리포트** | "우리 팀 궁합 봐봐" 재미 | 팀 링크 공유 → 가입 유도 |
| **오늘의 운세 한줄** | 매일 공유할 수 있는 가벼운 콘텐츠 | 카카오톡/스레드 공유 버튼 |
| **아기 백조 성장 기록** | "내 백조 이만큼 컸어" 성취감 | 성장 단계별 공유 카드 |

#### 핵심 전환 포인트

```
무료 개인 사용자 (B2C Free)
    │
    ├─→ 유료 개인 구독 (B2C Paid): 정액제 전환
    │
    ├─→ 기업 도입 리드 (B2B Lead): "회사에도 도입하고 싶다"
    │
    └─→ 브랜드 콜라보 제안 (Partnership): 마케팅 담당자가 연락
```

## 6. 경쟁 해자 (Moat)

### 왜 대형 플레이어가 따라올 수 없는가

| 해자 | 설명 |
|------|------|
| **데이터 해자** | 518,400가지 사주 DB + 사용자 행동 데이터 축적 → 시간이 갈수록 벌어지는 격차 |
| **기술 해자** | 명리 전문 SLM은 범용 LLM으로 대체 불가 (도메인 특화 파인튜닝 필요) |
| **브랜드 해자** | '자기 긍정'이라는 포지셔닝은 후발주자가 카피해도 진정성에서 밀림 |
| **네트워크 해자** | B2B API 고객 → 전환 비용 높음 (시스템 연동) → 락인 효과 |
| **PLG 해자** | 개인 바이럴 → 기업 도입 → 더 많은 개인 유입의 선순환 |

## 10. 결론: 나다운세의 이상적 성장 공식

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│   B2C (개인) = 바이럴 엔진                               │
│   → 무료 콘텐츠 + 나다움 태그 + 아기 백조로 사용자 확산     │
│                                                         │
│   B2B (기업) = 수익 엔진                                  │
│   → API 라이선싱 + 기업 복지 + 콜라보로 안정적 매출 확보     │
│                                                         │
│   B2C ←→ B2B 선순환 = 성장 엔진                          │
│   → 개인이 퍼뜨리고, 기업이 돈 내고, 기업 통해 더 많은      │
│     개인이 유입되는 플라이휠                                │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**한 줄 요약**: 나다운세는 개인에게는 '마음의 안전기지', 기업에게는 '직원 멘탈케어 인프라', 브랜드에게는 '2030 여성 접점 도구'가 되어, 세 축이 서로를 강화하는 B2B2C 플라이휠로 성장한다.
