# AI 카테고리 분류 기반 동적 유료 콘텐츠 추천

> **작성일**: 2026-03-05
> **상태**: 구현 대기

## 1. 배경

현재 사주/타로 상담 결과 페이지의 "이 흐름, 더 깊이 보고 싶다면" 추천 섹션은 **하드코딩된 더미 데이터**를 사용 중이다.
- `TaroConsultResultPage.tsx`: `TARO_RECOMMENDED_ITEMS` 상수 (5개 고정)
- `SajuConsultResultPage.tsx`: 인라인 하드코딩 (6개 고정, RecommendedCarousel 미사용)

**목표**: AI가 사용자 질문을 분석하여 카테고리를 자동 분류하고, 해당 카테고리 콘텐츠를 우선 노출하되 **카테고리 제한 없이** 전체 유료 콘텐츠를 인기순으로 추천하여 구매 전환을 유도한다.

---

## 2. 데이터 파이프라인

```
[사용자 질문]
  → [Edge Function AI 호출] → AI가 상담 응답 + 추천 카테고리(main/sub) 분류
  → [Loading 페이지] → localStorage에 결과 + recommendedCategory 저장
  → [Result 페이지] → Supabase 쿼리로 유료 콘텐츠 조회
  → [매칭 카테고리 콘텐츠 우선 + 나머지 인기순으로 채워서 표시]
```

### Step 3. 추천 콘텐츠 조회 서비스 생성

**NEW** `src/lib/consultRecommendationService.ts`

```typescript
import { supabase } from './supabase';
import type { MasterContent } from './freeContentService';

interface RecommendedCategory {
  main: string;
  sub: string;
}

/**
 * AI가 분류한 카테고리 기반 유료 콘텐츠 추천 조회
 * 카테고리 제한 없이 전체 유료 콘텐츠 대상, 매칭 카테고리 우선 노출
 */
export async function fetchConsultRecommendations(
  category: RecommendedCategory | null | undefined,
  limit = 6
): Promise<MasterContent[]> {
  const results: MasterContent[] = [];
  const usedIds = new Set<string>();

  // 1단계: 매칭 카테고리 콘텐츠 우선 수집 (sub → main 순서)
  if (category?.sub) {
    const { data } = await supabase
      .from('master_contents')
      .select('*')
      .eq('category_sub', category.sub)
      .eq('content_type', 'paid')
      .eq('status', 'deployed')
      .order('weekly_clicks', { ascending: false })
      .limit(limit);
    if (data) {
      for (const item of data) {
        if (!usedIds.has(item.id)) { results.push(item); usedIds.add(item.id); }
      }
    }
  }

  if (results.length < limit && category?.main) {
    const { data } = await supabase
      .from('master_contents')
      .select('*')
      .eq('category_main', category.main)
      .eq('content_type', 'paid')
      .eq('status', 'deployed')
      .order('weekly_clicks', { ascending: false })
      .limit(limit);
    if (data) {
      for (const item of data) {
        if (!usedIds.has(item.id) && results.length < limit) {
          results.push(item); usedIds.add(item.id);
        }
      }
    }
  }

  // 2단계: 나머지는 전체 인기순으로 채우기 (카테고리 무관)
  if (results.length < limit) {
    const { data } = await supabase
      .from('master_contents')
      .select('*')
      .eq('content_type', 'paid')
      .eq('status', 'deployed')
      .order('weekly_clicks', { ascending: false })
      .limit(limit + results.length); // 중복 제거 고려해 여유분
    if (data) {
      for (const item of data) {
        if (!usedIds.has(item.id) && results.length < limit) {
          results.push(item); usedIds.add(item.id);
        }
      }
    }
  }

  return results;
}
```

**핵심 설계**:
- 패턴 참고: `src/lib/freeContentService.ts`의 `fetchRecommendedPaidContent()` (lines 237-310)
- **카테고리 제한 없음**: 매칭 카테고리 콘텐츠를 우선 노출하되, 부족한 만큼 전체 인기순으로 채움
- 항상 `limit`개 결과 반환 (유료 콘텐츠가 충분한 경우)
- AI가 카테고리 미반환 시 → 바로 전체 인기순 fallback
