# PPT 디자인 가이드 (범용)

> 레퍼런스: 앱인토스 플랫폼 소개서 (27p)
> 용도: 서비스 소개서, 투자 IR, 파트너십 제안서 등

---

## 1. 전체 구조 (슬라이드 구성)

### 권장 슬라이드 순서 (20~30장 기준)

| 순서 | 섹션 | 슬라이드 수 | 내용 |
|------|------|-------------|------|
| 1 | **커버** | 1장 | 서비스명 + 한 줄 메시지 + 핵심 수치 |
| 2 | **목차** | 1장 | 4~5개 섹션, 페이지 번호 포함 |
| 3 | **시장/문제** | 2~3장 | 시장 규모, 타겟 유저 통계, 페인포인트 |
| 4 | **서비스 소개** | 3~4장 | 핵심 가치, 주요 기능, 스크린샷 |
| 5 | **기술/차별점** | 3~4장 | 기술 스택, API/SDK, 아키텍처 |
| 6 | **성과/사례** | 2~3장 | KPI, 고객 후기, 성공 사례 |
| 7 | **비즈니스 모델** | 2~3장 | 수익 구조, 가격 정책, 수수료 |
| 8 | **로드맵/절차** | 2~3장 | 도입 절차, 타임라인, 향후 계획 |
| 9 | **별첨** | 3~5장 | 상세 기능 목록, 기술 스펙 등 |
| 10 | **클로징** | 1장 | 감사 인사 + CTA |

### 목차 슬라이드 패턴

```
서비스 소개   Why [서비스명]   성공 사례
수수료 및 도입 절차 안내

핵심 키워드 A     03
핵심 키워드 B     14
핵심 키워드 C     13
서비스 소개        6
별첨              19
```

> 핵심 키워드 3개를 크게 배치하고, 세부 섹션은 페이지 번호와 함께 나열

## 2. 레이아웃 원칙

### 2.1 그리드 시스템

- **기본 여백**: 상하좌우 40~60px
- **콘텐츠 영역**: 슬라이드의 80% 이내
- **페이지 번호**: 우측 하단 또는 좌측 하단, 작은 크기
- **로고 위치**: 우측 상단 고정 (커버 제외)

### 2.2 슬라이드 유형별 레이아웃

#### A. 타이틀 + 본문 (가장 빈도 높음)

```
┌─────────────────────────────────┐
│                         [로고]   │
│                                 │
│  큰 타이틀 텍스트               │
│  (서비스명 + 핵심 메시지)        │
│                                 │
│  부제목 또는 설명 텍스트         │
│                                 │
│                            [번호]│
└─────────────────────────────────┘
```

#### B. 좌우 분할 (기능 설명) — 앱인토스 p4, p8 참고

```
┌────────────────┬────────────────┐
│                │                │
│  텍스트 영역    │  이미지/도표    │
│  - 타이틀      │  - 스크린샷    │
│  - 설명 2~3줄  │  - 디바이스 목업│
│  - 포인트 3개   │                │
│                │                │
└────────────────┴────────────────┘
```

> 텍스트 좌측 40%, 이미지 우측 60% 비율 권장
> 앱인토스 p4: 좌측 텍스트 + 우측 앱 스크린샷 목업

#### C. 카드 그리드 (통계/수치 강조) — 앱인토스 p3 참고

```
┌─────────────────────────────────────────────────┐
│  타이틀: "대한민국 국민 50%가 사용하는 ..."       │
│                                                 │
│  ┌──────────┐ ┌──────────┐ ┌──────────────────┐ │
│  │ [아이콘]  │ │ [아이콘]  │ │   성별 분포      │ │
│  │ 누적 가입 │ │ 월간 활성 │ │   [파이 차트]    │ │
│  │  3천만*  │ │ 2,480만  │ │   51.2% / 48.8% │ │
│  ├──────────┤ ├──────────┤ ├──────────────────┤ │
│  │ 연령별   │ │ [아이콘]  │ │   연령별 분포    │ │
│  │ 가입자   │ │ 서비스 수 │ │   [바 차트]     │ │
│  │ 프로그레스│ │  200+*   │ │                  │ │
│  └──────────┘ └──────────┘ └──────────────────┘ │
│                                                 │
│  *출처: 내부 데이터 기준                         │
└─────────────────────────────────────────────────┘
```

> **핵심 패턴**: 숫자는 초대형 Bold, 라벨은 소형 Regular
> 카드마다 상단에 미니 아이콘 배치 (사람, 차트, 기기 등)
> 차트는 카드 안에 삽입하여 시각적 밀도 확보

#### D. 3~4 컬럼 (비교/나열) — 앱인토스 p6 참고

```
┌──────────┬──────────┬──────────┐
│  항목 1   │  항목 2   │  항목 3   │
│  아이콘   │  아이콘   │  아이콘   │
│  제목     │  제목     │  제목     │
│  설명     │  설명     │  설명     │
└──────────┴──────────┴──────────┘
```

> 앱인토스: "쉬운개발 / 빠른성장 / 낮은비용" 3컬럼
> 각 컬럼 상단에 키워드를 Bold로, 하단에 2~3줄 설명

#### E. 아이콘 네비게이션 (탐색 경로) — 앱인토스 p5 참고

```
┌─────────────────────────────────────────┐
│  [강조 배경색 밴드]                      │
│  타이틀: "이미 300+종의 미니앱이 ..."    │
│  부제목: 게임 · 쇼핑 · 운세 · 웹툰 ...  │
│                                         │
│  ┌────────┐ ┌────────┐ ┌────────┐ ┌────┐│
│  │[스크린] │ │[스크린] │ │[스크린] │ │    ││
│  │  샷 1  │ │  샷 2  │ │  샷 3  │ │ ...││
│  └────────┘ └────────┘ └────────┘ └────┘│
│  전체 탭 1   카테고리 2   검색 3   혜택 4│
└─────────────────────────────────────────┘
```

> 상단 1/3에 강조 배경색 밴드 + 타이틀
> 하단 2/3에 스크린샷 4개를 수평 나열
> 각 스크린샷 아래 라벨 + 번호

#### F. 프로세스/타임라인

```
┌─────────────────────────────────┐
│                                 │
│  [1단계] → [2단계] → [3단계]     │
│  1~2주     1~2주     1~5주      │
│  사전준비   개발      테스트      │
│                                 │
└─────────────────────────────────┘
```

## 3. 타이포그래피

### 3.1 폰트 선택

| 용도 | 권장 폰트 | 대안 |
|------|----------|------|
| 제목 | **Pretendard Bold/ExtraBold** | Spoqa Han Sans Neo Bold |
| 본문 | **Pretendard Regular/Medium** | Noto Sans KR |
| 수치 강조 | **Pretendard Black** 또는 Montserrat Bold | - |
| 코드/기술 | Fira Code, JetBrains Mono | - |

### 3.2 크기 체계

| 요소 | 크기 | 비고 |
|------|------|------|
| 커버 타이틀 | 40~54pt | 1~2줄 이내 |
| 섹션 타이틀 | 32~40pt | 페이지 상단 |
| 서브 타이틀 | 24~28pt | 타이틀 아래 |
| 본문 | 16~20pt | 가독성 우선 |
| 캡션/주석 | 10~12pt | 하단 출처 표기 등 |
| 강조 수치 | 48~72pt | 통계 슬라이드 |

### 3.3 텍스트 규칙

- **한 슬라이드 최대 텍스트**: 60자 x 5줄 이내
- **글머리 기호**: `•` 또는 `✓` 사용
- **강조**: Bold + Primary 컬러 변경 (밑줄 사용 금지)
- **줄간격**: 1.4~1.6배
- **문장 종결**: `~해요` 체 (친근한 톤) 또는 `~합니다` 체 (공식 톤) — 하나로 통일

### 4.4 컬러 사용 원칙

- **배경**: 화이트(`#FFFFFF`) 기본, 구분 영역은 Alt 배경색 사용
- **강조 밴드**: Primary Dark 배경 + 화이트 텍스트 (섹션 전환, 핵심 메시지)
  - 앱인토스 p5: 상단 1/3을 블루 밴드로 채워 시선 집중
- **카드**: 화이트 배경 + Border 또는 미세 그림자, 혹은 Primary Light 배경
- **그래프/차트**: Primary → Accent → Warning 순으로 사용
- **텍스트 컬러**: 배경 대비 4.5:1 이상 (WCAG AA 기준)
- **한 슬라이드 최대 3색** (배경 제외)
- **타이틀 강조**: Primary 컬러로 핵심 키워드만 컬러 변경

### 4.5 강조 배경 밴드 패턴

│ ██  화이트 부제목           ████│
│ ████████████████████████████████│

```

> 슬라이드 상단 30~40%를 컬러 밴드로 채우는 패턴
> 앱인토스 p5에서 사용 — 시선을 타이틀에 먼저 집중시킴

## 5. 비주얼 요소

### 5.1 아이콘

- **스타일**: Line icon (2px stroke), 단색 Filled icon
- **크기**: 24~48px (본문 내), 64~80px (아이콘 중심 레이아웃)
- **컬러**: Primary 컬러 또는 Text Secondary 그레이
- **추천 소스**: Lucide Icons, Phosphor Icons, Heroicons
- **카드 내 아이콘**: 상단 좌측에 작은 아이콘 배치 (앱인토스 p3 패턴)

### 5.2 이미지 & 목업

- **디바이스 목업**: 앱인토스 p4처럼 iPhone 프레임에 서비스 화면 삽입
  - 그림자: `0 4px 24px rgba(0,0,0,0.08)`
  - 모서리: 기기 자연스러운 라운드
- **스크린샷 나열**: 4개까지 수평 배치, 균등 간격 (앱인토스 p5 패턴)
- **배경 이미지**: 사용 시 반드시 오버레이 적용 (텍스트 가독성 확보)
- **일러스트**: 미니멀 플랫 스타일, Primary/Accent 컬러 활용

### 5.3 차트 & 그래프

| 데이터 유형 | 권장 차트 | 앱인토스 예시 |
|------------|----------|-------------|
| 비율/구성 | 도넛 차트, 파이 차트 | 성별 분포 (51.2%/48.8%) |
| 추이/성장 | 라인 차트, 에어리어 차트 | - |
| 비교 | 바 차트 (수평/수직) | 연령별 분포 |
| 진행률 | 프로그레스 바 | 연령대별 가입자 비율 (95%, 87%...) |

**차트 스타일 규칙**:
- 파이/도넛: Primary + Primary Light 2색 조합, 라벨은 차트 옆에
- 바 차트: Primary 색상, 라벨 좌측 정렬
- 프로그레스 바: Primary 배경 + Background Alt 트랙

### 5.4 장식 요소

- **카드**: 라운드 코너 12~16px + 1px 보더(`#E5E8EB`) 또는 미세 그림자
- **배지/태그**: 작은 라운드 칩, Primary Light 배경 + Primary 텍스트
- **별표/주석**: 하단에 `*출처: ...` 형태 (10~12pt, Text Tertiary 컬러)
- **구분선**: 1px solid Border 컬러
- **숫자 뒤 단위**: 숫자는 ExtraBold, 단위(`만`, `+`, `%`)는 Regular로 대비

## 6. 슬라이드별 작성 가이드

### 6.1 커버 슬라이드

```
[필수 요소]
- 서비스 로고
- 서비스명
- 한 줄 핵심 메시지 (타겟 규모 + 행동 유도)
- 핵심 수치 1개 (선택)
- 날짜 또는 버전
- 부제목: "사업 및 서비스 소개" 등

[레퍼런스]
앱인토스: "3,000만 토스 유저에게 내 서비스 오픈하기"
→ 타겟 규모 + 행동 유도를 한 문장에 담음
```

### 6.2 시장/문제 슬라이드 — 앱인토스 p3 참고

```
[패턴: 카드 그리드 + 차트]
- 상단에 한 줄 타이틀 (핵심 키워드 Primary 컬러 강조)
  예: "대한민국 국민 [50%]가 사용하는 모바일 금융 서비스"
- 6칸 카드 그리드 (2행 3열)
  - 좌측 상단: 핵심 수치 + 아이콘 (누적 가입자 3천만)
  - 중앙 상단: 핵심 수치 + 아이콘 (MAU 2,480만)
  - 우측 상단: 파이 차트 (성별 분포)

## 7. 텍스트 작성 원칙

### 7.1 카피라이팅 공식

| 공식 | 설명 | 예시 |
|------|------|------|
| **숫자 + 행동** | 임팩트 있는 시작 | "MAU 00만, 서비스의 새로운 기준" |
| **~해요 체** | 친근하고 쉬운 톤 | "다양한 API·SDK를 제공해요" |
| **Before → After** | 문제 → 해결 | "설치 과정 제거로 마케팅 효율 UP!" |
| **질문형** | 관심 유도 | "어떻게 125일 만에 출시했을까요?" |
| **키워드 컬러 강조** | 시선 유도 | "[50%]가 사용하는" (50%만 Primary) |

### 7.2 톤 & 보이스

- **친근하되 신뢰감** 있게 (`~해요`, `~있어요`, `~돼요`)
- **전문 용어 최소화**: 기술 슬라이드에서도 쉬운 표현 우선
- **능동형 문장**: "제공됩니다" → "제공해요" / "확인할 수 있어요"
- **한 슬라이드 = 한 메시지**: 여러 메시지를 욱여넣지 않기

### 7.3 주석/출처 표기

```
*2024년 기준 / 출처: 와이즈앱
**내부 데이터 기준
***행정안전부 주민등록인구 통계 기준
```

> 슬라이드 하단에 `*` 표기, 10~12pt, Text Tertiary 컬러

### 10.2 AI 생성 시 주의사항

- AI가 생성한 텍스트는 반드시 **팩트 체크** 후 사용
- 자동 생성 레이아웃도 **이 가이드의 컬러/타이포에 맞게 수정**
- 이미지는 AI 생성 이미지보다 **실제 서비스 스크린샷** 우선
- 동일 프롬프트로 여러 버전 생성 후 **베스트 선택**

- 각 키워드 아래 세부 설명

> 3천만 / 2,480만 / 200+ / 95%
