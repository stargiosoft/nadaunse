# 사주 API 경량화 전략

> **목적**: 마음톡 사주 상담 모드에서 Stargio 통합 사주 API 응답을 경량화하여 AI 토큰 비용 절감
> **적용 위치**: `supabase/functions/mind-talk-chat/index.ts` (6-1. 사주 모드)
> **최종 업데이트**: 2026-03-12

---

## 1. 전체 흐름

```
사용자 사주 상담 요청
  → DB에서 사주 정보 조회 (saju_records)
  → Stargio 통합 사주 API 호출 (재시도 3회)
  → 전체 JSON에서 18개 핵심 필드만 추출 (pick 함수)
  → 시스템 프롬프트 [상세 사주 데이터] 블록에 삽입
  → Gemini AI가 참고하여 상담 응답 생성
```

---

## 2. API 호출

- **엔드포인트**: `https://service.stargio.co.kr:8400/StargioSaju`
- **파라미터**: `birthday` (YYYYMMDDHHMM), `lunar=false`, `gender`, `apiKey`
- **인증**: `SAJU_API_KEY` 환경변수 (Supabase Secrets)
- **재시도**: 3회 (1초, 2초 간격 Exponential Backoff)
- **헤더**: 브라우저 헤더 흉내 필수 (CORS 우회)

---

## 3. 경량화: 추출 필드 (18개)

원본 API 응답은 수십 개의 키를 포함하지만, `pick()` 함수로 아래 18개만 추출합니다.

| 카테고리 | 필드 | 설명 |
|----------|------|------|
| **핵심 사주** | `격국` | 사주 유형 (예: 정관격, 식신격) |
| | `격국설명` | 격국의 상세 해석 |
| | `일주` | 일간+일지 (예: 甲子) |
| | `일주설명` | 일주 성격/특성 해석 |
| **사주 구성** | `천간` | 년/월/일/시 4주 천간 |
| | `지지` | 년/월/일/시 4주 지지 |
| | `십성` | 비견, 식신, 정관 등 관계 해석 |
| | `십이운성` | 장생, 건록, 제왕 등 에너지 단계 |
| **운세 흐름** | `대운` | 10년 주기 대운 정보 |
| | `대운수` | 현재 대운 순번 |
| | `세운` | 올해 세운 정보 |
| **오행** | `발달오행` | 강한 오행 |
| | `오행비율` | 목/화/토/금/수 비율 |
| **용신** | `용신` | 보완이 필요한 오행 |
| | `용신설명` | 용신 상세 해석 |
| | `희신` | 용신을 돕는 보조 오행 |
| **해석 텍스트** | `성격` | 성격 분석 텍스트 |
| | `적성` | 직업/적성 분석 |
| | `건강` | 건강 주의사항 |
| **시기별 운세** | `올해운세` | 연간 운세 |
| | `이달운세` | 월간 운세 |
| | `오늘운세` | 일간 운세 |

> **참고**: 실제 추출 키는 코드상 18개이나, API 응답에 해당 키가 없으면 제외됩니다.

## 4. 프롬프트 삽입 구조

```
[사용자 성향 태그]
#내향적(+) #완벽주의(-) ...

[사용자 심리 상황 요약]
[1주 전] 직장에서 스트레스를 받고 있음...

[나다움 분석 요약]
[성격] 내면이 섬세하고...

[상세 사주 데이터]        ← 여기에 경량화된 JSON 삽입
{
  "격국": "정관격",
  "격국설명": "...",
  "일주": "甲子",
  ...
}
```

---

## 5. 토큰 절감 효과

- **원본**: 전체 API JSON (수십 개 키, 중첩 객체 포함)
- **경량화**: 18개 핵심 필드만 → 토큰 사용량 대폭 감소
- **로그**: `✅ 사주 API 호출 성공 (전체: N키, 추출: 18키)` 형태로 Supabase 로그에서 확인 가능

---

## 6. AI 활용 지침 (시스템 프롬프트)

사주 모드 시스템 프롬프트에서 AI에게 아래와 같이 지시:

- 사주 전문 용어(종살격, 상관, 편관, 대운, 오행 등)는 **직접 언급하지 않고** 쉬운 일상 언어로 풀어서 설명
- 사주 데이터가 있으면 **반드시 활용**하여 맞춤 상담 제공
- 사용자의 현재 고민/상황에 맞는 운세 해석 제공
