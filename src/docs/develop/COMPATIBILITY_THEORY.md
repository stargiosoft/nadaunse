# 궁합 명리 원리 정리

> **용도**: 운테 궁합 기능 및 향후 궁합 콘텐츠 개발 시 참고
> **작성일**: 2026-03-13

---

## 1. 궁합의 기본 프레임

모든 관계 궁합은 아래 4가지 축을 조합해서 본다.

| 축 | 설명 |
|----|------|
| **일간·일주** | 기본 기질, 대인관계 스타일. 모든 궁합의 1번 축 |
| **오행 상생·상극** | 서로의 기운을 키워주냐(상생) 깎아먹냐(상극) |
| **십성 관계** | 상대가 나한테 어떤 역할(비겁/식상/재/관/인)로 들어오는지 |
| **합·충·형·해** | 끈적/의존(합 과다), 자극·갈등(충), 거리조절 포인트 |

## 2. 천간 (天干) 관계

### 2-1. 천간합 (天干合) — 자연스럽게 끌리는 짝

| 합 | 조합 | 합화 오행 | 키워드 |
|----|------|-----------|--------|
| 갑기합 | 갑 + 기 | 토 | 리더 + 참모 |
| 을경합 | 을 + 경 | 금 | 부드러움 + 강인함 |
| 병신합 | 병 + 신 | 수 | 열정 + 냉철 |
| 정임합 | 정 + 임 | 목 | 섬세함 + 자유로움 |
| 무계합 | 무 + 계 | 화 | 안정 + 지혜 |

### 2-2. 천간충 (天干冲) — 부딪히는 관계

| 충 | 조합 | 오행 관계 |
|----|------|-----------|
| 갑경충 | 갑(목) ↔ 경(금) | 금극목 |
| 을신충 | 을(목) ↔ 신(금) | 금극목 |
| 병임충 | 병(화) ↔ 임(수) | 수극화 |
| 정계충 | 정(화) ↔ 계(수) | 수극화 |

> 무(토)·기(토)는 충 짝이 없음 (토는 중앙, 충 개념 해당 없음)

## 3. 오행 (五行) 관계

### 3-1. 천간 → 오행 매핑

| 오행 | 천간 | 성질 |
|------|------|------|
| 목(木) | 갑(양목), 을(음목) | 성장, 인자, 추진 |
| 화(火) | 병(양화), 정(음화) | 열정, 예의, 표현 |
| 토(土) | 무(양토), 기(음토) | 안정, 신뢰, 중재 |
| 금(金) | 경(양금), 신(음금) | 결단, 의리, 절제 |
| 수(水) | 임(양수), 계(음수) | 지혜, 유연, 소통 |

### 3-2. 상생 (相生) — 서로 살려주는 관계

```
목 → 화 → 토 → 금 → 수 → 목 (순환)
```

| 상생 | 의미 |
|------|------|
| 목생화 | 나무가 불을 키움 — 성장이 열정을 낳음 |
| 화생토 | 불이 재(토)를 만듦 — 열정이 안정을 낳음 |
| 토생금 | 땅에서 금속이 남 — 안정이 결단을 낳음 |
| 금생수 | 금속 표면에 물이 맺힘 — 절제가 지혜를 낳음 |
| 수생목 | 물이 나무를 키움 — 지혜가 성장을 낳음 |

### 3-3. 상극 (相克) — 서로 제압하는 관계

```
목 → 토 → 수 → 화 → 금 → 목 (순환)
```

| 상극 | 의미 |
|------|------|
| 목극토 | 나무가 흙을 뚫음 — 추진이 안정을 흔듦 |
| 토극수 | 흙이 물을 막음 — 고집이 유연함을 막음 |
| 수극화 | 물이 불을 끔 — 냉정이 열정을 꺾음 |
| 화극금 | 불이 금속을 녹임 — 열정이 절제를 무너뜨림 |
| 금극목 | 도끼가 나무를 벰 — 결단이 성장을 잘라냄 |

### 3-4. 비화 (比和) — 같은 오행

같은 오행끼리는 동질감·공감이 강하지만 과하면 경쟁·충돌.

| 비화 | 조합 |
|------|------|
| 목·목 | 갑-갑, 갑-을, 을-을 |
| 화·화 | 병-병, 병-정, 정-정 |
| 토·토 | 무-무, 무-기, 기-기 |
| 금·금 | 경-경, 경-신, 신-신 |
| 수·수 | 임-임, 임-계, 계-계 |

## 4. 십성 (十星) 관계

상대 일간이 내 사주에서 어떤 역할로 작용하는지.

### 4-1. 십성 분류

| 십성 | 오행 관계 | 음양 | 역할 |
|------|-----------|------|------|
| **비견** | 나와 같은 오행 | 같은 음양 | 동료, 경쟁자, 동지 |
| **겁재** | 나와 같은 오행 | 다른 음양 | 라이벌, 밀당, 끌림+경쟁 |
| **식신** | 내가 생하는 오행 | 같은 음양 | 표현, 재능, 편안한 소통 |
| **상관** | 내가 생하는 오행 | 다른 음양 | 도전, 반항, 자유로운 관계 |
| **편재** | 내가 극하는 오행 | 같은 음양 | 아버지, 유흥, 넓은 인맥 |
| **정재** | 내가 극하는 오행 | 다른 음양 | 배우자(남), 안정적 재물 |
| **편관** | 나를 극하는 오행 | 같은 음양 | 권위, 압박, 카리스마 |
| **정관** | 나를 극하는 오행 | 다른 음양 | 배우자(여), 질서, 존경 |
| **편인** | 나를 생하는 오행 | 같은 음양 | 특이한 학문, 고독한 돌봄 |
| **정인** | 나를 생하는 오행 | 다른 음양 | 어머니, 학문, 든든한 후원 |

### 4-2. 십성 판별법

```
내 일간 기준 → 상대 일간의 오행 → 관계 + 음양 → 십성 결정

예) 내가 갑(양목), 상대가 기(음토)
  - 목극토 → 내가 극하는 오행 = 재성
  - 갑(양) vs 기(음) → 다른 음양 = 정재
  → 상대는 나의 "정재" (배우자 성분, 남자 기준)
```

## 5. 지지 (地支) 관계 — 일지 궁합용

> 현재 운테는 일간(천간)만 계산. 일지는 만세력 필요.
> 향후 정밀 궁합 서비스 시 참고.

### 5-1. 지지육합 (六合)

| 합 | 조합 | 합화 |
|----|------|------|
| 자축합 | 자(쥐) + 축(소) | 토 |
| 인해합 | 인(호랑이) + 해(돼지) | 목 |
| 묘술합 | 묘(토끼) + 술(개) | 화 |
| 진유합 | 진(용) + 유(닭) | 금 |
| 사신합 | 사(뱀) + 신(원숭이) | 수 |
| 오미합 | 오(말) + 미(양) | — |

### 5-2. 지지삼합 (三合)

| 삼합 | 조합 | 합화 |
|------|------|------|
| 화국 | 인오술 | 화 |
| 목국 | 해묘미 | 목 |
| 수국 | 신자진 | 수 |
| 금국 | 사유축 | 금 |

### 5-3. 지지충 (六冲)

| 충 | 조합 |
|----|------|
| 자오충 | 자 ↔ 오 |
| 축미충 | 축 ↔ 미 |
| 인신충 | 인 ↔ 신 |
| 묘유충 | 묘 ↔ 유 |
| 진술충 | 진 ↔ 술 |
| 사해충 | 사 ↔ 해 |

### 5-4. 원진살 (怨嗔殺)

서로 미워하면서도 얽히는 관계:
자↔미, 축↔오, 인↔사, 묘↔진, 신↔해, 유↔술

### 5-5. 도화살 (桃花殺)

매력·끌림 관련 신살. 일지 기준:

| 일지 | 도화 |
|------|------|
| 인오술 | 묘 |
| 해묘미 | 자 |
| 신자진 | 유 |
| 사유축 | 오 |

## 6. 관계 유형별 핵심 포인트

### 6-1. 친구 궁합
- **핵심 축**: 일간·일지 상생/상극, 비겁·식상 라인
- 상생 위주 → 에너지 올라가는 사이
- 비견/겁재 강함 → 동지 + 경쟁 (베프 타입)
- 한쪽 식상 + 한쪽 인성 → 아이디어맨 + 정리맨 조합

### 6-2. 연애·결혼 궁합
- **핵심 축**: 일주(특히 일지), 재성/관성, 도화·홍염
- 일지 관계 = 실제 동거/결혼 체감 퀄리티
- 재성 (남→여), 관성 (여→남) = 배우자 성분
- 오행 보완 vs 같은 기운 과다 (성향 비슷하나 번아웃)
- 도화·홍염 = 끌림 강도, 합충 = 지속력
- 대운·세운 타이밍 = 언제 만나야 잘 되는지

### 6-3. 가족 (부모·자녀) 궁합
- **핵심 축**: 년주·월주, 재성·관성(부모), 식상·인성(자녀)
- 인성 = 어머니, 편재 = 아버지 (**내 사주 기준**)
- 부모 오행이 자녀를 과하게 극 → 통제·간섭, 갈등↑
- 자녀가 부모 오행을 생 → 효자/효녀 but 부담감
- 합 강함 → 떨어지기 힘듦, 충 강함 → 부딪히기 쉬움

### 6-4. 직장·비즈니스 궁합
- **핵심 축**: 관성·재성(상사), 비겁·식상(동료)
- 상사 = 내 사주의 관성 (나를 통제·평가)
- 상사 오행이 나를 생 → 키워주는 상사
- 상사 오행이 나를 극 → 압박·관리 강한 상사
- 동료: 비겁 겹침 → 역할 경쟁, 식상+인성 조합 → 기획+실행 파트너

## 7. 운테 궁합 적용 가능 범위

## 8. 궁합 관계 매트릭스 (천간 10×10)

"내 일간(행) → 상대 일간(열)" 기준, 상대가 나에게 어떤 십성인지:

```
내\상대  갑    을    병    정    무    기    경    신    임    계
갑      비견  겁재  식신  상관  편재  정재  편관  정관  편인  정인
을      겁재  비견  상관  식신  정재  편재  정관  편관  정인  편인
병      편인  정인  비견  겁재  식신  상관  편재  정재  편관  정관
정      정인  편인  겁재  비견  상관  식신  정재  편재  정관  편관
무      편관  정관  편인  정인  비견  겁재  식신  상관  편재  정재
기      정관  편관  정인  편인  겁재  비견  상관  식신  정재  편재
경      편재  정재  편관  정관  편인  정인  비견  겁재  식신  상관
신      정재  편재  정관  편관  정인  편인  겁재  비견  상관  식신
임      식신  상관  편재  정재  편관  정관  편인  정인  비견  겁재
계      상관  식신  정재  편재  정관  편관  정인  편인  겁재  비견
```

### 판별 로직 (구현용)

```
오행: 갑을=목, 병정=화, 무기=토, 경신=금, 임계=수
음양: 갑병무경임=양, 을정기신계=음

1) 내 오행 vs 상대 오행 → 비겁/식상/재성/관성/인성 결정
2) 내 음양 vs 상대 음양 → 같으면 편(偏), 다르면 정(正)

예) 내가 갑(양목), 상대가 경(양금)
  → 금극목 = 나를 극하는 오행 = 관성
  → 양 vs 양 = 같은 음양 = 편(偏)
  → 편관
```

### 천간합/충 + 십성 복합 태그

| 조합 | 십성 | 천간합/충 | 궁합 해석 |
|------|------|-----------|-----------|
| 갑↔기 | 정재/정관 | 합 | 끌림+안정 (최상 궁합) |
| 을↔경 | 정관/정재 | 합 | 끌림+안정 (최상 궁합) |
| 병↔신 | 정재/정관 | 합 | 끌림+안정 (최상 궁합) |
| 정↔임 | 정관/정재 | 합 | 끌림+안정 (최상 궁합) |
| 무↔계 | 정재/정관 | 합 | 끌림+안정 (최상 궁합) |
| 갑↔경 | 편관/편재 | 충 | 자극+긴장 (갈등 or 성장) |
| 을↔신 | 편관/편재 | 충 | 자극+긴장 |
| 병↔임 | 편관/편재 | 충 | 자극+긴장 |
| 정↔계 | 편관/편재 | 충 | 자극+긴장 |
