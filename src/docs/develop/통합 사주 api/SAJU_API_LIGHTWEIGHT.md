# 사주 API 경량화 전략

> **목적**: Stargio 통합 사주 API 응답에서 대용량 필드를 제외하여 AI 토큰 비용 절감
> **적용 위치**: `mind-talk-chat`, `generate-free-preview` (excludeKeys 방식)
> **최종 업데이트**: 2026-03-12

---

## 1. 전체 흐름

```
사용자 사주 상담/무료 콘텐츠 요청
  → DB에서 사주 정보 조회 (saju_records)
  → Stargio 통합 사주 API 호출 (재시도 3회)
  → 전체 JSON에서 대용량 8개 키 제외 (excludeKeys 방식)
  → 시스템 프롬프트 [상세 사주 데이터] 블록에 삽입
  → AI가 참고하여 상담/해석 응답 생성
```

---

## 2. API 호출

- **엔드포인트**: `https://service.stargio.co.kr:8400/StargioSaju`
- **파라미터**: `birthday` (YYYYMMDDHHMM), `lunar=false`, `gender`, `apiKey`
- **인증**: `SAJU_API_KEY` 환경변수 (Supabase Secrets)
- **재시도**: 3회 (1초, 2초 간격 Exponential Backoff)
- **헤더**: 브라우저 헤더 흉내 필수 (CORS 우회)

---

## 3. 경량화: 제외 방식 (excludeKeys)

원본 API 응답에서 **토큰 소비가 큰 8개 키만 제외**하고 나머지를 모두 포함합니다.

### 제외 필드 (8개)

| 필드 | 제외 이유 |
|------|----------|
| `월운보기` | 12개월 상세 운세 (매우 큼, 수천 토큰) |
| `본사주` | 합/충/형/원진 상세 분석 (큼) |
| `대운` | 현재/다음 대운 상세 텍스트 (큼) |
| `대운순서` | 대운 타임라인 배열 |
| `대운시작나이` | 대운 시작 나이 |
| `대운순서십이운성` | 대운 십이운성 목록 |
| `대운순서십성` | 대운 십성 목록 |
| `용신설명` | 용신 상세 텍스트 (큼) |

### 포함 필드 (~34개)

| 카테고리 | 포함 필드 |
|----------|----------|
| **기본 정보** | `성별`, `나이`, `만나이`, `양력`, `음력` |
| **사주 구성** | `사주`, `오행`, `십성`, `십이운성`, `사주점수`, `사주강약` |
| **오행/십성** | `발달오행`, `발달십성`, `천간점수` |
| **오주(확장)** | `오주`, `오주오행`, `오주십성` |
| **신살** | `12신살`, `기타신살` |
| **격국/용신** | `격구분`, `격용신`, `격용신오행`, `용신`, `용신오행` |
| **해석 텍스트** | `물상론` (닉네임/성격/인간관계), `일주론` (총평/연애성향/추천직업), `사주귀천` |
| **오늘 운세** | `오늘`, `오늘의운세`, `오늘의직장운`, `오늘의재물운`, `오늘의대인관계운`, `오늘의연애운` |
| **관계** | `관계분석` (이상형/연인시기/조심시기) |

## 4. 프롬프트 삽입 구조

```
[사용자 성향 태그]
#내향적(+) #완벽주의(-) ...

[사용자 심리 상황 요약]
[1주 전] 직장에서 스트레스를 받고 있음...

[나다움 분석 요약]
[성격] 내면이 섬세하고...

[상세 사주 데이터]        ← 여기에 경량화된 JSON 삽입
{
  "격구분": "종살격",
  "사주": ["乙亥", "己巳", "庚子", "辛未"],
  "물상론": { "닉네임": "한겨울의 흙", "성격": "..." },
  ...
}
```

## 5. 토큰 절감 효과

- **원본**: 전체 API JSON (~42개 키, 중첩 객체 포함, `월운보기`만 수천 토큰)
- **경량화**: 토큰 소비 큰 8개 키 제외 → ~34개 핵심 필드 유지
- **로그**: `✅ 사주 API 호출 성공 (전체: N키, 추출: M키)` 형태로 Supabase 로그에서 확인 가능

---

## 6. AI 활용 지침 (시스템 프롬프트)

사주 모드 시스템 프롬프트에서 AI에게 아래와 같이 지시:

- 사주 전문 용어(종살격, 상관, 편관, 대운, 오행 등)는 **직접 언급하지 않고** 쉬운 일상 언어로 풀어서 설명
- 사주 데이터가 있으면 **반드시 활용**하여 맞춤 상담 제공
- 사용자의 현재 고민/상황에 맞는 운세 해석 제공
